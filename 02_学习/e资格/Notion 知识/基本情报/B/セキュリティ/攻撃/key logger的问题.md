# key logger的问题

キーボード入力を読み取って第三者に送信するプログラムは、キーロガーと呼ばれます。

***利用者 ID とパスワード方式***と***チャレンジレスポンス方式***は、利用者 ID とパスワードだけで認証していますので、キーロガーによって利用者 ID とパスワードが一度盗まれれば、以後は第三者がいつでもログインできます。ただし、***利用者 ID とパスワード方式***はパスワードが通信経路上を流れるのに対し、***チャレンジレスポンス方式***はパスワードが通信経路上に流れないので、通信経路上でのパスワード盗聴のリスクがありません。

由于挑战法hash值还是在本地通过键入id和密码生成的，位于本地的key logger也能记录下来用于不当使用。。。

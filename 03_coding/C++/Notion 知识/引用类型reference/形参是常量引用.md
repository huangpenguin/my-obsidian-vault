# 形参是常量引用

```cpp
void f(const int& b) {}

int main() {
    f(1); // 合法的调用
    return 0;
}

```

### 常量引用 (const reference)

- `const int& b` 是一个常量引用，意味着它可以绑定到一个常量对象。
- 常量引用可以绑定到常量值、临时对象（即右值），以及非常量的左值（变量）。

### 传递字面值

- 当你传递一个整数字面值（如 `1`）给一个接受 `const int&` 的函数时，编译器会创建一个临时的整数对象并将其绑定到引用。
- 这个临时对象的生命周期会被延长到引用的生命周期结束，即在函数调用期间它是有效的。
- 在 `f(1);` 这行代码中，字面值 `1` 是一个右值。C++ 允许将右值绑定到 `const` 引用，因为右值的生命周期会被延长以确保引用在函数调用期间是有效的。

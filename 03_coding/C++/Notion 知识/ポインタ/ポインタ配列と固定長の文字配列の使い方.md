# ポインタ配列と固定長の文字配列の使い方

1.某种意义上来说const char* a=“abc”和char[]=”abc”用法相同,或者说本质上来说，数组名就是一个常量指针指向首元;

2.注意在这里其实指针是没有提前确保内存空间的，而配列则已经规定好空间了

```cpp
char a[]="afsgdghth";
a="sg54eg4";//尝试改变数组a的地址是错误的
```

- **ポインタ配列の場合**：ポインタが指す先を変更できます。
- **固定長の文字配列の場合**：個々の文字列の内容を変更するには、**`strcpy`** などの関数を使ってコピーする必要があります。***配列の各要素自体に新しいアドレスを代入することはできません***。
- **`a[1] = "a";`** という文は、**`a[1]`** に新しいアドレス（"a" の位置）を代入しようとする操作です。固定長の文字配列（配列の配列）では、各要素が固定されたメモリ位置を持つため、このような操作は許可されていません。**`a`** は固定長の文字配列で、各要素（**`a[0]`**, **`a[1]`**, **`a[2]`**）がそれぞれ独立した配列です。これらの配列のアドレスは変更できません。
- **固定長の文字配列**とは、各文字列が固定長の配列としてメモリに確保される配列のことを指します。これは、配列の各要素が文字列を格納するための固定されたサイズのメモリブロックを持つということです。例えば、**`char a[][5]`** という配列は、各要素が5文字分のメモリを持つ文字列の配列です。
**固定長の文字配列定義**: **`char a[][5] = { "LISP", "C", "Ada" };`** は、5文字分のメモリを持つ配列 **`a`** を定義しています。各要素は最大で4文字と終端文字（NULL文字）の5文字を保持できます。
- **固定長の文字配列を使う理由:**固定長の文字配列は、予め最大の文字列長が決まっている場合や、メモリ効率を高めるために使用されます。各要素のサイズが同じであるため、ランダムアクセスが効率的に行えます。配列の定義時に指定されたサイズを超える文字列は格納できません.このように、固定長の文字配列は一度定義すると、その構造自体は変わらないため、内容の変更には特定の方法を用いる必要があります。

```cpp
int main(void)
{
	char a[][5] = { "LISP", "C", "Ada" };
	const char* p[] = { "PAUL", "X", "MAC" };

	for (int i = 0; i < sizeof(a) / sizeof(a[0]); i++) {
		printf("a[%d] = \"%s\"\n", i, a[i]);
	}

	putchar('\n');//char a[][5] = { "LISP", "C", "Ada" }; は、各要素が配列であり、これらの配列は固定長のメモリに割り当てられています。このため、個々の要素に対して新しい文字列リテラルを代入することはできません。しかし、const char* p[] = { "PAUL", "X", "MAC" }; のようにポインタ配列の場合は、ポインタが指す先を変更することができます。
	//a[1] = "a";
	p[1] = "a";
	for (int i = 0; i < sizeof(p) / sizeof(p[0]); i++) {
		printf("p[%d] = \"%s\"\n", i, p[i]);
	}

	return 0;
}

```

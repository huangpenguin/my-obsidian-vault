# 生成器generator

生成器（Generator）是 Python 中的一种特殊类型的迭代器，允许函数在执行过程中暂停并在以后继续执行
生成器使用 `yield` 关键字返回一个值，并且在每次调用时从上次暂停的地方继续执行。生成器是懒惰求值的，即它们会按需生成数据，而不是一次性生成所有数据。

---

**generator -- 生成器**

返回一个 [generator iterator](https://docs.python.org/zh-cn/3.12/glossary.html#term-generator-iterator) 的函数。它看起来很像普通函数，不同点在于其包含 [`yield`](https://docs.python.org/zh-cn/3.12/reference/simple_stmts.html#yield) 表达式以便产生一系列值供给 for-循环使用或是通过 [`next()`](https://docs.python.org/zh-cn/3.12/library/functions.html#next) 函数逐一获取。

**generator iterator -- 生成器迭代器**

[generator](https://docs.python.org/zh-cn/3.12/glossary.html#term-generator) 函数所创建的对象。
每个 [`yield`](https://docs.python.org/zh-cn/3.12/reference/simple_stmts.html#yield) 会临时暂停处理，记住当前位置执行状态（包括局部变量和挂起的 try 语句）。当该 *生成器迭代器* 恢复时，它会从离开位置继续执行（这与每次调用都从新开始的普通函数差别很大）。

---

### 生成器的特点

1. **延迟计算：** 生成器每次只生成一个值，节省内存空间，适合处理大型数据集。
2. **状态保存：** 生成器会在 `yield` 语句处暂停，保存当前的执行状态，并在下次调用时继续执行。
3. **可迭代：** 生成器是可迭代对象，可以使用 `for` 循环、`next()` 函数等来遍历其生成的值。

### 生成器的语法

生成器通过在函数中使用 `yield` 关键字定义，yield每次出一个值，同时在此处中断

```python
def simple_generator():
    yield 1
    yield 2
    yield 3

gen = simple_generator()
print(next(gen))  # 输出: 1
print(next(gen))  # 输出: 2
print(next(gen))  # 输出: 3
#print(next(gen))  # Error

#下面的写法始终是重新生成一个生成器
print(next(simple_generator()))  # 输出: 1
print(next(simple_generator()))  # 输出: 1
print(next(simple_generator()))  # 输出: 1
```

生成器表达式是一种生成器的简洁表示法，类似于列表推导式，但使用圆括号而不是方括号。

```python
##生成器表达式
gen = (x ** 2 for x in range(10))
for value in gen:
    print(value)

##列表推导式
```

### 生成器的应用场景

1. **处理大数据集：** 生成器按需生成数据，适合处理无法一次性加载到内存中的大数据集。
2. **无限序列：** 生成器可以用于生成无限序列，如斐波那契数列、素数序列等。
3. **数据流处理：** 生成器可用于处理实时数据流，逐步处理数据而不是一次性加载所有数据。

### 生成器示例

1. **生成斐波那契数列：**

```python
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

fib = fibonacci()
for _ in range(10):
    print(next(fib))
```

**读取大文件：**

```python
def read_large_file(file_path):
    with open(file_path) as file:
        for line in file:
            yield line

file_path = 'large_file.txt'
for line in read_large_file(file_path):
    process(line)  # 假设存在处理函数
```

### 总结

生成器是 Python 中处理迭代数据的一种高效方式。它们通过延迟计算和按需生成数据，提供了内存效率高和易于实现的方案，特别适合处理大型数据集或无限序列。生成器表达式提供了一种简洁的语法，使得生成器的使用更加方便。

### 注意一个生成器的lifespan

在Python中，生成器是一次性使用的。当你使用生成器时，它会从当前位置开始生成值，一直到生成器耗尽为止。一旦生成器耗尽，就不能再次使用它生成值，除非你重新创建一个新的生成器实例。

在你的代码中，`ranger` 是一个生成器。你第一次迭代 `ranger` 时，它会从头到尾生成所有值。迭代完成后，`ranger` 已经耗尽，再次迭代它不会生成任何值。

```python
def my_range(first=0,last=10,step=1):
    number=first
    while number < last:
        yield number  #生成器返回当前的 number 值，并暂停执行，等待下一次调用 next()。
        number +=step 
#每次调用 next()，生成器会从上次暂停的地方继续执行。因为 number += step 在 yield number
#之后，所以每次 next() 调用都会执行 number += step，然后再次检查 while number < last 是否成立。
        
ranger=my_range(1,5)
for x in ranger:
    print(x) 

ranger_1=my_range(1,5)
for x in ranger_1:#这个地方如果再去访问ranger则啥都不会有
    print(x)
```

如果你想要重复使用生成的值，可以将生成器的值存储在一个列表中，这样你就可以多次访问这些值而不需要重新生成它们：

```python
ranger = list(my_range(1, 5))
for x in ranger:
    print(x)  # 输出: 1 2 3 4

# 再次访问已生成的值
for x in ranger:
    print(x)  # 输出: 1 2 3 4

```

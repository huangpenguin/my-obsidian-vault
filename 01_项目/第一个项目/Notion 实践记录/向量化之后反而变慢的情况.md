# 向量化之后反而变慢的情况

向量化前

```matlab
function rev = delay_line(Y, delay0, delay1, delay2, delay3, dev, out, M, N)

delay0_else_old =  mod(delay0+1,M)+1;
delay1_else_old =  mod(delay1+1,M)+1;
delay2_else_old =  mod(delay2+1,M)+1;
delay3_else_old =  mod(delay3+1,M)+1;

for i = 1:N   
    if dev(i)<1                               
        out(i)=interpl_4(Y(i, delay0(i)+1), Y(i, delay1(i)+1) ,Y(i, delay2(i)+1),Y(i, delay3(i)+1),dev(i));                        
    else                        
        out(i)=interpl_4(Y(i, delay0_else_old(i)),Y(i, delay1_else_old(i)), Y(i, delay2_else_old(i)),Y(i, delay3_else_old(i)),dev(i)-1);                  
    end            
end
rev = out;
end

function rev = interpl_4(a, b, c, d, frac)
cminusb = c - b;
rev = b + frac .* (cminusb - 0.166666667 .* (1. - frac) .* ((d - a - 3.0 .* cminusb) .* frac + (d + 2.0 .* a - 3.0 .* b)));
end
```

向量化后（变慢）

```matlab
function rev = delay_line(Y, delay0, delay1, delay2, delay3, dev, out, M, N)

delay0_else = mod(delay0 + 1, M) + 1;
delay1_else = mod(delay1 + 1, M) + 1;
delay2_else = mod(delay2 + 1, M) + 1;
delay3_else = mod(delay3 + 1, M) + 1;

y0 = Y(sub2ind(size(Y), 1:1001, delay0 + 1));  
y1 = Y(sub2ind(size(Y), 1:1001, delay1 + 1)); 
y2 = Y(sub2ind(size(Y), 1:1001, delay2 + 1));  
y3 = Y(sub2ind(size(Y), 1:1001, delay3 + 1)); 

y0_else = Y(sub2ind(size(Y), 1:1001, delay0_else)); 
y1_else = Y(sub2ind(size(Y), 1:1001, delay1_else)); 
y2_else = Y(sub2ind(size(Y), 1:1001, delay2_else)); 
y3_else = Y(sub2ind(size(Y), 1:1001, delay3_else)); 

dev_less_than_1 = dev < 1;

out(dev_less_than_1) = interpl_4(y0(dev_less_than_1), y1(dev_less_than_1), y2(dev_less_than_1), y3(dev_less_than_1), dev(dev_less_than_1));
out(~dev_less_than_1) = interpl_4(y0_else(~dev_less_than_1), y1_else(~dev_less_than_1), y2_else(~dev_less_than_1), y3_else(~dev_less_than_1), dev(~dev_less_than_1) - 1);

rev = out;

end

function rev = interpl_4(a, b, c, d, frac)
cminusb = c - b;
rev = b + frac .* (cminusb - 0.166666667 .* (1. - frac) .* ((d - a - 3.0 .* cminusb) .* frac + (d + 2.0 .* a - 3.0 .* b)));
end
```

- **索引访问的开销**：第二段代码使用了 `sub2ind` 函数来生成索引，然后一次性从矩阵 `Y` 中提取数据。虽然这种做法在语法上很简洁，但 `sub2ind` 的使用引入了额外的计算开销。这是因为 `sub2ind` 需要计算每一个元素的线性索引，尤其是在矩阵尺寸较大时，这个过程会比较耗时。
- **条件判断的实现方式**：第一段代码在每次迭代中都直接通过 `if-else` 语句来判断并选择相应的值，而第二段代码先进行批量的条件判断并存储在 `dev_less_than_1` 变量中，然后再使用逻辑索引进行批量处理。这种方法虽然可以减少代码的行数，但在执行逻辑索引的过程中需要分配额外的内存来存储布尔索引，并且在大规模数据集下，这种方式的性能可能不如简单的逐项 `if-else` 语句。
- **内存访问模式**：第一段代码通过在每次循环中访问所需的元素，这种方法在内存访问模式上更具局部性，可以更好地利用 CPU 缓存。这种连续访问小块内存的方式通常比第二段代码那样一次性访问多个不同位置的内存要快，因为后者可能导致缓存命中率降低。
- **循环优化**：虽然 MATLAB 通常在循环处理上比向量化操作慢，但在这个特定场景下，由于涉及较复杂的索引计算和条件判断，直接的逐元素操作反而减少了内存操作复杂性，从而提高了速度。

虽然向量化通常是优化 MATLAB 代码的一个重要策略，但并不总是适用。特别是在涉及复杂条件判断、索引计算或内存分配时，循环有时能带来更直接和高效的操作，因为 MATLAB 的 JIT（即时编译器）能够对简单的循环结构进行有效优化

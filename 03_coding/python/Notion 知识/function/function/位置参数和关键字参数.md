# 位置参数和关键字参数

1. **位置参数**：通过参数的位置来传递值。
2. **关键字参数**：通过参数名来传递值。

在定义函数时，例如：

```python
def f(a=1, b=2):
    print(f"a: {a}, b: {b}")

```

函数 `f` 定义了两个带有默认值的参数 `a` 和 `b`。你可以通过位置参数或关键字参数来调用这个函数。

### 使用位置参数

当你调用 `f(2, 3)` 时，`2` 和 `3` 被作为位置参数传递，分别对应参数 `a` 和 `b`：

```python
f(2, 3)  # 输出: a: 2, b: 3

```

### 使用关键字参数

你也可以使用关键字参数来调用这个函数：

```python
f(a=2, b=3)  # 输出: a: 2, b: 3

```

或者混合使用位置参数和关键字参数：

```python
f(2, b=3)  # 输出: a: 2, b: 3

```

### 总结

尽管 `a` 和 `b` 在定义时有默认值，并且可以作为关键字参数使用，但这并不限制你只能通过关键字来传递它们。你仍然可以使用位置参数的方式来传递这些值。位置参数会按顺序覆盖默认值，而关键字参数则通过指定的参数名来覆盖默认值。

下面是完整的示例，展示了多种调用方式：

```python
def f(a=1, b=2):
    print(f"a: {a}, b: {b}")

# 使用位置参数
f(2, 3)  # 输出: a: 2, b: 3

# 使用关键字参数
f(a=2, b=3)  # 输出: a: 2, b: 3

# 混合使用位置参数和关键字参数
f(2, b=3)  # 输出: a: 2, b: 3

# 只使用默认参数
f()  # 输出: a: 1, b: 2

```

# 无名命名空间

1. **内部链接**：与**`static`**关键字一样，无名命名空间中的所有变量和函数都具有内部链接，即它们在定义它们的文件之外不可见。
2. **作用域限制**：无名命名空间中的所有内容只在声明它们的文件中可见。这有助于避免命名冲突，并确保这些实体不会在其他文件中被访问。

```cpp
// file1.cpp
namespace {
    int counter = 0;

    void incrementCounter() {
        counter++;
    }
}

void useCounter() {
    incrementCounter();
}

// file2.cpp
// 不能访问 file1.cpp 中的 counter 和 incrementCounter
// int anotherCounter = counter;  // 错误：counter 在此文件中不可见
// incrementCounter();  // 错误：incrementCounter 在此文件中不可见

```

# * 和 **

在 Python 中，`*` 和 `**` 可以用于函数定义和调用时的参数解包。它们分别用于结合位置参数（positional arguments）和关键词参数（keyword arguments）。

在函数定义中，`*args` 用于将可变数量的位置参数组合成一个元组。

```python
def my_function(*args):
    for arg in args:
        print(arg)

my_function(1, 2, 3)  # 输出: (1,2,3)
```

### `*kwargs`

在函数定义中，`**kwargs` 用于将可变数量的关键词参数组合成一个字典。进来的一开始处是字典

```python
def my_function(**kwargs):
    for key, value in kwargs.items():
        print(f"{key} = {value}")

my_function(a=1, b=2, c=3)  # 输出: a = 1 b = 2 c =3
```

一个*参数只能出现在函数定义中最后一个位置参数后面，而 [**](https://python3-cookbook.readthedocs.io/zh-cn/latest/c07/p01_functions_that_accept_any_number_arguments.html#id5)参数只能出现在最后一个参数。 有一点要注意的是，在*参数后面仍然可以定义其他参数,这种参数就是我们所说的强制关键字参数

```python
def a(x, *args, y):
    pass

def b(x, *args, y, **kwargs):
    pass
```

---

在 Python 中，`*` 和 `**` 操作符常用于函数定义和函数调用时传递关键字参数。

**用于函数定义**：

*允许函数接受任意数量的位置参数，返回一个包含所有位置参数的元组。

** 允许函数接受任意数量的关键字参数，返回一个包含所有关键字参数的字典。

**用于函数调用**：

`*`可以将一个列表或元组解包成位置参数传递给函数。

`**` 可以将一个字典解包成关键字参数传递给函数。

示例：

```python
def example_function(x, y, z):
    print(x, y, z)

args = (1, 2, 3)
example_function(*args)  # 等效于 example_function(1, 2, 3)

kwargs = {'x': 4, 'y': 5, 'z': 6}
example_function(**kwargs)  # 等效于 example_function(x=4, y=5, z=6)

```

输出：

```

1 2 3
4 5 6

```

# 基础知识

### 1. **Ollama 的架构简要**

Ollama 是一个运行本地语言模型的轻量框架，它：

- 封装了模型加载、推理和管理的所有底层逻辑；
- 对外提供一个统一的 HTTP API（如 `/api/generate` 或 `/api/chat`）；
- 用户调用的是一个 *封装后推理结果的接口*，并非底层模型内部推理的控制接口。

### 2. **你无法做的事情**

使用 Ollama 时，以下通常无法做到：

- **修改系统提示（system-level instruction）** 在模型载入或 system template 级别；
- **更改 inference middleware**（如修改 think block 的插入机制）；
- **修改 tokenizer 行为、logits 处理、stop condition 等底层推理规则**；
- **访问模型的配置文件（如 qwen.yaml）或代码中的 prompt-injection templates**（除非你自己手动修改 Ollama 镜像构建方式）。

### 3. **你能做的事情**

- 控制传入的 prompt（包括 system prompt）；
- 控制使用的模型版本；
- 修改 Ollama 配置（如并发数量、设备等）；
- **对返回内容做后处理（这是目前你能有效控制输出的地方）**；
- 如果愿意，可以**fork Ollama 源码，修改其中的推理逻辑，然后重新构建本地模型镜像**（这需要较强工程能力）。

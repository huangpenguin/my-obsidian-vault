# new

`new A{}` 这种语法不会报错，即使类 `A` 只有默认构造函数。这种表达方式是合法的，用于在堆上分配一个 `A` 类型的对象，并调用它的默认构造函数。C++ 语言中的内存分配机制和对象大小处理确保了这可以正常工作。

### 详细解释

### 1. 内存分配和对象大小

当你使用 `new` 操作符时，C++ 运行时会根据类型 `A` 的大小来分配足够的内存。类的大小是编译期已知的，无论类是否有默认构造函数。

- **类的大小**：编译器在编译时确定类 `A` 的大小（包括它的成员变量所需的内存和对齐要求）。
- **内存分配**：`new` 操作符在运行时请求分配器（通常是 `malloc` 或类似机制）为对象分配足够的内存。
- **对象构造**：内存分配完成后，`new` 操作符会调用类的构造函数来初始化对象。

### 2. `new` 操作符的使用

`new A{}` 表达式在现代 C++ 中是合法的，用来创建类型 `A` 的对象并调用它的默认构造函数。

- **C++11 及以后**：在 C++11 引入的统一初始化语法（也称为列表初始化）中，`A{}` 是一种新的初始化方式，称为**列表初始化**。即使在这里我们使用的是`new`操作符，`A{}` 会尝试调用匹配的构造函数。
    - `A a{};` 使用默认构造函数初始化 `a`。
    - `new A{}` 在堆上分配一个 `A` 类型的对象，并使用默认构造函数初始化。

### 运行时内存分配的机制

在调用 `new A{}` 时，发生了以下步骤：

1. **内存分配**：`new` 操作符首先在堆上分配足够的内存以容纳 `A` 类型的对象。
    - 编译器已经知道 `A` 的大小（包括其所有成员）。
    - 分配的内存是通过调用 `operator new`（类似于 `malloc`）来完成的。
2. **构造函数调用**：内存分配完成后，`new` 操作符会调用 `A` 的构造函数来初始化该对象。
    - 在 `new A{}` 这种情况下，`A` 的默认构造函数被调用。
3. **返回指针**：`new` 操作符返回指向分配内存（且初始化后）的对象的指针。

### 

以下是一个完整的例子，展示了如何在 C++ 中使用 `new` 操作符分配对象的内存：

```cpp
cpp复制代码
#include <iostream>class A {
//默认是private
public:
    A() { std::cout << "A's default constructor called." << std::endl; }
    int x;
    double y;
};

int main() {
    A* ptr = new A{};  // 创建一个 A 对象，调用默认构造函数
    ptr->x = 42;
    ptr->y = 3.14;

    std::cout << "ptr->x: " << ptr->x << ", ptr->y: " << ptr->y << std::endl;

    delete ptr;  // 释放内存
    return 0;
}

```

在这个示例中：

- `new A{}` 创建一个 `A` 对象，并调用默认构造函数。
- 我们可以访问和修改对象的成员。
- `delete ptr` 释放分配的内存。

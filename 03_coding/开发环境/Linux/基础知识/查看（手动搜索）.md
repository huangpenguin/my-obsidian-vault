# 查看（手动搜索）

### ✅ **在文件名后加上标识符，标出类型**：

| 类型 | 显示形式（加的符号） |
| --- | --- |
| 目录 | `/` 结尾 |
| 可执行文件 | `*` 结尾 |
| 符号链接 | `@` 结尾 |
| 命名管道 | ` |
| 套接字 | `=` 结尾 |

---

### 🔍 举例：

```bash

ls -F /home/user/workspace

```

输出可能是这样的：

```

project1/     run.sh*     README.md    data@
```

解释如下：

- `project1/`：目录
- `run.sh*`：可执行脚本
- `README.md`：普通文件
- `data@`：符号链接（symlink）

---

### ✅ 为什么用 `F`？

- 它比默认的 `ls` 多提供了文件类型的视觉提示
- 但又不像 `ls -l` 那样占用太多空间
- 很适合快速浏览目录结构时使用

---

如果你习惯用 `ls` 来看文件，可以考虑在 `.bashrc` 或 `.zshrc` 中加上别名：

```bash

alias ls='ls -F --color=auto'

```

这样你每次用 `ls` 都能看到类型标记+颜色，非常直观。

---

- **`tree -L 2 /datadrive`**  非常好用的观察文件夹结构的办法
- **`cat`**: 显示文件内容。
    - `cat myfile.txt`
- **`less`**: 分页显示文件内容（按 `q` 退出）。
    - `less large_log_file.log`

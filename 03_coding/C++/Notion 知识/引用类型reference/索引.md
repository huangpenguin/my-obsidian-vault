# 引用类型reference

1.普通的参照是左边值参照，初始化的时候只能使用左值，但是后面的代入可以使用比如数字リテラシー等右值，而右边值参照&&是c++11后引入的，经常用于move_construct

2.相当于一个常量指针(const *),一旦指定之后就无法再更改指定位置

```cpp
#include <iostream>
#include <vector>
using namespace std;
class A
{
    int m_value{0};

public:
    A(){};
    int &value()
    {
        return m_value;
    }
    const int &value() const
    {
        return m_value;
    }
    void show()
    {
        cout<<"A's value is "<<m_value<<endl;
    }
};

int main()
{
    A a = A{};
    int& b=a.value();
    cout<<"b="<<b<<endl;
    b=100;
    cout<<a.value()<<endl;
    a.show();

    const int& c=a.value();
    //c=10000; error
    cout<<c<<endl;
    a.show();
}
```

3.代入新的值也不会改变该参照的地址，只是其参照对象被修改了

```cpp
int main() {
    int &&b = 100;  // b 是一个右值引用，绑定到临时对象 100
    int &a = b;     // a 是一个左值引用，绑定到 b 所引用的对象

    std::cout << "Address of b: " << &b << std::endl; // 输出 b 的地址
    std::cout << "Address of a: " << &a << std::endl; // 输出 a 的地址

    a = 10; // 通过 a 修改 b 所引用的对象的值

    std::cout << "Value of b: " << b << std::endl;    // 输出 b 的值
    std::cout << "Value of a: " << a << std::endl;    // 输出 a 的值

    
    std::cout << "Address of b: " << &b << std::endl; // 输出 b 的地址
    std::cout << "Address of a: " << &a << std::endl; // 输出 a 的地址
    return 0;
}
```

# (已集成到全过程中)设置 SSH 端口转发和docker转发

要在本地通过端口转发访问你 GCP VM 上运行的 Ollama（或其它）服务，关键是在 SSH 连接时加上 `-L` 参数，把远程主机的端口映射到你本地机器的一个端口。下面分步骤详细说明：

---

### 端口转发命令格式

```bash
gcloud compute ssh <VM_NAME> \
  --zone=<ZONE> \
  -- -L <本地端口>:localhost:<远程端口>
```

- `<VM_NAME>`：你的 VM 实例名称，例如 `ty-test`
- `<ZONE>`：VM 所在可用区，例如 `us-central1-f`
- `L 本地端口:localhost:远程端口`：
    - **本地端口**：你想在自己电脑上用哪个端口访问（如 `11434`）
    - **localhost**：表示映射到 VM “自己” 的环回地址
    - **远程端口**：VM 内部服务实际监听的端口（Ollama 默认是 `11434`）
    - 执行后，SSH 会话建立，并为你在本地开启一个监听。在这个会话存续期间，你在自己机器上访问 `http://localhost:11434`，会被自动转发到 VM 上的 `localhost:11434`

---

### 确认远程服务在 VM 上可用

在 VM 上，Ollama 容器已经用以下命令启动：

```bash
sudo docker run -d \
  --gpus=all \
  -v ollama:/root/.ollama \
  -p 11434:11434 \
  --name ollama \
  ollama/ollama:latest
```

这会让 **VM 内部** 的 `localhost:11434` 上有一个 HTTP 服务。 (VM↔ollama docker)

---

### 在本地测试

1. **保持上面那条命令的 SSH 窗口打开**；
2. 本地另开一个终端（或在脚本里直接调用），运行：
    
    ```bash
    
    curl http://localhost:11434/api/models
    ```
    
    或者直接在浏览器里打开 `http://localhost:11434`，看是否能返回 Ollama 的接口页面；
    
3. **在本地运行你的 Python 脚本**，确保脚本中的 `OLLAMA_URL = 'http://localhost:11434'`，即可直接向 VM 上的服务发起请求。

---

### 可选：后台转发

如果你不想在 SSH 会话窗口里输入任何命令，只做端口转发，可以加上 `-N`（不执行远程命令）：

```bash
gcloud compute ssh ty-test \
  --zone=us-central1-f \
  -- -L 11434:localhost:11434 -N
```

- 这条命令会一直运行，直到你在本地按 `Ctrl-C` 结束
- 同样保持本地端口映射有效，方便脚本或浏览器访问

---

完成以上步骤后，你就能在自己电脑上的 IDE 或终端，像访问本地服务一样，测试和调试连接到 GCP VM 上的 Ollama 服务了。

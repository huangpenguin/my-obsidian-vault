# 无标题

## 项目概述

这是一个基于 PaddleOCR 的托盘文字识别项目，主要用于识别工业托盘上的文字信息。

## 完整流程解析

**涉及两台机器：**

- **Workstation (192.168.3.24)：** 用于代码修改、数据准备、标注
- **GPU Server (192.168.3.18)：** 用于模型训练

### 2. 数据准备阶段 (02_data.md - 推测)

**虽然没有提供具体文档，但从项目结构可以推断：**

**数据收集：**

- 使用 `tray_capture` 模块采集托盘图像
- 图像包含需要识别的文字信息

**数据标注：**

- 使用 PPOCRLabelv2 标注工具
- 分别标注文本检测（det）和文本识别（rec）数据
- 检测标注：标出文字区域的边界框
- 识别标注：标出每个文字区域对应的文本内容

**数据格式：**

- 检测数据：图像 + 边界框坐标
- 识别数据：文字图像片段 + 对应文本

## 完整工作流程总结：

1. **环境准备** → 在两台服务器上配置相同的 Python 环境
2. **数据采集** → 使用 tray_capture 收集托盘图像

6. **模型验证** → 测试模型性能
7. **模型部署** → 部署到生产环境（可能涉及 ROS 节点）

- **多机协作：** 开发和训练分离，提高效率
- **分布式训练：** 使用4张GPU并行训练，加速训练过程
- **两阶段OCR：** 先检测文字位置，再识别文字内容
- **领域适配：** 针对日语和特定行业数据进行模型定制

```bash

```

**命令详解：**

- `nohup ... &`：后台运行，即使断开SSH连接也继续训练
- `python -u`：实时输出print内容，不缓存
- `m paddle.distributed.launch`：启动分布式训练
- `-ips` 和 `-gpus`：指定使用的机器和GPU
- `> output/xxx.log 2>&1`：将输出和错误都重定向到日志文件

### 训练日志解读：

```
[2025/04/15 15:22:33] ppocr INFO: epoch: [2/1000], global_step: 230, lr: 0.006990,
loss: 1.155330, loss_shrink_maps: 0.640279, loss_threshold_maps: 0.408506,
loss_binary_maps: 0.112043, loss_cbn: 0.000000, avg_reader_cost: 0.00958 s,
avg_batch_cost: 0.91719 s, avg_samples: 16.0, ips: 17.44460 samples/s,
eta: 1 day, 17:24:24, max_mem_reserved: 16865 MB, max_mem_allocated: 15705 MB

```

**每个参数的含义：**

- `epoch: [2/1000]`：当前第2轮，总共1000轮
- `global_step: 230`：全局训练步数
- `lr: 0.006990`：当前学习率
- `loss: 1.155330`：总损失值（越小越好）
- `loss_shrink_maps, loss_threshold_maps, loss_binary_maps`：DB++算法的不同损失组件
- `avg_batch_cost: 0.91719 s`：每个batch耗时
- `ips: 17.44460 samples/s`：每秒处理的图片数
- `eta: 1 day, 17:24:24`：预计还需要训练时间
- `max_mem_reserved: 16865 MB`：GPU显存使用量

### 2.3 `crt_ocr_rec_baseline.py` - 生成识别baseline数据集

**目的：** 创建用于训练日语文字识别baseline模型的数据集

**处理的数据类型：**

```python
def create_rec_baseline():
    synthetic_datasets = [
        "ja+en/1_3m",      # 日英混合300万
        "ja+en/2_0.3m",    # 长文本30万
        "ja/1_3m",         # 纯日语300万
        "ja/1_2m",         # 纯日语200万
        "ja/2_0.5m",       # 长文本50万
    ]

    public_datasets = [
        "mlt-2017",        # 国际竞赛数据
        "mlt-2019"
    ]

    # 合成数据：单个文字图片 + 对应文本
    # 格式：word_001.jpg	Toyota

    all_data = []
    for dataset in synthetic_datasets + public_datasets:
        data = load_recognition_data(dataset)
        all_data.extend(data)

    # 转换为LMDB格式（高效的数据库格式）
    create_lmdb_dataset(all_data, "rec_baseline_train_202210")

```

**数据格式转换：**

```
原始：每个文字区域的图片 + 对应文本
word_001.jpg -> "Toyota"
word_002.jpg -> "トヨタ"
word_003.jpg -> "ABC123"

LMDB格式：高效的键值对数据库
key: image_001, value: (image_binary, "Toyota")
key: image_002, value: (image_binary, "トヨタ")

```

### 2.4 `crt_ocr_rec_aisin.py` - 生成Aisin识别数据集

**关键步骤：**

```python
def create_rec_aisin():
    # 1. 读取检测数据的标注
    det_annotations = load_det_annotations("det_aisin_train_202504.txt")

    word_images = []
    word_texts = []

    for img_path, annotations in det_annotations:
        # 2. 加载原始图片
        original_img = cv2.imread(img_path)

        for ann in annotations:
            # 3. 根据边界框裁剪出文字区域
            points = ann["points"]
            transcription = ann["transcription"]

            # 透视变换，将四边形文字区域变为矩形
            word_img = crop_text_region(original_img, points)

            word_images.append(word_img)
            word_texts.append(transcription)

    # 4. 保存为LMDB格式
    create_lmdb_dataset(word_images, word_texts, "rec_aisin_train_202212")

```

**透视变换示例：**

```python
def crop_text_region(image, points):
    # points: [[x1,y1], [x2,y2], [x3,y3], [x4,y4]]
    # 目标：变为标准矩形文字图片

    # 计算目标矩形大小
    width = max(distance(points[0], points[1]), distance(points[2], points[3]))
    height = max(distance(points[1], points[2]), distance(points[3], points[0]))

    # 透视变换矩阵
    src_points = np.array(points, dtype=np.float32)
    dst_points = np.array([[0,0], [width,0], [width,height], [0,height]], dtype=np.float32)

    M = cv2.getPerspectiveTransform(src_points, dst_points)
    cropped = cv2.warpPerspective(image, M, (width, height))

    return cropped

```

```python
def create_character_dict():
    all_characters = set()

    # 从所有标注文件中提取字符
    for annotation_file in ["det_baseline_train.txt", "det_aisin_train.txt"]:
        with open(annotation_file) as f:
            for line in f:
                _, annotations = line.strip().split('\\t')
                for ann in json.loads(annotations):
                    text = ann["transcription"]
                    all_characters.update(list(text))

    # 添加特殊字符
    special_chars = ['blank', 'unk', '<s>', '</s>']
    character_dict = special_chars + sorted(list(all_characters))

    # 保存字典
    with open("dict.txt", "w") as f:
        for char in character_dict:
            f.write(char + "\\n")
```

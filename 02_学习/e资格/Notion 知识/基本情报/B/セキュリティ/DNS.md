# DNS

電子署名とは、電子文書の真正性を証明する技術の総称です。デジタル署名を含む広義の署名を指します。電子署名の中で公開鍵暗号方式を利用している署名が、デジタル署名です。

この問題では、送信者は１で、電子メールのデータにハッシュ関数を適用して、【ハッシュ値】を生成します。元のデータの長さによらず、ハッシュ値は一定長の文字列です。また、同一のデータから生成されるハッシュ値は常に同じです。データが １ 文字でも異なれば、生成されるハッシュ値はまったく異なるものとなります。

秘密鍵と公開鍵は、公開鍵暗号で使用する一対の鍵で、一方で暗号化すると他方で復号できる性質があります。S 社だけが持つ【秘密鍵】でハッシュ値を暗号化すると、S 社が公開する【公開鍵】で復号してハッシュ値を取り出せるので、取引先はS 社が送信したメールであると判断できます。また、 手順６ でハッシュ値の一致を確認することで、電子メールが改ざんされていないと判断できます。

実際にはこの処理は、電子署名に対応したメールソフトで自動的に行えるようになっていますので、手作業で行う必要はありません。

DNS 権威サーバに設定して管理される情報を、リソースレコード（RR）といいます。これには、以下のような種類があります。

・A レコード：ホスト名（たとえば、www）に対応する IP アドレス（たとえば、192.168.1.1）を指定します。

・MX レコード：メール受信サーバのホスト名を指定します。

・PTR レコード： IP アドレスに対応するホスト名を指定します。

管理者権限は、サーバのあらゆる設定を管理する権限です。また、シリアル番号は DNSサーバの設定値の１つです。デジタル証明書は、サーバやクライアントが真正なものであることを示すために付与される電子的な証明書です。

この問題は、攻撃者が DNS ソフトウェアの脆弱性を突いて【管理者権限】を奪取し（管理者としてログインし）、 【A レコード】を不正に書き換えました。その結果、自社の Web サイトの URL を入力したにもかかわらず、マルウェア（不正プログラム）が仕込まれた外部の Web サーバにアクセスさせられたものです。

DMZ（DeMilitarized Zone：非武装ゾーン）とは、公開ネットワークからのパケットの通過を制御することで、社内ネットの安全性を高める仕組みです。Web サーバ、および DNS サーバ１が攻撃を受けても、社内に侵入することはありません。

DNS （Domain Name System）とは、クライアント（PCなど）から依頼を受けて、ホスト名に対応する IP アドレスを回答する（名前解決する）仕組みで、「名前解決したホスト名の情報を保持しておく機能」とは、キャッシュに情報を保持する機能です。

キャッシュにある IP アドレスを不正に書き換えて、クライアントを不正なサイトにアクセスさせる攻撃を、DNS キャッシュポイズニング攻撃といいます。この問題の場合、ある Web サイトの URL を正しく入力したにもかかわらず、見覚えのない不審なサイトが表示されたのは、 DNS キャッシュポイズニング攻撃と考えられます。しばらくたつと正しい内容が表示されたのは、 DNS サーバ２ のキャッシュの保持期限が過ぎて削除されたためです。

A. 正しい。

B. DNS フラッド攻撃とは、ウイルスに乗っ取られた多数のホスト（PC など）を操って、DNS サーバに大量の名前解決のリクエストを送りつけ、負荷をかけて正常に利用できないようにする攻撃です。

C. DNS 水責め攻撃とは、DNS サーバに存在しないサブドメインの名前解決のリクエストを大量に送りつけ、負荷をかけて正常に利用できないようにする攻撃です。

D. DNS リフレクションとは、送信元 IP アドレスを攻撃先ホストのものに偽装して、DNSの問い合わせパケットを多数の DNS サーバに送りつけ、その応答がいっせいに返ってくるよう仕向けることで、攻撃先ホストの負荷を上昇させて利用できなくする攻撃です。

共連れとは、１人の社員が IC カードをかざして解錠したときに、居合わせた別の社員が IC カードを使用せずに一緒に出入りすることです。ピギーバックともよばれます。共連れで入退室した社員は、入退室の記録が残らないという問題があります。

アンチパスバックとは、 IC カードで入室と退室を交互に行わないと、解錠できなくすることです。 IC カードをかざして入室した後、だれかと一緒に IC カードを使わずに共連れで退室すると、退室の記録が残らないため、次に IC カードをかざして入室しようとしても、解錠されません。逆に、 IC カードを使わずに共連れで入室すると、入室の記録が残らないため、次に IC カードで退室しようとしても、解錠されません。これによって、共連れ防止の対策となります。ただし、共連れで続けて入室と退室をすることは、防ぎきれません。

A. アンチパスバックの導入で解決できる可能性があります。正しい。

B. アンチパスバックとは関係ありません。この問題点は、オンデマンドプリントの導入で解決できる可能性があります。オンデマンドプリントとは、PC から印刷指示をしても即座には印刷されず、本人がプリンタに IC カードをかざすなどの操作をすると印刷が始まる仕組みです。

C. アンチパスバックとは関係ありません。この問題点は、作業室への鞄の持ち込みを禁止して、ロッカーに入れるルールにすることで解決できる可能性があります。

D.. アンチパスバックとは関係ありません。この問題点は、書類や印刷物を片付けてから帰宅するように周知徹底することで解決できる可能性があります。

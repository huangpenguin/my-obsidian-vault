# 只接受关键字参数的函数(キーワード専用引数)

将强制关键字参数放到某个*参数或者单个*后面就能达到这种效果。

```python
**def** recv(maxsize, *, block):
    'Receives a message'
    **pass**
recv(1024, True) *# TypeError    *表示所有的位置参数的结束，所以此处block是关键词参数*
recv(1024, block=True) *# Ok*
```

```python
def anyargs(*args,a, **kwargs):
    print(args) # A tuple
    print(kwargs) # A dict

anyargs(1,2,3,4,a=9,b=10)
```

```python
def print_data(data,*,start=0,end=100):
    for value in (data[start:end]):
        print(value)

data=[1,2,3,4,5]
print_data(data)
print('\n')
print_data(data,start=4)
print('\n')
print_data(data,end=0)
```

利用上述的写法可以在接受完任意个数的位置参数后仍获取关键词参数

```python
def minimum(*values, clip=None):
    m = min(values)
    if clip is not None:
        m = clip if clip > m else m
    return m

minimum(1, 5, 2, -5, 10) # Returns -5
minimum(1, 5, 2, -5, 10, clip=0) # Returns 0
```

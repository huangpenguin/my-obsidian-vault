# 矩阵切片的变量对齐问题

对于Python和MATLAB的矩阵index的问题，如果index是变量并且在循环控制语句中，那么变量不必纠结+1问题，形式上保持一致，然后在变量的范围（一般是for循环处）处理一下取值即可。

比如
for k in range(a)啥的

只需要确保k范围对上即可以

但是对于直接访问的，非变量、非循环等情况，则需要按照python里面表达的意思，对matlab代码进行修正。

比如

array[a]=1

array(a-1)=1;

保持a的值不变的话则需要对括号里面做-1处理

silce代码举例

只有起点不一样而已

```python
self.RthY1[lf_limit:n_] = self.a;
```

```matlab
obj.RthY1(lf_limit+1:n_) = obj.a
```

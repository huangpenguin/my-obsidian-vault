# 搜索

## ✅ 最推荐：`find` 命令

### 1️⃣ 如果你大概知道它在某个目录下，比如 `/mnt`：

```bash

find /datadrive/workspace/2021.aisin-tray-recognition -type d -name "aisin_dict.txt" 2>/dev/null

```

---

### 2️⃣ 如果你完全不知道在哪：

```bash
sudo find / -type d -name "2021.aisin-tray-recognition" 2>/dev/null

```

- 加了 `sudo` 可以查找更多目录
- `2>/dev/null` 会隐藏权限错误的提示，结果更清爽

---

## ✅ 更快的方法（如果你愿意安装一次）

### 安装 `mlocate`：

```bash

sudo apt update
sudo apt install mlocate

```

### 初始化数据库（只需一次）：

```bash

sudo updatedb

```

### 搜索目录：

```bash

locate 2021.aisin-tray-recognition | grep -E '/2021\.aisin-tray-recognition/?$'

```

这个方式非常快（几秒钟内），适合经常需要搜索的用户。

---

## ✅ 补充技巧：只看目录路径（不看文件）

如果你用 `locate` 找出的结果中夹杂了很多文件，而你只关心目录，可以加一层过滤：

```bash

locate 2021.aisin-tray-recognition | while read line; do [ -d "$line" ] && echo "$line";done

```

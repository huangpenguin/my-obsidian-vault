# magic method/Dunder Methods

[**_ _ main _ _**](_%20_%20main%20_%20_.md)

---

在Python中，**带有下划线的方法或函数**通常被称为魔术方法"（Magic Methods）**或**"双下方法"（Dunder Methods）。它们用于实现类的特殊行为（如运算符重载、对象初始化等）。对于经常使用Python进行开发或调包的人来说，了解这些方法非常重要，因为它们能帮助你更好地理解和使用第三方库，甚至自定义类的行为。

以下是**你需要重点掌握的双下方法**，按用途分类：

---

### 1️⃣ **对象生命周期相关**

| **方法名** | **作用** |
| --- | --- |
| `__init__(self, ...)` | 对象初始化时调用（构造函数） |
| `__del__(self)` | 对象销毁时调用（析构函数） |
| `__new__(cls, ...)` | 创建对象时调用（通常用于不可变类型或单例模式） |

[**对象生命周期** 和 **类的构造函数**](%E5%AF%B9%E8%B1%A1%E7%94%9F%E5%91%BD%E5%91%A8%E6%9C%9F%20%E5%92%8C%20%E7%B1%BB%E7%9A%84%E6%9E%84%E9%80%A0%E5%87%BD%E6%95%B0/%E7%B4%A2%E5%BC%95.md)

---

### 2️⃣ **字符串表示相关**

| **方法名** | **作用** |
| --- | --- |
| `__str__(self)` | 定义 `str(obj)` 或 `print(obj)` 时的输出 |
| `__repr__(self)` | 定义 `repr(obj)` 或交互式环境中的输出（通常用于调试） |
| `__format__(self, format_spec)` | 定义 `format(obj, format_spec)` 的行为 |

---

### 3️⃣ **比较运算符相关(operator overloading)**

| **方法名** | **作用** |
| --- | --- |
| `__eq__(self, other)` | 定义 `==` 的行为 |
| `__ne__(self, other)` | 定义 `!=` 的行为 |
| `__lt__(self, other)` | 定义 `<` 的行为 |
| `__le__(self, other)` | 定义 `<=` 的行为 |
| `__gt__(self, other)` | 定义 `>` 的行为 |
| `__ge__(self, other)` | 定义 `>=` 的行为 |

---

### 4️⃣ **算术运算符相关(operator overloading)**

| **方法名** | **作用** |
| --- | --- |
| `__add__(self, other)` | 定义 `+` 的行为 |
| `__sub__(self, other)` | 定义 `-` 的行为 |
| `__mul__(self, other)` | 定义 `*` 的行为 |
| `__truediv__(self, other)` | 定义 `/` 的行为（真除法） |
| `__floordiv__(self, other)` | 定义 `//` 的行为（地板除法） |
| `__mod__(self, other)` | 定义 `%` 的行为 |
| `__pow__(self, other)` | 定义 `**` 的行为 |

---

### 5️⃣ **容器类型相关**

| **方法名** | **作用** |
| --- | --- |
| `__len__(self)` | 定义 `len(obj)` 的行为 |
| `__getitem__(self, key)` | 定义 `obj[key]` 的行为（支持索引或键访问） |
| `__setitem__(self, key, value)` | 定义 `obj[key] = value` 的行为 |
| `__delitem__(self, key)` | 定义 `del obj[key]` 的行为 |
| `__contains__(self, item)` | 定义 `item in obj` 的行为 |
| `__iter__(self)` | 定义迭代器行为（支持 `for` 循环） |
| `__next__(self)` | 定义迭代器的下一个值 |

---

### 6️⃣ **上下文管理相关**

| **方法名** | **作用** |
| --- | --- |
| `__enter__(self)` | 定义 `with` 语句进入时的行为 |
| `__exit__(self, exc_type, exc_val, exc_tb)` | 定义 `with` 语句退出时的行为（用于资源清理） |

---

### 7️⃣ **属性访问相关**

| **方法名** | **作用** |
| --- | --- |
| `__getattr__(self, name)` | 当访问不存在的属性时调用 |
| `__setattr__(self, name, value)` | 当设置属性时调用 |
| `__delattr__(self, name)` | 当删除属性时调用 |
| `__getattribute__(self, name)` | 访问任何属性时调用（优先级高于 `__getattr__`） |

---

### 8️⃣ **调用对象相关**

| **方法名** | **作用** |
| --- | --- |
| `__call__(self, ...)` | 定义 `obj(...)` 的行为（使对象可像函数一样调用） |

---

### 9️⃣ **其他常用方法**

| **方法名** | **作用** |
| --- | --- |
| `__hash__(self)` | 定义 `hash(obj)` 的行为（用于字典键或集合元素） |
| `__bool__(self)` | 定义 `bool(obj)` 的行为 |
| `__getstate__(self)` | 定义对象序列化时的行为 |
| `__setstate__(self, state)` | 定义对象反序列化时的行为 |

---

### 🔟 **实际应用场景**

1. **自定义类**：通过实现双下方法，使你的类支持运算符、迭代、上下文管理等。
2. **理解第三方库**：许多库（如NumPy、Pandas）大量使用双下方法实现高级功能。
3. **调试与扩展**：了解这些方法有助于调试和扩展现有代码。

---

### 示例代码

```
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)  # 输出: Vector(4, 6)
```

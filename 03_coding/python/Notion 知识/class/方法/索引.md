# 方法

- instance method    最常见的
- class method   使用@classmethod修饰，对整个class和object影响
- static method   使用@staticmethod修饰，不影响object和class，不需要self/cls等参数，在实例化之前就可以使用的方法

调用 `x.f()` 其实就相当于 `MyClass.f(x)`

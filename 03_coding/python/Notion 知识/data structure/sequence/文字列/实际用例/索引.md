# 实际用例

```python
#slice切片操作
用语解释:
offset:其实就是python index(序数-1)，也就是添字的数字，对于第1个数，offset是0

string="abcdefghijklmnopqrstuvwxyz"

string[:]#取出所有
string[start:]#取出从offsetstart开始的所有值
string[:end]#取出到end-1的offset为止的所有值。也就是不包括end
string[start:end:step]#包含start不包含end

string[-3:]#取出最后3个
string[-6:-3]#取出倒数第6到倒数第4

string[::7]#开头到最后（不包含）每隔7个取出
string[14::3]#offset14开始到最后为止,包含最后一个,每隔3个取出

#反向遍历
string[-1:-1]#从最后一个开始
string[::-1]#同上

#如果数的时候超过了范围就会取到能取的地方为止，不会报错
string[-50:]#从第一个开始
string[-50:-49]#空
string[:70]#到最后为止
```

```python
#split();join()
len(string)#函数

string.split(",")#classのメソッド、文字列専用

a_list=['yeti','bigfoot','loch ness monster']
a_string=','.join(a_list)
print(a_list)#这都是类方法，没有修改原来的值
print(a_string)

```

`join` 方法的语法是 `separator.join(iterable)`，其中 `separator` 是用来分隔每个元素的字符串，而 `iterable` 是要被连接的可迭代对象（例如列表、元组等）。

```python
#replace()

setup="a duck goes into a bar, the other duck goes into a toilet"
print(setup.replace('duck','dumpling',2))#置换两个
print(setup)#此处也没有覆写原来的值

setup.replace('a ','a famous ')
setup.replace('a','a famous')
```

```python

# strip()

world='''\tearth 1232\t\n'''#"\s\tearch 1232\t\n"
print(world.strip())#啥参数都不用是去掉两头的所有空白文字（'\t','','\n'），注意是去掉两头的所以中间会留下来
print(world.lstrip())
print(world.rstrip())
print(world.strip(' '))#\s
print(world.strip('  '))#\s\s
print(world.strip('\t'))#\t
print(world.strip('\n'))
print(world.strip(','))
print(world.strip('!'))

blurt="what the！ ...!!?"
print(blurt.strip('.?!'))#有多个参数都筛，但是文字列中间的标点不会拆
print(blurt.strip(string.whitespace+string.punctulation))#清除所有锚点和空格字符
```

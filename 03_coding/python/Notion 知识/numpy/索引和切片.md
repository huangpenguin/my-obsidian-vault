# 索引和切片

- 索引：
    
    ```
    arr = np.array([1, 2, 3, 4])
    print(arr[2])  # 输出: 3
    ```
    
- 切片：
    
    ```
    print(arr[1:3])  # 输出: [2 3]
    ```
    
- 多维数组索引：
    
    ```
    arr = np.array([[1, 2, 3], [4, 5, 6]])
    print(arr[1, 2])  # 输出: 6
    ```
    
- 布尔索引：
    
    ```
    arr = np.array([1, 2, 3, 4])
    print(arr[arr > 2])  # 输出: [3 4]
    ```

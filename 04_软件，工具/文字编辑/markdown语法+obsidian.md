# 🚀 Obsidian & Markdown 终极语法速查表

## ✨ 一、 Obsidian 专属“魔法”语法

这些是 Obsidian 远超普通 Markdown 软件的核心杀手锏功能。

### 1. 链接与知识网络
*   **双向链接**：`[[页面名称]]`。输入两个左方括号，自动搜索并链接库中的其他笔记页面。
*   **块链接 (精准到段落)**：`[[页面名称^]]`。在链接名称后加上 `^`，可直接定位并链接到某篇笔记里的具体段落。
*   **层级标签**：`#技术/前端/React`。井号紧跟文字，中间不能有空格，支持用 `/` 创建嵌套层级。

### 2. 高亮文字
觉得加粗不够显眼？用两个等号包围文字即可：`==非常非常重要==`。

### 3. Callouts (彩色标注块)
用于高亮显示重要的提示或警告。在大于号 `>` 后加空格和 `[!类型]`。

> [!info] 这是一个 Info 块
> 适合补充背景信息，背景为蓝色。
> 常用类型替换词：`note`(笔记) | `tip`(技巧,绿) | `warning`(警告,橙) | `bug`(报错,红) | `question`(问题)

**进阶：可折叠标注**
在方括号后加 `-`（默认折叠）或 `+`（默认展开）。
> [!example]- 点击展开查看代码
> 这里是被折叠起来的内容，点击标题才会滑下显示。

## ⌨️ 二、 基础排版 (肌肉记忆)

一旦习惯了以下符号，排版速度极快，完全不需要动鼠标。

### 1. 文本装饰
| 效果 | 语法结构 | 示例 |
| :--- | :--- | :--- |
| **加粗** | `**文字**` | **重要内容** |
| *斜体* | `*文字*` | *专有名词* |
| ***粗斜体*** | `***文字***` | ***极其重要*** |
| ~~删除线~~ | `~~文字~~` | ~~作废内容~~ |

### 2. 标题与段落
*   **标题**：使用 `#` 加空格表示，数量代表层级（`# 一级` 到 `###### 六级`）。
*   **换段**：段落之间必须留一个**空行**。
*   **换行(不换段)**：在上一行末尾敲**两个空格**再回车。
*   **分割线**：连敲三个减号 `---` 并回车。（**注意**：在笔记最顶部敲是唤出 YAML 属性面板，在正文里敲才是分割线）。

### 3. 列表与待办
*   **无序列表**：`- ` 或 `* ` (符号+空格)。按 `Tab` 缩进为子项目。
*   **有序列表**：`1. ` (数字+点+空格)。
*   **待办事项 (Task)**：`- [ ] ` (方括号中间有空格)。
*   **已完成任务**：`- [x] `。在 Obsidian 中可直接用鼠标点击打勾。

## 💻 三、 引用、代码与多媒体

### 1. 代码展示
*   **行内代码**：用单个反引号包围，例如标记函数名 `useState`。
*   **多行代码块**：用三个反引号包围，第一行末尾可写明语言类型以开启高亮。
```python
# 这是一个 Python 代码块
print("Hello Obsidian!")
```
### 2. 网页链接与图片

- **基础链接**：`[显示文本](URL)` -> `[访问百度](https://www.baidu.com)`
    
- **带悬停标题的链接**：`[文本](URL "标题")`
    
- **插入图片**：在链接前加感叹号 `![图片说明](图片URL)`
    

### 3. 引用与注释

- **普通引用区块**：段落开头使用 `>` 加空格。
    
- **隐藏注释**：`<!-- 仅源码可见，预览模式下隐藏 -->`。

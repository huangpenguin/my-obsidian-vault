# 可调用对象

在 Python 中，函数的名字本质上是一个引用指向一个可调用对象。可调用对象是任何可以使用括号 `()` 进行调用的对象。除了普通函数外，其他类型的对象也可以是可调用的，只要它们实现了特殊方法 `__call__()`。

### 可调用对象的类型

1. **普通函数**: 由 `def` 关键字定义的函数。
    
    ```python
    def f(x):
        return x * 2
    
    print(f(5))  # 输出: 10
    
    ```
    
2. **内置函数**: 由 Python 内置提供的函数，例如 `int`、`len` 等。
    
    ```python
    print(int('123'))  # 输出: 123
    
    ```
    
3. **匿名函数（lambda 表达式）**: 由 `lambda` 关键字定义的短小函数。
    
    ```python
    g = lambda x: x + 1
    print(g(5))  # 输出: 6
    
    ```
    
4. **类实例**: 如果一个类实现了 `__call__()` 方法，那么它的实例也是可调用的。
    
    ```python
    class Adder:
        def __init__(self, n):
            self.n = n
    
        def __call__(self, x):
            return x + self.n
    
    add5 = Adder(5)
    print(add5(10))  # 输出: 15
    
    ```
    

### 函数名是引用

在 Python 中，函数名实际上是一个指向函数对象的引用。这意味着你可以将函数赋值给其他变量，或者将它们存储在数据结构中。

```python
def my_function():
    print("Hello, World!")

# 函数名是引用
f = my_function
f()  # 输出: Hello, World!

# 存储在列表中
functions = [my_function, f]
functions[0]()  # 输出: Hello, World!
functions[1]()  # 输出: Hello, World!

```

### 检查对象是否可调用

可以使用内置函数 `callable()` 检查一个对象是否是可调用的。

```python
print(callable(f))  # 输出: True
print(callable(42))  # 输出: False
```

### 小结

在 Python 中，函数的名字本质上是一个引用，指向一个可调用对象。除了普通函数之外，内置函数、lambda 表达式和实现了 `__call__()` 方法的类实例也是可调用对象。这种灵活性使得 Python 的函数处理非常强大和灵活

# 环境构建

---

## 推荐流程：

### 1. 先按原文档跑通项目

```bash
# 按照原文档用 conda + pip 的方式
conda create --name paddle_env python=3.9
conda activate paddle_env
pip install paddlepaddle-gpu -i <https://www.paddlepaddle.org.cn/packages/stable/cu117/>
# ... 其他依赖

```

### 2. 确认项目能正常运行后，再迁移到 uv

```bash
# 在项目根目录初始化 uv 项目
uv init

# 生成当前环境的依赖列表
pip freeze > requirements.txt

# 或者手动创建 pyproject.toml，指定具体依赖

```

### 3. 用 uv 重新创建环境

```bash
# 删除 conda 环境（可选）
conda deactivate
conda remove --name paddle_env --all

# 用 uv 创建新环境并安装依赖
uv sync
# 或
uv add paddlepaddle-gpu --index <https://www.paddlepaddle.org.cn/packages/stable/cu117/>
uv add git+https://github.com/PaddlePaddle/PaddleOCR.git@v2.10.0
# ... 其他依赖

```

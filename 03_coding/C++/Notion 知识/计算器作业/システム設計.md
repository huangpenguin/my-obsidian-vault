# システム設計

CLI電卓を実装するにあたり、以下のようなクラス設計を行います。

1. **CLIApp**: メインのアプリケーションクラス。全体の流れを管理。
2. **Parser**: 構文解析を行うクラス。
3. **Calculator**: 実際の計算を行うクラス。
4. **Memory**: ANSメモリー機能を管理するクラス。

### クラス設計

1. **CLIApp**:
    - コマンドライン引数を解析し、適切な処理を行う。
    - メインループを持ち、ユーザー入力を受け付け、解析し、実行する。
2. **Parser**:
    - 構文解析を行い、命令や計算式に関する情報を取得する。
    - エラー処理も行う。
3. **Calculator**:
    - 与えられた計算式を評価し、結果を返す。
    - 範囲外の数値や演算エラーを処理する。
4. **Memory**:
    - ANSメモリーを管理し、値の取得・設定を行う。

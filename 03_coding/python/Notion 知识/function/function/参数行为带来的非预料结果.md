# 参数行为带来的非预料结果

在 Python 中，函数默认参数的行为可能会导致一些意外的问题，尤其是当默认参数是可变类型（如列表、字典或集合）时,但是immutable的整数、字符串等不会 产生这研发的问题。让我们先解释一下为什么会出现这些问题。

### Python 中默认参数的行为

在 Python 中，default参数值是在函数定义时计算的，而不是在函数调用时计算的。这意味着如果default参数是一个可变对象（例如列表），并且该对象在函数的多次调用中被修改，那么这些修改会保留，并且在后续的调用中会使用相同的对象。

来看一个例子：

```python
def f(arg, result=[]):
    result.append(arg)
    return result

print(f(1))  # 输出: [1]
print(f(2))  # 输出: [1, 2]
print(f(3))  # 输出: [1, 2, 3]

```

在这个例子中，`result` 列表在每次调用 `f` 时都被修改，因为它引用的是同一个列表对象。因此，每次调用 `f` 时，`result` 列表都会包含之前所有的修改。

### 解决方法

为了避免这种行为，可以使用 `None` 作为默认参数，并在”函数内部”创建一个新的列表，这样就是函数调用时生成的新的list

```python
def f(arg, result=None):
    if result is None:
        result = []
    result.append(arg)
    return result

print(f(1))  # 输出: [1]
print(f(2))  # 输出: [2]
print(f(3))  # 输出: [3]
```

现在，每次调用 `f` 时，都会创建一个新的列表，因此不会受到前一次调用的影响。

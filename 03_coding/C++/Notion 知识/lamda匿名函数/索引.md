# lamda匿名函数

```cpp
int main() {
    int x = 10;
    int y = 20;

    // 按值捕获 x，按引用捕获 y
    auto lambda = [x, &y]() {
        std::cout << "x = " << x << ", y = " << y << std::endl;
    };

    x = 15;
    y = 25;

    lambda(); // 输出：x = 10, y = 25
    return 0;
}

```

- **`[x, &y]`** 是捕获列表：
    - **`x`** 按值捕获：在定义Lambda时，将外部变量 **`x`** 的当前值（10）复制到Lambda内部。此后的任何修改（如 **`x = 15`**）都不会影响Lambda内部的 **`x`**。
    - **`&y`** 按引用捕获：在定义Lambda时，将外部变量 **`y`** 的引用传递到Lambda内部。此后的任何修改（如 **`y = 30`**）都会影响Lambda内部的 **`y`**，反之亦然。

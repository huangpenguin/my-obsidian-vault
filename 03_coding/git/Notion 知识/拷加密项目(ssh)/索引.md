# 拷加密项目(ssh)

## 第一步：确认 GitHub 账号的邮箱地址

### 查看你 GitHub 登录使用的邮箱地址：

1. 登录你的 GitHub 网站账号。
2. 打开 [https://github.com/settings/emails](https://github.com/settings/emails)
3. 页面中会列出你的主邮箱地址（也可能有多个绑定邮箱）。
4. **用这个邮箱替换 `your_email@example.com`**。

---

## ✅ 第二步：生成 SSH 密钥

在你用 Git 的那台 Linux 主机（比如 `pjt-aks-huang`）运行：

```bash
ssh-keygen -t ed25519 -C "你的 GitHub 邮箱"

ssh-keygen -t ed25519 -C "6444032088[@qq.com](mailto:huangpenguin@gmail.com)"
```

你会看到提示：

```
Generating public/private ed25519 key pair.
Enter file in which to save the key (/home/你的用户名/.ssh/id_ed25519):
```

直接回车（默认路径即可）。

然后它会问你要不要设密码：

```
Enter passphrase (empty for no passphrase):
```

也可以直接回车（不设置密码）或自行设置。

最终会生成两个文件：

- `/home/你的用户名/.ssh/id_ed25519`（私钥，不能泄露）
- `/home/你的用户名/.ssh/id_ed25519.pub`（公钥）

---

## ✅ 第三步：将 SSH 公钥添加到 GitHub

先用这个命令显示你的公钥内容：

```bash
cat ~/.ssh/id_ed25519.pub
```

复制完整输出内容，例如：

```
ssh-ed25519 AAAAC3Nz...rest... your_email@example.com
```

然后去 GitHub：

1. 打开网页：[https://github.com/settings/keys](https://github.com/settings/keys)
2. 点击「**New SSH key**」
3. **Title** 随便填，比如 `aks vm key`
4. **Key** 粘贴你刚刚复制的公钥内容
5. 点击「**Add SSH key**」

---

## ✅ 第四步：测试 SSH 连接

在你的 VM 上运行：

```bash
ssh -T git@github.com
```

如果一切正常，会显示：

```

Hi huangpenguin! You've successfully authenticated, but GitHub does not provide shell access.
```

✅ 就说明 SSH 设置成功了！

如果显示：

```

penguinpp@pjt-aks-a100-80gb:~$ ssh -T git@github.com
The authenticity of host 'github.com (140.82.113.4)' can't be established.
ECDSA key fingerprint is SHA256:p2QAMXNIC1TJYWeIOttrVc98/R1BUFWu3/LiyKgUfQM.
Are you sure you want to continue connecting (yes/no/[fingerprint])?

```

说明第一次使用github

## ✅ 第五步：用 SSH 地址来克隆项目

```bash

git clone git@github.com:emuni-kyoto/pjt_aks.git

```

这时候就不会提示输入用户名或密码了。

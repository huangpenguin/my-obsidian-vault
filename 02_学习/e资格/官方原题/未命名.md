获取方法
### 网络抓包“釜底抽薪”（拿到最原始文件）

如果上面通过前端操作的办法都被防住了，那我们直接去拿它的网络传输源文件：

1. 打开开发者工具（F12），切换到 **“网络 (Network)”** 标签。
    
2. 在过滤分类里，不要选全部，**只点选 `Fetch/XHR`**。
    
3. 保持这个面板打开，**按 F5 刷新整个网页**。
    
4. 网站加载题目的过程中，会在这里出现几条请求。你点击面板里的 **`大小 (Size)`** 表头，让文件从大到小排序。
    
5. 那个排在第一、体积最大（通常在几百 KB 到几 MB，可能没有 `.pdf` 后缀）的数据流，就是被 JS 抽取的 PDF 本体。
    
6. 右键点击它 -> **在新标签页中打开 (Open in new tab)**。浏览器会识别出它的真实身份，并让你下载。

### 用 Mac 终端（Terminal）强行下载

1. **回到开发者工具的 Network（网络）面板：** 找到刚才那个你点开会报 403 的、体积最大的请求流。
    
2. **复制带“身份证明”的完整请求：** 在这个请求上点击 **右键** -> 找到 **“复制” (Copy)** -> 选择 **“复制为 cURL” (Copy as cURL)**。 _(注意：如果你用的是 Chrome，选 `Copy as cURL`; 如果是 Safari，叫 `Copy as cURL`; Firefox 也是类似的。这会把所有复杂的头部信息全部复制进你的剪贴板。)_
    
3. **打开 Mac 的终端 (Terminal)：** 按 `Cmd + 空格` 呼出聚焦搜索，输入 `Terminal`（终端）并回车打开。
    
4. **粘贴并修改命令：** 在终端里把你刚才复制的那一大串东西 **粘贴** 进去。（这串命令可能会非常长，不用管它）。 **⚠️ 别急着按回车！** 在这串命令的最末尾，先敲一个**空格**，然后加上这行代码：
    
    Bash
    
    ```
    --output target.pdf
    ```

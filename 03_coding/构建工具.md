# Makefile

配合这个Makefile文件可以实现自动的ruff和mypy检查

```
.PHONY: check ruff mypy run help

help:
	@echo "Available commands:"
	@echo "  make run    - Run the application"
	@echo "  make check  - Run ruff check and mypy"
	@echo "  make ruff   - Run ruff check only"
	@echo "  make mypy   - Run mypy only"

check: ruff mypy

ruff:
	@echo "Running ruff check..."
	uv run ruff check src/ app/ main.py

mypy:
	@echo "Running mypy..."
	uv run mypy src/ app/ main.py

run:
	@echo "Starting application..."
	uv run python main.py
```

# pathlib explaination

# pathlib 是什么

`pathlib` 是用于处理文件路径的 Python 标准库。
使用 `pathlib`，可以将文件路径作为对象进行操作，而不是仅仅作为字符串处理。

## 为什么不用 os.path？

与 `os.path` 相比，`pathlib` 具有以下优点：

### 1. 丰富的方法

`pathlib` 将文件路径作为对象，可以执行各种操作，提供了更丰富的 API。

### 2. 处理跨平台的路径分隔符

`pathlib` 自动处理不同操作系统的路径分隔符，例如：

- 在 Windows 上，使用 `\`
- 在 Linux/Unix 上，使用 `/`

使用 `pathlib`，可以编写在不同系统上都能运行的代码。

### 3. 更简单的路径拼接

`pathlib` 允许使用 `/` 运算符拼接路径。例如：

```python
from pathlib import Path

path = Path("/home/user") / "test.txt"
print(path)  # /home/user/test.txt

```

---

# 主要类

`pathlib` 中的类结构如下：

## PurePath

- 提供与操作系统无关的通用路径操作。
- 可执行路径解析、拼接、拆分等基本操作。

### PureWindowsPath

- 继承自 `PurePath`
- 专为 Windows 系统提供路径操作。

### PurePosixPath

- 继承自 `PurePath`
- 专为 Unix/Linux 系统提供路径操作。

## Path（核心类）

- 继承自 `PurePath`
- 增加了文件系统操作能力。
- 根据操作系统自动生成 `WindowsPath` 或 `PosixPath` 实例。

### WindowsPath

- 继承自 `Path`
- 适用于 Windows 平台，不能直接实例化。

### PosixPath

- 继承自 `Path`
- 适用于 Unix/Linux 平台，不能直接实例化。

# pathlib 基本用法

## 生成路径

```python
from pathlib import Path

# 绝对路径
path = Path("/home/user/test.txt")

# 拼接路径
path = Path("/home", "user", "test.txt")  # /home/user/test.txt

# 注意：多个绝对路径拼接时，前面的路径会被忽略
path = Path("/home", "/user", "test.txt")  # /user/test.txt

# 相对路径
path = Path("test.txt")

# 获取当前目录
path = Path.cwd()

```

## 路径拼接

使用 `/` 运算符拼接路径：

```python
from pathlib import Path

path = Path("/home/user") / "test.txt"
print(path)  # /home/user/test.txt

```

等效于：

```python
path = Path("/home/user").joinpath("test.txt")

```

---

## 路径拆分

```python
from pathlib import Path

path = Path("/home/user/test.txt")
print(path.parent)  # /home/user
print(path.name)    # test.txt
print(path.stem)    # test
print(path.suffix)  # .txt

```

获取多个扩展名：

```python
tar_gz = Path("/home/user/test.tar.gz")
print(tar_gz.suffixes)  # ['.tar', '.gz']
print("".join(tar_gz.suffixes))  # .tar.gz

```

---

## 路径存在性检查

```python
from pathlib import Path

path = Path("/home/user/test.txt")
print(path.exists())  # 检查路径是否存在
print(path.is_file())  # 检查是否为文件
print(path.is_dir())   # 检查是否为目录

```

---

## 绝对路径与相对路径转换

[absolute path and relative path](absolute%20path%20and%20relative%20path.md)

```python
from pathlib import Path

# 绝对路径 -> 相对路径
abspath = Path("/home/user/test.txt")
print(abspath.relative_to("/home"))  # user/test.txt

# 相对路径 -> 绝对路径
relpath = Path("user/test.txt")
print(relpath.absolute())

# 规范化路径
print(Path("user/../test.txt").resolve())  # /home/test.txt

```

---

## 路径操作

```python
from pathlib import Path

path = Path("/home/user/test.txt")
path.rename("/home/user/test2.txt")  # 重命名
path.replace("/home/user/test2.txt")  # 覆盖重命名
path.mkdir(parents=True)  # 创建目录（包括父目录）
path.rmdir()  # 删除目录

```

---

## 文件操作

```python
from pathlib import Path

path = Path("/home/user/test.txt")

# 读取文件
print(path.read_text())

# 写入文件
path.write_text("Hello World!")

# 删除文件
path.unlink()

```

JSON 处理示例：

```python
from pathlib import Path
import json

path = Path("/home/user/test.json")
data = json.loads(path.read_text())
path.write_text(json.dumps(data))

```

---

## 获取文件信息

```python
from pathlib import Path

fpath = Path("/home/user/test.txt")
print(fpath.stat().st_size)  # 文件大小
print(fpath.stat().st_mtime)  # 修改时间
print(fpath.stat().st_ctime)  # 创建时间

```

获取目录内容：

```python
dpath = Path("/home/user")
print(list(dpath.iterdir()))  # 获取目录下的文件和子目录
print(list(dpath.glob("**/*")))  # 递归获取所有文件
print(list(dpath.glob("**/*.txt")))  # 获取所有.txt 文件

```

---

这样，`pathlib` 让路径操作变得更简单、直观、跨平台。

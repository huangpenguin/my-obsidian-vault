# vm分离旧磁盘，挂载新磁盘(实现换系统)

## 答案是：**可以更换系统盘，不用换 VM 实例。**

你可以在 GCP 中**创建新的 Ubuntu 系统盘**，然后**替换现有 VM 的启动盘**，实现“不换实例，只换系统”的目的。

---

## 🛠️ 操作步骤详解（保留 VM，替换为 Ubuntu 系统）：

### ✅ 前提说明：

- 假设你当前 VM 实例是 `vm-debian`，系统是 Debian，系统盘为 `disk-debian`。
- 你想保留 VM 本身（IP 不变、设置不变），但把系统盘换成 Ubuntu 系统盘。

---

### 📌 步骤 1：准备新系统盘（Ubuntu）

1. 打开 GCP 控制台 → **「磁盘」** 页面。
2. 点击「创建磁盘」：
    - 名称：如 `ubuntu-disk`
    - 地区/区域：与你现有 VM 相同
    - 来源类型：**公共镜像**
    - 操作系统：选择 Ubuntu（如 Ubuntu 22.04 LTS）
    - 大小：你可以自定义，比如 20 GB、50 GB 等
3. 创建完后记下这个磁盘名。

---

### 📌 步骤 2：停止现有 VM

1. 回到 VM 实例页面，找到你当前的实例（如 `vm-debian`）。
2. 点击「停止」。

---

### 📌 步骤 3：**卸下旧系统盘**

1. 进入该实例的详情页面 → 点击「编辑」。
2. 找到「启动磁盘」部分，点击「分离启动磁盘」或「更换」。
3. 移除旧的系统盘（不要删除磁盘，如果你还想保留原数据的话）。

---

### 📌 步骤 4：**挂载新的 Ubuntu 系统盘作为启动盘**

1. 在同一页面中，点击「附加磁盘」。
2. 选择你刚创建的 `ubuntu-disk`。
3. 设置为「**引导磁盘**」（Boot Disk）。
4. 保存更改。

---

### 📌 步骤 5：启动 VM

1. 回到实例列表，重新启动这个 VM。
2. 此时它将从新的 Ubuntu 系统盘启动。

---

### ✅ 结果：

- VM 实例的 **IP 不变**，**配置不变**，**名称不变**。
- 系统已经从 Debian → Ubuntu。
- 你原来的旧系统盘（`disk-debian`）依然存在，**可挂载回来提取文件**。

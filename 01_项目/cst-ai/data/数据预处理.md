## 1. 旋转：空缺从哪来、怎么填

实现见 `rotate_u16_cw`：

cylinderblock_tiff_io.pyLines 214-234

def rotate_u16_cw(

arr: np.ndarray,

degrees_cw: float,

*,

edge_mode: str = "nearest",

) -> np.ndarray:

...

rotated = rotate(

arr.astype(np.float32),

-degrees_cw,

reshape=False,

order=1,

mode=edge_mode,

)

要点：

|参数|含义|
|---|---|
|`-degrees_cw`|`scipy.ndimage.rotate` 默认逆时针为正，所以要取负才能实现顺时针|
|`reshape=False`|输出仍是 1280×1280，不扩大画布|
|`order=1`|双线性插值（旋转后非整数坐标处的像素由周围 4 点加权）|
|`mode="nearest"`|越界采样用最近的有效像素填充|

空缺怎么产生：`reshape=False` 时，输出每个像素对应原图上的一个采样点（逆旋转后的坐标）。正方形转一个非 90° 角后，画布四角会落到原图范围之外——这些就是“空缺”。

以前的问题：`mode="constant", cval=0` 会把空缺填成 0（纯黑），和 CT 圆盘外的灰底不一致，四角会出现黑三角。

现在的填法：`mode="nearest"` 不引入新颜色，越界时取离边界最近的原图像素。四角会延续边缘灰度，看起来仍是灰底，而不是黑边。

注意：这是 scipy 在采样阶段的边界处理，不是先算多边形再手工填色；具体每个输出像素由逆变换 + 插值 + 边界模式共同决定。

## 2. 放缩（resize）

cylinderblock_tiff_io.pyLines 237-255

def resize_u16(...):

zoom_h = target_height / arr.shape[0]

zoom_w = target_width / arr.shape[1]

resized = zoom(

arr.astype(np.float32),

(zoom_h, zoom_w),

order=1,

mode=edge_mode,

)

- 输入：旋转后的 1280×1280
- 目标：1530×1530
- 比例：`1530/1280 ≈ 1.195`（宽高同比例放大）
- `order=1`：双线性插值
- `edge_mode="nearest"`：若采样点越界，同样用最近边界像素

这样 LQ 与 GT 同尺寸，训练时 pixel-wise loss 可直接对齐。代价是约 19.5% 的放大带来轻微模糊，但避免了 padding 黑边或裁 GT 丢外围。

`PairRecord.lq_scale` 记录的就是这个比例（`1530/1280`），写在 `manifest.csv` 和 `normalization.json` 里。

当一个类定义了 [`__init__()`](https://docs.python.org/zh-cn/3.12/reference/datamodel.html#object.__init__) 方法时，类的实例化会自动为新创建的类实例发起调用 `__init__()`。 因此在这个例子中，可以通过以下语句获得一个已初始化的新实例:

`x = MyClass()`

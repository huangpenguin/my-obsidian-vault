# network

你提到的“WiFi的地址”，可能指的是**路由器的IP地址**（通常是局域网的网关IP），这个地址通常类似于 `192.168.1.1`，它是路由器在本地网络中的IP地址。使用路由器的IP地址不适用于你当前的需求，原因如下：

### 1. **路由器的IP地址并不是设备的IP地址**

路由器的IP地址只是本地网络（局域网）的网关IP，所有设备通过这个路由器连接到互联网或其他局域网设备。你不能使用这个IP地址来直接进行设备间的通信，因为它代表的是网络的入口，而不是每个具体设备本身。

- PC 和智能手表都是连接在同一个WiFi网络下的独立设备，它们在同一个局域网中共享这个网络，但它们都有各自的**局域网IP地址**。
- 设备之间的通信必须通过每个设备的唯一局域网IP地址进行，而不是通过路由器的IP地址。路由器只是负责将网络请求路由到对应的设备。

### 2. **设备间通信需要使用每个设备的局域网IP**

在局域网中，每个连接到网络的设备都会从路由器分配到一个唯一的IP地址（例如`192.168.x.x`这样的地址）。这就是为什么：

- **PC** 作为服务器，要监听它自己在局域网中的IP地址。这样当其他设备（比如手表）想要连接到它时，可以知道要连接到哪里。
- **智能手表** 作为客户端，必须知道PC的IP地址，才能通过该地址找到并连接到PC上的服务。

### 3. **路由器的IP地址只用于网络的配置和管理**

路由器的IP地址通常用于网络的配置，比如访问路由器的设置界面（例如在浏览器中输入 `192.168.1.1`）。这个地址通常不会参与设备间的直接通信。你可以把它理解为是网络的“管理者”，它负责设备之间的通信流转，而不是直接参与通信。

### 举个例子：

假设你家中有多个设备连在同一个WiFi网络下：

- 路由器的IP地址可能是 `192.168.1.1`。
- 你的PC可能分配到 `192.168.1.100`。
- 你的智能手表可能分配到 `192.168.1.101`。

如果你想让手表与PC通信：

- 手表必须知道PC的IP地址，才能与它进行数据交换。
- PC也要监听它自己的局域网IP地址（`192.168.1.100`），这样手表才能找到并连接到它。

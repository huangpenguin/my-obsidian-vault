# GCP  VM環境のセットアップ

## 背景

GCP上でVMの環境をセットアップするためのメモ

## 事前準備

### gcloud CLIをインストールする

- https://cloud.google.com/sdk/docs/install?hl=ja

以下で問題なく連携できているかを確認し、該当のプロジェクトを選択

```bash
$ gcloud projects list
$ gcloud config set project pjt-lx
```

### インスタンスを作成し通常のssh接続を確認

GCP上でVMインスタンスを作成し、以下のようなコマンドで接続

```bash
$ gcloud compute ssh {インスタンス名} --project={プロジェクト名} --zone={ゾーン名}

# （例）gcloud compute ssh instance-hogehoge --project=pjt-lx --zone=asia-northeast1-b
```

### デフォルトのファイアーウォール設定を削除し、[IAP](https://cloud.google.com/iap/docs/concepts-overview?hl=ja)を設定

よりセキュアな環境を構築する場合には以下を実施

参考：https://blog.g-gen.co.jp/entry/login-your-vm-with-iap

![Screenshot 2025-06-24 at 17.51.04.png](GCP%20VM%E7%92%B0%E5%A2%83%E3%81%AE%E3%82%BB%E3%83%83%E3%83%88%E3%82%A2%E3%83%83%E3%83%97/Screenshot_2025-06-24_at_17.51.04.png)

上記のファイヤーウォールルールを削除し、以下を作成するコマンドを実行

```bash
$ gcloud compute firewall-rules create allow-iap-ssh \
  --direction=INGRESS \
  --priority=1000 \
  --network=default \
  --action=ALLOW \
  --rules=tcp:22 \
  --source-ranges=35.235.240.0/20 \
  --target-tags=iap-accessible-vm

```

![Screenshot 2025-06-24 at 17.57.09.png](GCP%20VM%E7%92%B0%E5%A2%83%E3%81%AE%E3%82%BB%E3%83%83%E3%83%88%E3%82%A2%E3%83%83%E3%83%97/Screenshot_2025-06-24_at_17.57.09.png)

### VMにタグを追加しファイヤーウォールルールを追加しIAP経由の接続を許可する

```bash

$ gcloud compute instances add-tags {インスタンス名} \
  --zone={ゾーン名}	 \
  --tags=iap-accessible-vm

# （例）gcloud compute instances add-tags instance-hogehoge \
#  --zone=asia-northeast1-b	 \
#  --tags=iap-accessible-vm

```

インスタンスとファイヤーウォールルールが紐づけられていることを確認する

## 接続方法

### gcloud CLIをインストールする

- https://cloud.google.com/sdk/docs/install?hl=ja

以下で問題なく連携できているかを確認し、該当のプロジェクトを選択

```bash
$ gcloud projects list
$ gcloud config set project pjt-lx
```

### コマンドラインベースでIAP経由で接続する

```bash
$ gcloud compute ssh instance-20250624-081832 --project=pjt-lx --zone=asia-northeast1-b --tunnel-through-iap
```

### ssh configを設定するためパラメター確認

`--dry-run`を追加して実際に実行されているコマンドを確認する

```bash
$ gcloud compute ssh instance-20250624-081832 --project=pjt-lx --zone=asia-northeast1-b --tunnel-through-iap --dry-run
```

以下の記事を参考にセットアップ

https://tech-tech.nddhq.co.jp/2024/08/07/connect-gce-from-vscode-through-iap-on-windows/

### SSH エージェントに鍵を追加し、VM上でgithubからpullできるようにする(vscode自动调用了其实)

```bash
ssh-add ~/.ssh/id_rsa  #GitHub 用鍵
```

 VMにIAP経由で接続後以下でgithubへの接続確認

```bash
ssh -T git@github.com
```

必要に応じてpush

## その他環境設定

```bash
$ curl -LsSf https://astral.sh/uv/install.sh | sh
```

### IAM権限の設定

以下の4つの権限を付与する

- Compute OS ログイン
- IAP で保護されたトンネル ユーザー
- サービス アカウント ユーザー
- Compute インスタンス管理者（v1）

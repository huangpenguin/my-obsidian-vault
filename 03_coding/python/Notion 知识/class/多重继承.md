# 多重继承

一个子类可能有多个父类，同时有相同的方法，此时可能有‘菱形’的继承关系，此时需要指定方法解析顺序（MRO）来控制

```python
# 定义第一个基类
class Animal:
    def eat(self):
        print("Animal is eating")

# 定义第二个基类
class Flyable:
    def fly(self):
        print("Flying")
    def eat(self):
        pass
        
# 定义一个多重继承的类，继承自 Animal 和 Flyable
class Bird(Animal, Flyable):#此处定义了mro顺序
    def chirp(self):
        print("Chirping")

# 创建 Bird 类的实例
sparrow = Bird()
sparrow.eat()  # 调用从 Animal 继承的方法
sparrow.fly()  # 调用从 Flyable 继承的方法
sparrow.chirp()  # 调用 Bird 自己的方法

sparrow.mro()#查看这个类的方法解析顺序
###
一般而言解析顺序都是从自己开始->定义处的父类顺序1->定义处的父类顺序2->...->祖父辈
###
```

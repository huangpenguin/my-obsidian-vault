# 数组属性

- 获取形状：
    
    ```
    arr = np.array([[1, 2, 3], [4, 5, 6]])
    print(arr.shape)  # 输出: (2, 3)
    ```
    
- 获取维度：
    
    ```
    print(arr.ndim)  # 输出: 2
    ```
    
- 获取元素总数：
    
    ```
    print(arr.size)  # 输出: 6
    ```
    
- 获取数据类型：
    
    ```
    print(arr.dtype)  # 输出: int64
    ```

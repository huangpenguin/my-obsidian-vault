### **旧格式→新格式转换**

```python
# 文件: src/back/logics/ocr_adapter.py
class OCRFormatAdapter:
    @staticmethod
    def convert_old_to_new_format(old_results: list[dict]) -> OCRResult:
        # 1. 创建OCRResult对象
        ocr_result = OCRResult()

        # 2. 转换每个图像
        for result in old_results:
            for image_data in result.get("images", []):
                image = OCRImage()

                # 3. 转换表格
                for table_data in image_data.get("tables", []):
                    table = convert_table_format(table_data)
                    image.tables.append(table)

                # 4. 转换文本行
                for field_data in image_data.get("fields", []):
                    text_line = convert_text_line_format(field_data)
                    image.text_lines.append(text_line)

                ocr_result.images.append(image)

        return ocr_result

```

```python
class BikoExtractor:
    def extract_biko_content(self, ocr_result: OCRResult) -> tuple[str, dict]:
        # 1. 查找备考位置
        biko_positions = self._find_biko_positions(ocr_result)

        # 2. 查找包含备考的表格
        biko_tables = self._find_biko_containing_table_with_debug(ocr_result, biko_positions)

        # 3. 检查关键词
        for table in biko_tables:
            keyword_result = self._check_biko_keywords(table_texts)
            if keyword_result != "null":
                return keyword_result, debug_info

        return "null", debug_info

    def _check_biko_keywords(self, texts: list[str]) -> str:
        # 关键词映射检查
        keyword_mapping = {"分割": "B", "連結": "C", "一体型": "C"}
        all_text = " ".join(texts)

        for keyword, code in keyword_mapping.items():
            if keyword in all_text:
                return code
        return "null"

```

## 📊 数据格式转换示意图

```
PDF bytes → AWS Textract → 旧格式OCR → 新格式OCR → 备考抽取结果
    ↓           ↓              ↓           ↓            ↓
文件数据    AWS响应      list[dict]   OCRResult    (str, dict)
                                    ↓
                              可视化PNG图像

```

## 🔧 关键接口函数

1. **OCR处理**: `process_pdf_to_ocr_result(pdf_data, filename) -> list[dict]`
2. **格式转换**: `OCRFormatAdapter.convert_old_to_new_format(old_results) -> OCRResult`
3. **备考抽取**: `BikoExtractor.extract_biko_content(ocr_result) -> (str, dict)`
4. **关键词检测**: `BikoExtractor._check_biko_keywords(texts) -> str`
5. **可视化生成**: `NewBikoDebugVisualizer.create_visualization() -> PNG文件`

这个调用链确保了从原始PDF文件到最终可视化结果的完整数据流转换。

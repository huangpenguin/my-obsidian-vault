# nano

### **. 用 `nano` 打开 JSON 文件**

```
nano config.json
```

---

### **2. 基本编辑操作**

- **移动光标**：
    - 使用方向键（**`↑`** **`↓`** **`←`** **`→`**）移动光标。
    - 快速跳转：
        - **`Ctrl + →`**：跳到下一个单词。
        - **`Ctrl + ←`**：跳到上一个单词。
        - **`Alt + \`**（或 **`PgUp`**）：跳到文件开头。
        - **`Alt + /`**（或 **`PgDn`**）：跳到文件末尾。
- **修改单行内容**：
    - 直接移动光标到目标位置，删除或插入字符。
- **删除操作**：
    - **`Backspace`**：删除光标前字符。
    - **`Delete`**：删除光标后字符。
    - **`Ctrl + K`**：剪切当前行（可粘贴到其他位置）。

---

### **3. 保存并退出**

- **保存修改**：
    - **`Ctrl + O`** → 按 **`Enter`** 确认文件名。
- **退出 `nano`**：
    - **`Ctrl + X`**（如果未保存，会提示保存）。

---

### **4. 实用技巧**

### **（1）显示行号（方便定位）**

在 **`nano`** 中临时启用行号：

bash

复制

下载

```
nano -c 文件名.json
```

- 按 **`Alt + #`** 可切换行号显示。

### **（2）搜索特定内容**

- **`Ctrl + W`**：输入关键词搜索 → 按 **`Enter`** 跳转到匹配位置。
- **`Alt + W`**：重复上一次搜索。

### **（3）语法高亮（可选）**

如果 JSON 文件内容复杂，可以安装 **`nano`** 的语法高亮插件：

bash

复制

下载

```
sudo apt install nano-syntax-highlighting
```

然后重新打开文件即可看到彩色语法。

---

### **5. 示例：修改 JSON 文件**

假设文件内容如下：

json

复制

下载

```
{
  "name": "test",
  "version": "1.0",
  "port": 8080
}
```

**目标**：将 **`"port": 8080`** 改为 **`"port": 3000`**

步骤：

1. 光标移动到 **`8080`** 的位置。
2. 删除旧数字，输入 **`3000`**。
3. 按 **`Ctrl + O`** 保存，再按 **`Ctrl + X`** 退出。

---

### **注意事项**

- JSON 文件必须保持**合法格式**（如引号、逗号、缩进等），否则可能导致程序解析失败。
- 如果修改后格式混乱，可以用 **`jq`** 工具自动格式化：复制下载
    
    bash
    
    ```
    jq . 文件名.json > 临时文件.json && mv 临时文件.json 文件名.json
    ```

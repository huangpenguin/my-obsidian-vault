# 建议你把系统理解成六层

```
第6层：任务与VLA
“抓住小球”
语言、图像 → 动作策略

第5层：机器人学习框架
LeRobot、MJLab、Isaac Lab
数据集、训练、rollout、环境管理

第4层：运动规划与安全
MoveIt、MoveIt Servo
IK、碰撞检查、目标跟踪

第3层：控制器
ros2_control controllers
轨迹、位置、速度控制

第2层：Driver
UR ROS2 Driver
协议转换、收发状态和命令

第1层：硬件或物理引擎
真实UR / MuJoCo / Isaac Sim
执行动作并产生下一状态
```

其中仿真情况下：

```
第4、3、2层可能被简化或由adapter模拟
第1层换成MuJoCo
```

真实情况下：

```
第2层driver不可缺少
第1层是UR硬件
```


## 第一阶段：不用神经网络预测

```
RealSense
→ CV检测三维位置
→ Kalman估计位置和速度
→ 预测100～200 ms后位置
→ MoveIt Servo
→ UR driver
→ UR
```

先记录：

```
图像timestamp
CV完成timestamp
命令发送timestamp
机器人状态timestamp
末端实际到达timestamp
```

先测清楚系统真实延迟。

## 第二阶段：MJLab生成多种球轨迹

随机化：

```
球速度
球加速度
运动方向
相机噪声
丢帧
延迟
标定偏差
控制周期
UR响应参数
```

生成：

```
过去10帧观测 → 150 ms后真实位置
```

## 第三阶段：训练并比较

比较：

```
匀速外推
Kalman
MLP
GRU
```

不要一开始加入 Transformer。

## 第四阶段：闭环 rollout

将预测器接到模拟 UR：

```
预测器 → MoveIt Servo近似控制器 → MJLab UR
```

评估：

```
拦截成功率
最小距离
末端速度
加速度
jerk
不同球速下的表现
```

## 第五阶段：真实 UR 部署

```
PyTorch/ONNX预测模型
→ ROS2 prediction node
→ MoveIt Servo
→ ros2_control
→ UR ROS2 driver
→ UR机械臂
```

最适合你当前项目的预测算法排序是：

> **Kalman Filter → MLP → GRU。**

MJLab 的主要价值则是：

> **批量制造带真实噪声和延迟的轨迹、执行闭环 rollout、做 domain randomization，而不是代替整个预测算法或 driver。**

# 下载网络链接

### 方法一：使用 `wget`

```bash
bash
复制编辑
wget https://paddle-model-ecology.bj.bcebos.com/paddlex/imgs/demo_image/general_ocr_002.png

```

---

### ✅ 方法二：使用 `curl`

```bash
bash
复制编辑
curl -O https://paddle-model-ecology.bj.bcebos.com/paddlex/imgs/demo_image/general_ocr_002.png

```

---

### 📌 补充说明：

- `wget` 会保留文件名自动保存，你可以加 `O 文件名` 来指定另存为的名字。
- `curl -O` 会自动用远程文件名保存；用 `o 文件名` 可以自定义名字。

# MSE（均方误差）和 SSE（和方差误差）

### 1. SSE（Sum of Squared Errors，和方差误差）

- **定义**：SSE 是模型预测值与真实值之间的误差的平方和。公式如下：SSE=i=1∑n(yi−y^i)2
    
    SSE=∑i=1n(yi−y^i)2\text{SSE} = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
    
    其中，yiy_iyi 是第 iii 个真实值，y^i\hat{y}_iy^i 是第 iii 个预测值，nnn 是样本的总数。
    
- **特点**：
    - SSE 是一个绝对量，它随着样本数量的增加而增大。
    - SSE 的值表示了所有预测误差的总和，因此对于样本数量较多的数据集，SSE 可能会非常大。
- **适用场景**：SSE 常用于统计分析和回归模型中，用来评估模型的整体拟合效果。它能够直观地表示总误差的大小。

### 2. MSE（Mean Squared Error，均方误差）

- **定义**：MSE 是 SSE 的平均值，即将 SSE 除以样本数 nnn。公式如下：MSE=n1i=1∑n(yi−y^i)2
    
    MSE=1n∑i=1n(yi−y^i)2\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
    
- **特点**：
    - MSE 是 SSE 的标准化版本，它将总误差平均到每个样本上，从而得到每个样本的平均误差平方。
    - MSE 是一个相对量，与样本数量无关，因此它更适合比较不同规模数据集的模型性能。
- **适用场景**：MSE 常用于回归模型的性能评估，特别是在需要比较不同模型或不同数据集上的误差时使用。

### 总结

- **SSE** 是所有样本的误差平方和，反映的是总误差大小，数值依赖于样本数量。
- **MSE** 是 SSE 的平均值，反映的是每个样本的平均误差，便于比较不同规模数据集的模型性能。

SSE 主要用于评估模型的总体误差，而 MSE 则用于衡量每个样本的平均误差，因此 MSE 更常用于模型评估和比较。

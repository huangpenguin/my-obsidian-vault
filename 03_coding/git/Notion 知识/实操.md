# 实操

```python
echo "# demo_mdcp" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/emuni-kyoto/demo_mdcp.git
git push -u origin main
```

| **命令** | **作用** |  |
| --- | --- | --- |
| **`echo "# demo_mdcp" >> README.md`** | 创建项目说明文件 |  |
| **`git init`** | 初始化本地 Git 仓库 |  |
| **`git add README.md`** | 添加文件到暂存区（Staging Area） | **git add . 添加所有文件** |
| **`git commit -m "first commit"`** | 提交到本地仓库 |  |
| **`git branch -M main`** | 重命名分支为 **`main`** |  |
| **`git remote add origin <URL>`** | 关联远程仓库 | git remote -v
检查是否关联上 |
| **`git push -u origin main`** | 推送到远程仓库并设置默认上游 |  |

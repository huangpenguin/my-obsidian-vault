以下是为你量身定制的“零预算”个人项目 CI/CD 练习方案：

---

### 1. 免费的“质检员”：GitHub Actions (CI)

- **费用：** **￥0**
    
- **白嫖规则：** GitHub Actions 对所有**公开仓库（Public Repository）**是**完全免费且无限制**的。即使是私有仓库，每个月也赠送 2000 分钟的免费运行额度。
    
- **练手建议：** 在你的个人 RAG 或 Web 项目中，直接写一个 `.github/workflows/ci.yml`。每次你更新代码，让它自动帮你跑 `pytest` 和 `ruff`。看着每次提交后冒出的绿色对勾（`✔`），成就感拉满。
    

---

### 2. 免费的“镜像仓库”：GitHub Packages (GHCR)

既然要玩 Docker 部署，你就需要一个地方存你的 Docker 镜像。

- **费用：** **￥0**
    
- **白嫖规则：** GitHub 官方自带一个叫 **GitHub Container Registry (GHCR)** 的服务。只要你的项目是公开的，存储和流量完全免费。
    
- **练手建议：** 别去用 Azure 昂贵的容器仓库（ACR）了，直接在 GitHub Actions 里把打包好的镜像推送到 `ghcr.io/你的用户名/你的项目名:latest`。
    

---

### 3. 免费的“服务器”：Azure 免费额度 / 替代方案 (CD)

至于最终部署的服务器，确实需要精打细算。

#### 方案 A：申请 Azure 的免费学生/新用户额度（首选）

- 如果你还有**学生身份**（用学校邮箱），可以申请 **Azure for Students**，每年送 **100 美元**免费额度，不需要信用卡，而且包含免费额度的 Web App 和 12 个月免费的 B1s 虚拟机。
    
- 如果是**新注册普通用户**，Azure 会送 **200 美元**的常规额度（首月有效）以及大批 12 个月免费的热门服务。
    
- **练习目标：** 利用免费额度开一个最便宜的 Azure App Service (F1 或 B1 级别)，在 GitHub Actions 里配置上面提到的 **Publish Profile**，直接实现全自动 Docker 部署。
    

#### 方案 B：如果 Azure 额度用完了，无缝平替到 Render / Railway

如果你只是想练习“GitHub 联动云服务自动部署 Docker”的完整过程，又不想被 Azure 绑定信用卡，行业内有几个公认的**现代白嫖神器**：

- **Render (render.com) 或 Railway (railway.app)：** 它们对个人开发者非常友好。你只需要在上面创建一个 Web Service，把你的 GitHub 仓库连过去。只要 GitHub 上的 `main` 分支有更新，它们就会自动在云端帮你 Build Docker 镜像并部署。
    
- **费用：** 提供充足的免费 Free Tier（每月运行时间额度），只要你的项目不是 24 小时被高并发访问，完全够用。
    

---

### 💡 为什么个人项目一定要练习这个？

1. **面试时的巨大加分项：** 很多应届生或初级开发者的简历上，项目经历都写着“在本地运行、在 localhost:8000 调试”。如果你的简历上写着：_“独立构建了基于 GitHub Actions 与 Docker 的 CI/CD 自动化流水线，实现了代码质量内建与云端自动化部署”_，面试官一眼就能看出你有**生产环境的工程思维**。
    
2. **培养良好的开发习惯：** 哪怕是个人项目，有了 CI 之后，你每次改代码都会更谨慎地写测试。如果哪天代码写漏了类型、格式乱了，CI 会立刻“报错”提醒你，这能极大地帮你提升代码质量。

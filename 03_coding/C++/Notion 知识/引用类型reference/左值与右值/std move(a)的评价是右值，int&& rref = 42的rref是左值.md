# std::move(a)的评价是右值，int&& rref = 42的rref是左值

### `std::move` 的行为

`std::move` 是一个标准库函数模板，用于将一个对象显式地转换为右值引用。它的返回值是一个右值引用类型，但请注意：

- **返回值是右值**：`std::move`的返回值是一个右值引用，因此可以绑定到右值引用的变量。
- **用法场景**：`std::move`通常用于将一个左值转换为右值，以便传递给接受右值引用的函数，从而触发移动语义。

示例：

```cpp

int a = 10;
int&& r = std::move(a);  // std::move(a) 是一个右值
```

在这个例子中

- `std::move(a)` 将变量`a`转换为一个右值引用（右值）。
- `r` 是一个右值引用，可以绑定到`std::move(a)`的结果。

### 右值引用的变量本身是左值

当我们定义一个右值引用变量时，例如：

```cpp
int&& rref = 42;
```

这里的`rref`是一个右值引用类型的变量，但**rref 本身是一个左值**。我们可以这样理解：

- **类型 vs. 表达式**：`rref`的类型是右值引用（`int&&`），但`rref`这个变量在表达式中是一个左值。
- **访问方式**：我们可以对`rref`进行取地址操作或赋值操作，这些都是左值的特性。

```cpp
int&& rref = 42;
int&& anotherRref = std::move(rref);  // 这里的 std::move(rref) 是一个右值
```

*在这个示例中：*

- `*rref`的类型是`int&&`，即右值引用类型。*
- *但`rref`在表达式中作为左值（我们可以对`rref`取地址或赋值）。*
- `*std::move(rref)`将`rref`转换为一个右值，以便可以绑定到另一个右值引用变量`anotherRref`。*

### 具体分析：左值和右值

1. **左值 (lvalue)**:
    - 代表在内存中具有确定地址的对象，可以持久存储。
    - 例如：变量名、数组元素、引用等。
    - 左值可以出现在赋值语句的左侧。
    - 示例：`int x = 10;`, `x` 是左值。
2. **右值 (rvalue)**:
    - 通常是临时对象，不具有持久的内存地址
    - 例如：字面值（如`42`）、临时对象（如函数返回的值）。
    - 右值通常不能出现在赋值语句的左侧。
    - 示例：`int x = 10 + 20;`, 表达式 `10 + 20` 的结果是右值。

### `std::move` 详解

`std::move` 的定义如下：

```cpp
template <class T>
typename std::remove_reference<T>::type&& move(T&& t) noexcept {
    return static_cast<typename std::remove_reference<T>::type&&>(t);
}
```

`std::move`将其参数转换为右值引用（通过类型转换为`T&&`），所以其返回值是右值。

### 为什么 `int&& rref = 42` 的 `rref` 是左值？

虽然 `rref` 是一个右值引用类型的变量，但作为一个变量，`rref`在表达式中仍然是一个左值。这是因为：

- **变量的性质**：任何变量（无论类型如何）在表达式中出现时都是左值。
- **持久性存储**：`rref`在内存中有一个持久的位置（它是一个存储在栈或堆中的变量）。

### 总结

- **`std::move` 的返回值是右值**：它将其参数转换为右值引用，可以绑定到右值引用变量。
- **右值引用类型的变量是左值**：即使变量的类型是右值引用（`T&&`），这个变量在表达式中本身是左值，因为它是一个可以在内存中被持久存储的对象。

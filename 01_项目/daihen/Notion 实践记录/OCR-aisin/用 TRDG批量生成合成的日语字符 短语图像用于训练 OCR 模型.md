# 用 TRDG批量生成合成的日语字符/短语图像用于训练 OCR 模型

**合成图像（synthetic data）与真实世界（real-world data）之间的“域差距（domain gap）”**。

### ✅ 简单回答：

**直接用合成数据训练的模型，拿去识别真实世界图像时，准确率通常会下降。**

但——如果设计得当，合成数据可以非常有效，甚至和真实数据差不多好。

---

### 📌 为什么会有问题？

### 🧱 域差距（Domain Gap）主要表现在：

| 方面 | 合成图像 vs 真实图像 |
| --- | --- |
| 字体 | 通常用标准字体 |
| 背景 | 通常是干净纹理图 |
| 噪声 | 模拟模糊、扭曲，但有限 |
| 光照 | 合成中很均匀 |
| 颜色 | 前景/背景分离明显 |

---

### ✅ 那为什么大家还用它？

因为真实数据成本高，而**精心设计的合成数据**：

- 能大量扩充训练集，提升泛化能力；
- 作为预训练阶段的数据很有效；
- 可以模仿特定领域，比如车牌、工业标签等。

---

### 🔧 如何缓解这个问题？

你可以通过以下方法提高合成图像对真实任务的适应性：

| 方法 | 说明 |
| --- | --- |
| ✅ 更丰富的字体集 | 多种风格、模糊字体、仿手写字体 |
| ✅ 加强背景复杂度 | 使用真实拍摄的纹理图、背景图 |
| ✅ 加入真实扭曲 | 模拟相机畸变、遮挡、压缩损失 |
| ✅ 数据增强 | 模糊、噪声、对比度、光照变化、裁剪等 |
| ✅ 混合真实数据 | 合成数据 + 少量标注好的真实数据微调（fine-tuning） |
| ✅ 域自适应技术 | 如使用 style transfer、adversarial training 来缩小域差距 |

---

### ✅ 总结

合成图像如你用的 TRDG，可以：

- **快速生成大量标注好的训练数据**
- **模拟一定程度的现实场景**

但若想部署到现实世界，建议：

1. **合成数据多样性要强**
2. **加入部分真实数据用于微调**
3. **进行 domain adaptation 或使用更强的数据增强**

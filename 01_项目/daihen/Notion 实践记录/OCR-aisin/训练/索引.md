# 训练

---

## 思路

```bash
# 如果要测试训练流程，应该使用小数据集或少量epoch
python tools/train.py -c ../tray_recog/configs/det/det_r50_db++_baseline.yml -o Global.epoch_num=1

# 如果要正式训练，应该明确说明是训练而不是测试
nohup python -m paddle.distributed.launch --ips="192.168.3.18" --gpus "0,1,2,3" tools/train.py -c ../tray_recog/configs/det/det_r50_db++_baseline.yml > output/train.log 2>&1 &

# 如果要评估模型，应该使用eval命令
python tools/eval.py -c ../tray_recog/configs/det/det_r50_db++_baseline.yml

# 1. 检查baseline模型训练结果
ls -la output/det_r50_db++_baseline/

# 2. 评估baseline模型性能
python PaddleOCR/tools/eval.py -c tray_recog/configs/det/det_r50_db++_baseline.yml \
  -o Global.checkpoints=output/det_r50_db++_baseline/latest

# 3. 如果baseline效果满意，开始训练aisin模型
nohup python -u -m paddle.distributed.launch --ips="192.168.3.18" --gpus "0,1,2,3" \
  PaddleOCR/tools/train.py -c tray_recog/configs/det/det_r50_db++_aisin.yml \
  > output/det_r50_db++_aisin.yml.log 2>&1 &

# 4. 推理测试
python PaddleOCR/tools/infer_det.py \
  -c tray_recog/configs/det/det_r50_db++_aisin.yml \
  -o Global.checkpoints=output/det_r50_db++_aisin/latest \
  Global.infer_img=path/to/test/image.jpg
```

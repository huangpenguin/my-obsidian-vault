# 链式调用

链式调用是一种编程风格，通过在对象的方法中返回自身 (`self`)，使得多个方法调用可以串联在一起进行，简化代码的书写和提高可读性。这种方式在 Python 中尤其常见，例如一些对象操作的方法链，像 `str.strip().lower().replace()`, 其中每个方法都会对字符串进行操作并返回修改后的字符串实例。

在你的 `AdalineSGD` 类中，也有类似的链式调用支持。`fit` 和 `partial_fit` 方法返回了 `self`，允许用户在训练模型后立即调用其他方法而不需要重新引用对象。例如：

```python
# 初始化 AdalineSGD 类
adaline = AdalineSGD(eta=0.01, n_iter=10)

# 使用链式调用的方式拟合数据并打印成本
adaline.fit(X_train, y_train).partial_fit(X_new, y_new).predict(X_test)

```

在上面的代码中：

1. `adaline.fit(X_train, y_train)` 会对训练数据进行拟合，并返回 `adaline` 对象本身。
2. `.partial_fit(X_new, y_new)` 是在第一次拟合之后，继续使用部分新的训练数据进行增量训练。
3. `.predict(X_test)` 使用训练好的模型对测试数据进行预测。

### 链式调用的优势

1. **简洁**：可以减少代码行数，避免每次调用都要重新获取对象。
2. **可读性**：代码结构清晰，步骤一目了然，便于理解模型训练过程。
3. **便于流式操作**：特别是处理数据流或连续操作时，链式调用非常自然。

### 示例代码

一个更完整的链式调用示例：

```python
python复制代码
# 假设 X_train, y_train, X_test 是已经定义好的训练和测试数据
adaline = AdalineSGD(eta=0.01, n_iter=15, shuffle=True, random_state=1)

# 使用链式调用训练模型，并立即预测结果
predictions = adaline.fit(X_train, y_train).partial_fit(X_train[:5], y_train[:5]).predict(X_test)

print(predictions)

```

在这个例子中，我们初始化一个 `AdalineSGD` 实例，设置学习率、迭代次数等参数。然后通过链式调用对训练数据 `X_train` 和 `y_train` 进行拟合训练，接着使用 `partial_fit` 方法进一步微调模型，最后对测试数据 `X_test` 进行预测。

这样通过链式调用的方式，使得代码更简洁、更具有逻辑性，也更易于阅读和维护。

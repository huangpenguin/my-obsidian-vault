# SSH

### 1. 在本地安装 VS Code 和 Remote - SSH 扩展

### 2. 配置 SSH 连接

### （1）生成 SSH 密钥对（如果尚未有）

在本地终端中运行以下命令生成 SSH 密钥：

```bash
ssh-keygen -t rsa -b 4096
```

根据提示设置存储位置（默认位置即可）和密码短语。如果你不想每次输入密码，可以留空。

### （2）将公钥复制到远程服务器

```python
#获取本地公钥（在本地）
type C:\Users\huang\.ssh\id_rsa.pub

```

在远程server操作：

```python
mkdir C:\Users\your-username\.ssh
notepad C:\Users\your-username\.ssh\authorized_keys#注意别改成txt格式了

```

将公钥粘贴到 `authorized_keys` 文件中,设置文件权限

```python
icacls C:\Users\your-username\.ssh /grant your-username:F
icacls C:\Users\your-username\.ssh\authorized_keys /grant your-username:F
```

### （3）测试 SSH 连接

确保你可以通过 SSH 成功连接到远程服务器：

```bash
ssh your-username@your-server-i
```

### 3. 在 VS Code 中配置 Remote SSH 连接

1. 打开 VS Code。
2. 按 `Ctrl+Shift+P`（Windows/Linux）或 `Cmd+Shift+P`（Mac） 打开命令面板。
3. 在命令面板中输入 `Remote-SSH: Connect to Host`，然后选择它。
4. 在出现的输入框中，输入你的远程服务器地址，格式如下：
    
    ```bash
    your-username@your-server-ip
    ```
    
5. 如果这是你第一次连接该服务器，VS Code 会提示你选择 SSH 配置文件（`~/.ssh/config`）中保存连接信息的位置。选择一个配置文件或创建新的配置。
6. 连接后，VS Code 会通过 SSH 连接到服务器，你将看到一个新的 VS Code 窗口，表示你已经成功连接到了远程服务器。

### 4. 配置 SSH 配置文件（可选，但推荐）

为了简化连接，你可以在 `~/.ssh/config` 文件中添加配置项，这样你可以使用别名来连接服务器。

在终端中编辑 SSH 配置文件：

```bash
nano ~/.ssh/config

```

添加如下内容：

```bash
Host my-server
    HostName your-server-ip
    User your-username
    IdentityFile ~/.ssh/id_rsa  # 替换为你的私钥路径

```

保存并退出编辑器。现在你可以在 VS Code 中通过别名 `my-server` 进行连接，而不必每次输入完整的用户名和 IP 地址。

### 5. 在 VS Code 中打开远程文件和终端

连接成功后，你可以：

- 在 VS Code 的文件资源管理器中浏览远程服务器上的文件。
- 直接编辑远程服务器上的代码文件，所有修改将会保存在远程服务器上。
- 使用 VS Code 内置终端，打开 SSH 连接后的远程终端环境。

你可以在左侧栏中打开文件夹或项目，编辑代码，执行调试等操作，完全像在本地一样方便。

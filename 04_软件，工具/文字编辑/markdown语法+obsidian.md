# 🚀 Obsidian 核心语法与高阶指令指南

## 一、 绝杀功能：Callouts（彩色标注块）

Callouts 是 Obsidian 最漂亮的特性之一，用来高亮显示重要的提示、警告或信息。

### 1. 基础语法
在大于号 `>` 后面加一个空格，然后打出 `[!类型]`。
下一行继续用 `>` 打头，写正文。

> [!info] 这是一个 Info 块
> 这里可以写具体的补充信息，背景会变成蓝色，前面自带一个小图标。

> [!tip] 这是一个 Tip 块
> 适合用来记录小技巧和最佳实践，背景是绿色的。

> [!warning] 这是一个 Warning 块
> 用来高亮容易踩坑的地方，背景是橙色的。

> [!bug] 这是一个 Bug 块
> 程序员最爱，记录遇到的报错和解决办法，背景是红色的。

**其他支持的常用类型（直接替换中括号里的英文即可）：**
`note` (笔记), `success` (成功), `question` (问题), `danger` (危险), `quote` (引用)。

### 2. 进阶玩法：可折叠的 Callout
如果你有一段很长的代码或补充说明，不想占版面，可以在方括号后面加一个减号 `-`（默认折叠）或加号 `+`（默认展开）。

> [!example]- 点击展开查看示例代码
> 这里是被折叠起来的内容。
> 只有你点击了标题，它才会滑下来显示。

## 二、 程序员最爱的区块指令

### 1. 代码区块 (Code Block)
输入三个反引号（键盘左上角 Esc 键下方）加语言名称，按回车。

```javascript
// 这是一个 JavaScript 代码块
function sayHello() {
  console.log("Hello Obsidian!");
}
````

### 2. 行内代码 (Inline Code)

如果只想在句子里标记一个单词，比如函数名，用单个反引号把它包起来。

比如：在 React 中，我们经常使用 `useState` 这个 Hook。

### 3. 普通引用区块

如果不写 `[!info]` 这些，直接敲大于号 `>` 就是普通的引用。

## 三、 Obsidian 专属“魔法”语法

### 1. 双向链接 (Internal Link)

极其强大！打出两个左方括号 `[[` ，Obsidian 会自动列出你所有的笔记让你选。

示例：我要复习一下 [[React基础语法]]

### 2. 块链接 (Block Link) - 精确到段落！

如果你不想链接整篇笔记，只想链接某篇笔记里的**某一段话**，在名字后面打一个 `^` 符号。

示例：之前记录的那个报错在 [[前端踩坑记录^1a2b3c]]

### 3. 高亮文字 (Highlight)

如果你觉得加粗不够显眼，用两个等号 `==` 把文字包起来。

示例：这是一段 ==非常非常重要== 的复习重点。

### 4. 标签 (Tag)

用井号 `#` 紧跟文字，中间不能有空格。支持使用 `/` 创建层级。

示例：#技术/前端/React

## 四、 基础 Markdown 肌肉记忆

一旦习惯了，排版速度极快。

- **加粗：** 用两个星号包起来，**就像这样**。**sfdfds dfsfsdf
    
- **斜体：** 用一个星号包起来，_就像这样_。*sfdsfsf
    
- **删除线：** 用两个波浪号包起来，~~就像这样~~。~~sadasdasd sdasdads sdasd
    
- sdadasdasd

### 标题 (Headers)

敲下 `#` 然后加一个空格，就是标题。

# 一级标题 (最大)

## 二级标题

### 三级标题

###### 六级标题 (最小)

### 列表 (Lists)

- **无序列表：** 输入一个 `-` 或 `*` 加空格。
    
    - 按 `Tab` 键可以缩进成子列表。
        
- **有序列表：** 输入 `1.` 加空格。
    
- **待办事项 (Task list)：** 输入 `- [ ]` 加空格（注意括号中间有个空格）。
    
    - [x] 已经完成的任务 (把空格改成小写字母 x)
        fdsfsdfsfsfs 
        - [ ] 
        
    - [ ] 还没完成的任务
        
    - [ ] 在 Obsidian 里，你可以直接用鼠标点击这个方框来打勾！
        

### 分割线 (Horizontal Rule)

连敲三个减号 `---` 然后按回车，就能画出一条华丽的分割线。

（注：==如果在笔记最最顶部敲 `---`，调出的是属性/YAML面板，在正文里敲才是分割线==）。

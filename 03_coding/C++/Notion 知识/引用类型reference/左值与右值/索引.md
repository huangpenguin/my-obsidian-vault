# 左值与右值

（独学c++　p282）

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int &&b = 100;  // b 是一个右值引用，绑定到临时对象 100
    int &a = b;     // a 是一个左值引用，绑定到 b 所引用的对象

    std::cout << "Address of b: " << &b << std::endl; // 输出 b 的地址
    std::cout << "Address of a: " << &a << std::endl; // 输出 a 的地址

    a = 10; // 通过 a 修改 b 所引用的对象的值

    std::cout << "Value of b: " << b << std::endl;    // 输出 b 的值
    std::cout << "Value of a: " << a << std::endl;    // 输出 a 的值

    
    std::cout << "Address of b: " << &b << std::endl; // 输出 b 的地址
    std::cout << "Address of a: " << &a << std::endl; // 输出 a 的地址
    return 0;
}
```

左值参照与右值参照

```cpp
#include <iostream>
#include <utility>
void show(int& value)
{
std::cout << "参照" << std::endl;
}
void show(int&& value)
{
std::cout << "右辺値参照" << std::endl;
}
int main()
{
int i = 0;
show(i); // 参照
show(std::move(i)); // 右辺値参照
}
```

在C++中，函数参数可以使用右值引用（`&&`），这允许我们传递右值（临时对象）给函数，并且可以“捕获”右值，使其在函数内部仍然有效。当函数参数是右值引用时，传递一个数字字面量（如`42`）是完全可以的，因为字面量是右值。

### 右值引用概述

右值引用在C++11中引入，主要用于支持**移动语义**和**完美转发**。右值引用通过使用`&&`符号来声明。

### 右值和左值

- **右值**：不能取地址的值，例如字面量、临时对象等。它们通常存在于表达式中，在表达式结束时会被销毁。
    - 示例：`42`，`std::move(someObject)`，`someObject + anotherObject`
- **左值**：可以取地址的值，表示有持久性存储的对象。
    - 示例：变量名`x`，数组元素`arr[0]`，类对象`myObj`
- 左值引用是设计用来绑定到左值的，因为左值有持久的存储。右值（包括右值引用）是临时的，并且没有持久的存储。因此，试图将一个右值绑定到左值引用可能会导致悬空引用或非法访问，因为右值可能在不久之后被销毁。

### 传递右值到右值引用

当你传递一个右值（如`42`）到一个接受右值引用的函数时，编译器会识别它并允许调用，因为右值引用正是为了处理这种情况设计的。

### 示例

```cpp
cpp复制代码
void processValue(int&& x) {
    std::cout << "Right value: " << x << std::endl;
}

int main() {
    processValue(42);  // 42 是一个右值，可以传递给右值引用
}

```

在这个例子中：

- `processValue` 函数的参数是一个右值引用`int&&`。
- 当调用`processValue(42)`时，`42`是一个右值，因此它可以传递给`processValue`的右值引用参数`x`。

### 为什么这可行？

因为`42`是一个右值，编译器会将其视为一个临时对象。右值引用的一个主要用途是接受和处理这些临时对象，而不必创建额外的拷贝或影响性能。因此，当你传递`42`到`int&&`参数时，这是完全合法的。

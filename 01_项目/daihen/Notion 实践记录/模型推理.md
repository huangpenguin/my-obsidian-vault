# 模型推理

## 目录结构

### **📁 目录结构说明：**

### **🔷 训练配置文件**

- `config.yaml` /  - 训练配置文件
    
    ```
    config.yml
    ```
    
- `train.log` - 训练日志（6.5MB）
- `train_result.json` - 训练结果摘要

### **🔷 Checkpoint目录（每10个epoch保存一次）**

- `iter_epoch_10`, , ...,  - 每10个epoch的checkpoint
    
    ```
    iter_epoch_20
    ```
    
    ```
    iter_epoch_200
    ```
    
- `latest/` - **最新的checkpoint**（第200轮）
- `best_accuracy/` - **最佳准确率的checkpoint**（第162轮）✨

### **🔷 每个checkpoint目录包含的文件（以 `best_accuracy` 为例）：**

| **文件后缀** | **大小** | **说明** |
| --- | --- | --- |
| **`.pdparams`** | 14.4 MB | **模型参数**（权重） - 用于推理和恢复训练 |
| **`.pdopt`** | 28.4 MB | **优化器状态** - 仅用于恢复训练（Adam/SGD等的参数） |
| **`.states`** | 196 B | **训练状态** - epoch数、学习率等元信息 |
| **`.info.json`** | 215 B | **性能指标** - 准确率、召回率、FPS等 |

### **🔷 推理模型目录 `inference/`**

这是最重要的部分，用于实际推理：

| **文件** | **大小** | **说明** |
| --- | --- | --- |
| **`inference.pdiparams`** | 4.7 MB | **推理模型参数**（精简版，去掉了训练用的参数） |
| **`inference.json`** | 234 KB | **模型结构**（计算图定义） |
| **`inference.yml`** | 903 B | **推理配置** |

### **💡 文件后缀总结：**

| **后缀** | **用途** | **是否必需** |
| --- | --- | --- |
| `.pdparams` | 训练checkpoint，完整参数 | 恢复训练必需 |
| `.pdopt` | 优化器状态 | 仅恢复训练需要 |
| `.states` | 训练元数据 | 仅恢复训练需要 |
| `.info.json` | 性能指标记录 | 非必需，供查看 |
| `inference.pdiparams` | **推理专用参数** | **推理必需** ✅ |
| `inference.json` | **推理计算图** | **推理必需** ✅ |
| `inference.yml` | 推理配置 | 推理建议有 |

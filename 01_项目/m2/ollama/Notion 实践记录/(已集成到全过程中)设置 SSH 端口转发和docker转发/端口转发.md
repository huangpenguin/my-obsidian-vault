# 端口转发

### 直接打开 GCP 防火墙 + 用外部 IP 访问

1. 在 GCP 控制台 → VPC 网络 → 防火墙 规则，**允许 TCP 11434** 从你本地的公网 IP（或任何来源）进入到你的 VM。
2. 然后在本地运行：
    
    ```bash
    curl http://<你的-VM-外部-IP>:11434
    ```
    
    如果返回了 HTML（Ollama 的主页）或者 404 JSON，就说明连通了。
    

---

### 2. 用 SSH 隧道（更安全，也不用改防火墙）

1. 在本地打开一个终端，建立隧道：
    
    ```bash
    ssh -N -L 11434:localhost:11434 penguinpp@<你的-VM-外部-IP>
    ```
    
    - `L 本地端口:目标地址:目标端口`，这里把本地的 11434 通道打到 VM 的 11435
    - `N` 表示“只转发端口不执行远程命令”
2. 隧道建立后，本地再运行：
    
    ```bash
    curl http://localhost:11434
    ```
    
    这时请求会被透明地转发到 VM 上的 Ollama 服务。
    

---

### 本地测试容器是否真的在 VM 上监听

如果你想先在 VM 上自己测试，登录到那台机器，运行：

```bash
curl http://127.0.0.1:11434   # 或者 localhost
```

如果这里能通，那说明容器端没问题；如果连 VM 自己都连不上，再检查：

```bash
sudo docker logs ollama       # 看有没有 “Serving on 0.0.0.0:11434” 之类的信息
sudo netstat -tlnp | grep 11434

```

确保 Ollama 真在监听 `0.0.0.0:11434`（而不是仅监听 `127.0.0.1`）。

---

**总结**：

- `docker run -p` 是 VM→容器 映射，不是 本地→VM。
- 想从本地访问 VM 上的服务，要么在 GCP 放通并用 VM 的外网 IP，要么建立 SSH 隧道映射。

选择其中一个方案，正确配置后你的 `curl localhost:11434`（在本地）就能拿到 Ollama 的响应了。

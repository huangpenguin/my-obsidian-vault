# 使用正则表达式处理123+这样的计算式子

### 正则表达式解释

正则表达式从左往右开始匹配，左边的优先级高

正则表达式 `R"((\d+|~\d+|[+\-*/]))"` 由以下部分组成：

1. `\d+`:
    - `\d` 匹配任何一个数字（等同于 `[0-9]`）。
    - `+` 表示前面的模式可以重复一次或多次（即，匹配或多个数字）。
    - 因此，`\d+` 可以匹配任意长度的数字（例如，`123`、`4567`）。
2. `~\d+`:
    - `~` 是字面字符，表示负号前缀。
    - `\d+` 同上，匹配一个或多个数字。
    - 因此，`~\d+` 可以匹配带有负号的数字（例如，`~123`、`~4567`）。
3. `[+\-*/]`:
    - 方括号 `[]` 用于定义字符类，表示可以匹配其中任意一个字符。
    - + - * /  分别是四则运算符。减号在字符类中有特殊意义（表示范围），所以在这里用 `\` 转义。
    - 因此，`[+\-*/]` 可以匹配四则运算符中的任意一个。
4. 整个表达式被括号 `()` 包围，这在这里是可选的，用于分组。

### 代码的功能

```cpp
std::regex regex(R"((\d+|~\d+|[+\-*/]))");
```

- 这行代码定义了一个正则表达式对象 `regex`，用于匹配输入字符串中的整数（正负均可）和四则运算符。

```cpp
auto words_begin = std::sregex_iterator(input.begin(), input.end(), regex);
auto words_end = std::sregex_iterator();
```

- `std::sregex_iterator` 是一个标准库的正则表达式迭代器，用于遍历输入字符串中所有与正则表达式匹配的子字符串。
- `words_begin` 是一个迭代器，指向输入字符串中第一个匹配的子字符串。
- `words_end` 是一个默认构造的迭代器，表示到达匹配结束的位置。

```cpp
for (std::sregex_iterator i = words_begin; i != words_end; ++i) {
    std::string token = (*i).str();
    std::transform(token.begin(), token.end(), token.begin(), ::toupper);
    validateToken(token, tokens);
}

```

- 这个 `for` 循环使用正则表达式迭代器 `i` 从 `words_begin` 到 `words_end` 遍历所有匹配项。
- `(*i).str()` 返回当前匹配项的字符串表示，并存储在 `token` 中。
- `std::transform` 将 `token` 转换为大写形式。
- 最后，调用 `validateToken` 函数对 `token` 进行验证和处理，并将其存储到 `tokens` 向量中。

### 正则表达式迭代器的工作原理

1. `std::sregex_iterator` 创建一个从 `input` 的开头到结尾基于 `regex` 进行匹配的迭代器。
2. 在 `for` 循环中，迭代器 `i` 每次指向下一个匹配的子字符串，直到 `words_end`。
3. 每个匹配的子字符串都会被转换为大写，然后传递给 `validateToken` 进行处理。

通过这种方式，可以确保输入字符串被正确地分割成符合规则的 tokens，并且每个 token 都经过验证和处理。

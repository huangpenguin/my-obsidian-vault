# 数组操作

- 改变形状：
    
    ```
    arr = np.arange(6)
    reshaped_arr = arr.reshape(2, 3)  # 将1维数组变为2x3的数组
    print(reshaped_arr)
    ```
    
- 转置：
    
    ```
    arr = np.array([[1, 2, 3], [4, 5, 6]])
    transposed_arr = arr.T
    print(transposed_arr)
    ```
    
- 展平数组：
    
    ```
    flattened_arr = arr.flatten()  # 将多维数组变为1维
    print(flattened_arr)
    ```
    
- 拼接数组：
    
    ```
    arr1 = np.array([1, 2, 3])
    arr2 = np.array([4, 5, 6])
    concatenated_arr = np.concatenate((arr1, arr2))
    print(concatenated_arr)  # 输出: [1 2 3 4 5 6]
    ```

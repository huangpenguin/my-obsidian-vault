# sequence

一种 [iterable](https://docs.python.org/zh-cn/3.12/glossary.html#term-iterable)，它支持通过 [`__getitem__()`](https://docs.python.org/zh-cn/3.12/reference/datamodel.html#object.__getitem__) 特殊方法来使用整数索引进行高效的元素访问，并定义了一个返回序列长度的 [`__len__()`](https://docs.python.org/zh-cn/3.12/reference/datamodel.html#object.__len__) 方法。 内置的序列类型有 [`list`](https://docs.python.org/zh-cn/3.12/library/stdtypes.html#list), [`str`](https://docs.python.org/zh-cn/3.12/library/stdtypes.html#str), [`tuple`](https://docs.python.org/zh-cn/3.12/library/stdtypes.html#tuple) 和 [`bytes`](https://docs.python.org/zh-cn/3.12/library/stdtypes.html#bytes) 等。 请注意虽然 [`dict`](https://docs.python.org/zh-cn/3.12/library/stdtypes.html#dict) 也支持 [`__getitem__()`](https://docs.python.org/zh-cn/3.12/reference/datamodel.html#object.__getitem__) 和 `__len__()`，但它被归类为映射而非序列，因为它使用任意 [immutable](https://docs.python.org/zh-cn/3.12/glossary.html#term-immutable) 键而不是整数来查找元素。

[`collections.abc.Sequence`](https://docs.python.org/zh-cn/3.12/library/collections.abc.html#collections.abc.Sequence) 抽象基类定义了一个更丰富的接口，在 [`__getitem__()`](https://docs.python.org/zh-cn/3.12/reference/datamodel.html#object.__getitem__) 和 [`__len__()`](https://docs.python.org/zh-cn/3.12/reference/datamodel.html#object.__len__) 之外，还添加了 `count()`, `index()`, [`__contains__()`](https://docs.python.org/zh-cn/3.12/reference/datamodel.html#object.__contains__) 和 [`__reversed__()`](https://docs.python.org/zh-cn/3.12/reference/datamodel.html#object.__reversed__)。 实现此扩展接口的类型可以使用 [`register()`](https://docs.python.org/zh-cn/3.12/library/abc.html#abc.ABCMeta.register) 来显式地注册。 要获取有关通用序列方法的更多文档，请参阅 [通用序列操作](https://docs.python.org/zh-cn/3.12/library/stdtypes.html#typesseq-common)。

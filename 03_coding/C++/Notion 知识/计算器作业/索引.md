# 计算器作业

### 代码中的逆波兰式计算

在 `Parser` 类中，`parseAndEvaluate` 方法处理输入的逆波兰式表达式。下面是代码的详细解释：

```cpp
cppCopy code
class Parser {
public:
    /**
     * @brief 解析和计算输入表达式
     * @param input 输入的表达式
     * @param memory 内存管理对象，用于获取 ANS 的值
     * @return 计算结果
     */
    int parseAndEvaluate(const std::string& input, Memory& memory) {
        std::istringstream stream(input);
        std::stack<int> stack;
        std::string token;

        while (stream >> token) {
            if (isNumber(token)) {
                stack.push(std::stoi(token)); // 操作数入栈
            } else if (token == "+") {
                checkStackSize(stack, 2); // 检查栈中是否有足够的操作数
                int b = stack.top(); stack.pop(); // 弹出操作数
                int a = stack.top(); stack.pop();
                stack.push(a + b); // 执行加法运算并将结果入栈
            } else if (token == "-") {
                checkStackSize(stack, 2);
                int b = stack.top(); stack.pop();
                int a = stack.top(); stack.pop();
                stack.push(a - b); // 执行减法运算并将结果入栈
            } else if (token == "*") {
                checkStackSize(stack, 2);
                int b = stack.top(); stack.pop();
                int a = stack.top(); stack.pop();
                stack.push(a * b); // 执行乘法运算并将结果入栈
            } else if (token == "/") {
                checkStackSize(stack, 2);
                int b = stack.top(); stack.pop();
                int a = stack.top(); stack.pop();
                if (b == 0) {
                    throw std::invalid_argument("division by zero"); // 处理除以零的错误
                }
                stack.push(a / b); // 执行除法运算并将结果入栈
            } else if (token == "ans") {
                stack.push(memory.getAns()); // 使用 ANS 的值
            } else {
                throw std::invalid_argument("invalid token");
            }
        }

        if (stack.size() != 1) {
            throw std::invalid_argument("invalid expression"); // 如果栈中不止一个元素，说明表达式无效
        }

        int result = stack.top();
        return checkOverflow(result); // 检查是否溢出
    }

private:
    /**
     * @brief 检查是否是数字
     * @param str 输入字符串
     * @return 如果是数字则返回 true，否则返回 false
     */
    bool isNumber(const std::string& str) {
        // 支持负数（以 '~' 作为前缀表示负号）
        return !str.empty() && std::all_of(str.begin(), str.end(), [](char c) { return std::isdigit(c) || c == '~'; });
    }

    /**
     * @brief 检查堆栈的大小是否满足运算的要求
     * @param stack 操作数栈
     * @param requiredSize 所需的最小大小
     */
    void checkStackSize(const std::stack<int>& stack, size_t requiredSize) {
        if (stack.size() < requiredSize) {
            throw std::invalid_argument("insufficient operands");
        }
    }

    /**
     * @brief 检查结果是否溢出
     * @param result 计算结果
     * @return 如果没有溢出，返回结果值
     * @throws std::overflow_error 如果结果溢出
     */
    int checkOverflow(int result) {
        if (result < -99999 || result > 99999) {
            throw std::overflow_error("overflow");
        }
        return result;
    }
};

```

### 调用关系

1. **`main` 函数**：启动程序并创建 `Calculator` 对象，调用其 `run` 方法。
2. **`Calculator::run` 方法**：显示提示符并读取用户输入，使用 `CommandHandler` 处理命令，使用 `Parser` 解析和计算输入的表达式。
3. **`CommandHandler::handleCommand` 方法**：识别用户输入的是否为命令并执行相应的操作（如退出或清除）。
4. **`Parser::parseAndEvaluate` 方法**：解析输入的逆波兰式表达式并进行计算，处理操作数和运算符，进行必要的错误检查。
5. **`Memory` 类**：用于存储和管理计算结果，支持存储 ANS 变量并在需要时获取其值。

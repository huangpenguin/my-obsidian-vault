# 修复第一次使用

你遇到的是典型的第一次通过 SSH 连接某个服务器（比如 GitHub）时的提示，但你输完 `yes` 之后却 **没有成功写入 `known_hosts` 文件**，所以它提示：

```
Host key verification failed.
```

---

## ✅ 原因

你的系统可能出现了以下问题之一：

1. `~/.ssh` 目录不存在或权限不对；
2. 没有权限写入 `~/.ssh/known_hosts`；
3. SSH 客户端配置不正确。

---

## ✅ 解决步骤

### 🔧 第一步：确保 `.ssh` 目录存在并权限正确

```bash
mkdir -p ~/.ssh
chmod 700 ~/.ssh
```

### 🔧 第二步：手动添加 GitHub 到 known_hosts

```bash
ssh-keyscan github.com >> ~/.ssh/known_hosts
chmod 644 ~/.ssh/known_hosts
```

你可以验证一下内容：

```bash
cat ~/.ssh/known_hosts
```

应该会看到像下面这样的内容：

```

github.com ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI...

```

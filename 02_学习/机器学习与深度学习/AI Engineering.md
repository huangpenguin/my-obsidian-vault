# AI Engineering

链接：https://www.zhihu.com/question/644285055/answer/76740452292

1、使用 o[llama](https://zhida.zhihu.com/search?content_id=708463554&content_type=Answer&match_order=1&q=llama&zhida_source=entity) 拉模型到本地运行；（两天+）

2、注册[智谱](https://zhida.zhihu.com/search?content_id=708463554&content_type=Answer&match_order=1&q=%E6%99%BA%E8%B0%B1&zhida_source=entity)的开发者 API，获取[token](https://zhida.zhihu.com/search?content_id=708463554&content_type=Answer&match_order=1&q=token&zhida_source=entity)，用 python requests 调用 API； 用 [openai](https://zhida.zhihu.com/search?content_id=708463554&content_type=Answer&match_order=1&q=openai&zhida_source=entity) 框架调用 API；同时可以练习 prompt，写各种任务，如 小红书提示词生成、文章改写等。（两天+）

因：智谱有免费的 大模型 和 多模态 API，操作简单也不肉疼；同时兼容 openai 框架，适应后面其他模型的调用；

3、使用 langchain 或 [llama-index](https://zhida.zhihu.com/search?content_id=708463554&content_type=Answer&match_order=1&q=llama-index&zhida_source=entity) 写个 RAG，有空再写 Agent 编排调用工具。（一周+）

因：RAG 和 Agent 最容易看到效果，不容易气馁；也是是目前市场主要业务落地方向，有这个能力就可以做基本的 AI应用了

4、玩 [huggingface](https://zhida.zhihu.com/search?content_id=708463554&content_type=Answer&match_order=1&q=huggingface&zhida_source=entity)，拉模型、数据集下来，根据页面的提示来调用；（一周+）

这一步你才需要考虑显卡；前面把环境配置都熟悉了，去租云服务显卡用起来也会很方便。

5、使用 unsloth 微调qwen、llama 等模型（教程比较多，学习方便）（一周+）

6、学习 torch，进一步了解深度学习原理 （一个月+）

推荐：B站  [刘二大人 pytorch 入门教程](https://link.zhihu.com/?target=https%3A//www.bilibili.com/video/BV1Y7411d7Ys/) ；（小土堆的也不错，但选一个就够了，[李沐](https://zhida.zhihu.com/search?content_id=708463554&content_type=Answer&match_order=1&q=%E6%9D%8E%E6%B2%90&zhida_source=entity) 系列教程 可以后面又需要的时候补充看）

7、学习数学概率等知识 ，然后学习 numpy、pandas 等 （一个月+）

推荐  斯坦福系列课程，[唐宇迪](https://zhida.zhihu.com/search?content_id=708463554&content_type=Answer&match_order=1&q=%E5%94%90%E5%AE%87%E8%BF%AA&zhida_source=entity)的视频教程

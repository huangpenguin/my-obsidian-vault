# 基础知识

### Ubuntu Server 的文件系统结构

了解 Linux 的文件系统结构对于文件管理至关重要：

- `/`: 根目录，所有其他目录都位于其下。
- `/home`: 用户主目录，每个用户都有自己的子目录（例如 `/home/your_username`）。
- `/etc`: 存放系统配置文件。
- `/var`: 存放经常变化的数据，如日志文件 (`/var/log`)、Web 服务器文件 (`/var/www`)。
- `/tmp`: 存放临时文件，系统重启后通常会被清空。
- `/usr`: 存放用户程序和库。
- `/opt`: 存放第三方可选软件包。
- `/mnt`: 临时挂载文件系统（如 NFS 共享），就是我们之前提到的 `/mnt/data` 和 `/mnt/home`。

### 常用命令行操作

这是你日常与 Ubuntu Server 交互的核心：

- **`ls`**: 列出目录内容。
    - `ls -l`: 详细列表（权限、所有者、大小、日期等）。
        - ls -ls /datadrive
    - `ls -a`: 显示所有文件，包括隐藏文件（以 `.` 开头的文件）。
        - ls /: 表示查看根目录下的文件
- **`pwd`**: 显示当前工作目录的路径。
- **`mkdir`**: 创建新目录。
    - `mkdir my_new_folder`: 创建一个名为 `my_new_folder` 的目录。
- **`rm`**: 删除文件或目录。
    - `rm myfile.txt`: 删除文件。
    - `rm -r my_folder`: 递归删除目录及其内容。
    - `rm -rf my_folder`: 强制递归删除（慎用，没有二次确认）。

### `~` (波浪号) 表示什么？

在 Linux 命令行中，`~` (波浪号) 是一个非常有用的**快捷方式**，它总是代表**当前用户的“家”目录 (Home Directory)**。

- 对于用户 `huang` 来说，他的家目录就是 `/home/huang`。
- 所以，当你看到 `~/` 时，它等同于 `/home/huang/`。
- 因此，`~/.vnc/xstartup` 就等同于 `/home/huang/.vnc/xstartup`。

这个波浪号是一个非常方便的缩写，可以节省你输入完整路径的时间。

## 一、文件操作

| 命令 | 作用 |
| --- | --- |
| `ls -lh` | 查看当前目录，带人类可读文件大小 |
| `cd /path/to/dir` | 切换目录 |
| `cp -r src dst` | 复制文件/目录 |
| `mv src dst` | 移动（或重命名） |
| `rm -rf /path` | 删除目录或文件（危险，慎用） |
| `find . -name "*.py"` | 查找当前目录下所有 `.py` 文件 |
| `du -sh *` | 查看当前目录下所有文件/文件夹大小（简洁） |
| `df -h` | 查看磁盘挂载及剩余空间 |

## 常见工具的退出方式对比

| 工具 | 启动方式 | 退出方式 | 说明 |
| --- | --- | --- | --- |
| `top` / `htop` | 实时查看系统状态 | `q` | `q` = quit |
| `less` / `man` / `git log` | 翻页查看文档 | `q` | 用 `less` 做 pager 的工具几乎都是 `q` 退出 |
| `nano` | 编辑器 | `Ctrl + X` | 退出前会提示是否保存 |
| `vim` | 编辑器 | `ESC` → `:q` 或 `:wq` | 很多新人容易卡住（必须 ESC 后输入命令） |
| `python`, `node`, `ipython`（REPL） | 启动交互解释器 | `Ctrl + D` 或输入 `exit()` | 表示 EOF |
| `ssh`, `sftp`, `ftp` | 远程会话 | 输入 `exit` 或 `Ctrl + D` | 回到本地终端 |
| `tmux` / `screen` | 多终端复用 | `Ctrl + B` 然后 `:kill-session`（或 `exit` 所有 pane） | 更复杂，可配置快捷键 |

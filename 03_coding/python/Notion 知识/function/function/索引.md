**实参 argument**    **形参 parameter**

```python
#函数参数实例
def f(a,b='2',c):
	print(1)
f('a',c='c')#按顺序分别使用了顺序参数，默认参数(b)，关键词参数
```

## **解包实参列表**

函数调用要求独立的位置参数，但实参在列表或元组里时，要执行相反的操作。例如，内置的 [`range()`](https://docs.python.org/zh-cn/3.12/library/stdtypes.html#range) 函数要求独立的 *start* 和 *stop* 实参。如果这些参数不是独立的，则要在调用函数时，用 `*` 操作符把实参从列表或元组解包出来：

```python
list(range(3, 6))            *# normal call with separate arguments*[3, 4, 5]
args = [3, 6]
list(range(*args))            *# call with arguments unpacked from a list*[3, 4, 5]
```

字典可以用 `**` 操作符传递关键字参数

```python
def parrot(voltage, state='a stiff', action='voom'):
    print("-- This parrot wouldn't", action, end=' ')
    print("if you put", voltage, "volts through it.", end=' ')
    print("E's", state, "!")

d = {"voltage": "four million", "state": "bleedin' demised", "action": "VOOM"}
parrot(**d)
```

# 核心技术栈
- 语言：Python 3.11
- 包管理器：uv (绝对不要使用 pip, poetry 或 pipenv)

# 代码规范与质量控制 (极其重要)
- 代码风格与 Linting：必须遵守 Ruff 的规范。
- 类型检查：必须通过 Mypy 的严格静态类型检查。所有新函数必须包含完整的类型提示 (Type Hints)。

# 目录结构
- 核心代码主要位于 `src/` 和 `app/` 目录，以及根目录的 `main.py`。

# Cursor 行为准则
1. 依赖安装：当需要添加新库时，请给我提供 `uv add <package>` 命令，而不是 pip install。
2. 代码生成：在修改或生成代码时，请自动应用 Python 的类型注解（例如 `def foo(bar: str) -> int:`）。
3. 提交前自查：在协助我完成一段重要的代码修改后，请主动在终端运行 `make check` 来验证代码质量。如果需要运行项目测试，请使用 `make run`。

# 结构体

### 构造体（结构体）

- **定义：** 构造体（结构体）是用户自定义的数据类型，可以包含多个成员变量，每个成员变量可以是不同类型。
- **示例：**
    
    ```cpp
    cpp复制代码
    struct Fruit {
        int id;
        string name;
        double price;
    };
    
    Fruit apple = {1, "apple", 1.2};  // 初始化一个水果对象
    
    ```

### 接口指南 二、 FRED API 对接实施步骤（抓取宏观状态数据）

FRED 负责为你的智能体提供上帝视角的宏观外生数据。

#### 步骤 1：获取开发者通信密钥 (API Key)

1. 访问美国圣路易斯联储数据官网：`fred.stlouisfed.org`
    
2. 点击右上角 **"My Account"** -> **"Create New Account"**，用邮箱完成极简注册。
    
3. 登录后，进入 **"My Account"** -> 选择 **"API Keys"** -> 点击 **"Request API Key"**。
    
4. 应用场景随便填（比如填 _"Personal Quant Research System"_），系统会立刻生成一串 32 位的纯字母数字字符串。**复制并妥善保存，这就是你的通信凭证。**
    

#### 步骤 2：抓取目标 Ticker 与核心参数

在未来的 Python 下载器层（Data Layer），你需要配置提取以下 4 个核心宏观序列：

- `T10Y2Y`：美债收益率曲线斜率（判定衰退）。
    
- `BAMLH0A0HYM2`：高收益垃圾债利差（判定企业信贷断电）。
    
- `CPILFESL`：核心 CPI 数据（判定通胀环境）。
    
- `VIXCLS`：官方 VIX 恐慌指数（判定市场即时情绪）。
    

#### 步骤 3：Python 底层挂载示例

在本地终端执行 `pip install fredapi`。后续代码中，严格要求调用 `as_of_date` 参数调用原始脏数据，彻底消灭面试官最忌讳的未来函数。

### 接口指南 三、 Moomoo OpenAPI 对接实施步骤（抓取底层 K 线数据）

Moomoo 负责为你的智能体提供 5 只 ETF 极其纯净的日线量价数据。

#### 步骤 1：理解物理网关架构 (OpenD 机制)

Moomoo 的量化接口极其专业。为了保障数据传输的绝对极速与安全，它**不允许你的 Python 脚本直接连接云端服务器**，而是强制要求你在本地电脑上运行一个官方的网关客户端软件——**FutuOpenD（或 Moomoo OpenD）**。

- 你的 Python 脚本通过本地端口（通常为 `127.0.0.1:11111`）向本地的 OpenD 发出请求；
    
- 本地的 OpenD 负责加密数据包，跨海直连华尔街主干网拉取数据。
    

#### 步骤 2：开启量化开发者权限

1. 前往 Moomoo 桌面端官网或者富途 OpenAPI 官方文档页面（`open.moomoo.com` 或直接在客户端内搜索 API）。
    
2. 下载并安装本地网关程序 **Moomoo OpenD**（或者直接在 Moomoo 桌面高级版客户端设置中开启量化 API 网关服务）。
    
3. 在 OpenD 软件中登录你实名开户的 Moomoo 账号，此时本地通信网关正式点亮挂机。
    

#### 步骤 3：抓取目标数据包规范

在后续的二次开发代码中，调用 Moomoo 接口提取 **XLK, XLV, MTUM, QUAL, SGOV** 这 5 只标的自 **2010 年至 2026 年**的完整历史数据。

- **拉取参数严格设定为：** `日K线 (Daily)`。
    
- **数据字段包含：** `开盘价(Open)`、`最高价(High)`、`最低价(Low)`、`收盘价(Close)`、`成交量(Volume)`。
    
- **强制复权指令：** 必须在接口调用时开启 **“前复权 (Forward Adjusted)”**，让系统自动抹平历年分红派息导致的K线缺口。

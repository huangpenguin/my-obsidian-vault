# protocol

***NTP （Network Time Protocol）***サーバは、正確な時刻を保持するサーバです。他の機器が定期的に NTP サーバにアクセスして、時刻の誤差を補正することで、正確な時刻を保ち、機器間で時刻を同期させることができます。

***SNMP (Simple Network Management Protocol)*** とは、各機器の稼働状況、負荷、障害情報などをネットワーク経由で監視・制御する仕組みです。各機器から個別に情報を収集する手間がかからない利点がありますが、機器間の時刻が同期していないと、前後関係を特定できません。

***ARP（Address Resolution Protocol）：***ホストの ***IP アドレスからMACアドレス***を知るためのプロトコル

***UDP（User Datagram Protocol）***：トランスポート層でコネクションレス型のサービスを提供するプロトコル

***HTTPS 443：*** HHTP 80 ポート番号25 は、電子メール送信の SMTP、587 はメール送信のサブミッションポートのポート番号です。110 はメール受信の POP3、995 はメール受信を暗号化して行う POP3S のポート番号です。

RPS（リバースプロキシ）とは、外部インターネットから内部サーバへの接続を中継する仕組みのことです。また、ステートフルインスペクションとはパケットフィルタリングの一種で、アプリケーション層の情報までを参照するものです。

項番 1は、「社外にある PC が Web ブラウザを用いて HTTPS で RPS にアクセス」に対応する設定です。プロトコルは HTTPS ですので、【ア】のポート番号は 443 です。

項番 2 は、「 RPS が HTTP で営業支援サーバにアクセス」に対応する設定です。プロトコルは HTTP ですので、【イ】のポート番号は 80 です。

# 终端

## 🧠 你在用的是什么终端？

你现在通过 SSH 登录 Linux 服务器，这种情况下使用的是：

> ✅ 登录 shell（Login Shell）
> 

登录 shell 指你输入用户名和密码（或用密钥）后系统给你一个命令行提示符，比如：

```bash
huang@gpu01:~$

```

---

## 🧾 Linux 初始化文件区别（以 bash 为例）

| 文件名 | 在什么时候被执行？ | 常见在哪执行？ |
| --- | --- | --- |
| `~/.bashrc` | **每次打开交互式 shell（不管是否登录）时** | 例如你在图形界面点开一个终端，或手动 `bash` |
| `~/.bash_profile` | **只在登录 shell 执行** | 比如你通过 SSH 登录进服务器 |
| `~/.profile` | 跟 `.bash_profile` 类似，是更通用的 fallback | 当 `.bash_profile` 不存在时执行 |

---

## 👀 你的情况

你通过 SSH 登录服务器（登录 shell），所以系统只尝试执行：

```
bash
复制编辑
~/.bash_profile → ~/.profile

```

它不会自动执行 `~/.bashrc`，所以你在 `.bashrc` 里加的 Conda 初始化代码 **没有被执行**，于是你登录后 `conda` 命令用不了。

---

## ✅ 正确做法：让 `.bash_profile` 调用 `.bashrc`

这就像告诉系统：“无论是登录还是普通 shell，都请执行我的配置”。

### 添加这段代码到 `~/.bash_profile`：

```bash
bash
复制编辑
if [ -f ~/.bashrc ]; then
    source ~/.bashrc
fi

```

这样每次你登录，系统就会执行 `.bashrc` 里配置的 Conda 初始化脚本了。

---

## 🛠 一键解决方法

你只需要执行下面这一句命令（不管你有没有 `.bash_profile`，都会自动追加这段）：

```bash
bash
复制编辑
echo 'if [ -f ~/.bashrc ]; then source ~/.bashrc; fi' >> ~/.bash_profile

```

然后重新登录 SSH，再执行：

```bash
conda --version

```

## bash快捷键和操作

## ✅ 基础必备操作

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 调出上一条命令 | `↑`（方向键）或 `Ctrl + P` | 历史命令向上 |
| 调出下一条命令 | `↓`（方向键）或 `Ctrl + N` | 历史命令向下 |
| 光标移动到行首 | `Ctrl + A` | 很高频用法 ✅ |
| 光标移动到行尾 | `Ctrl + E` | 很高频用法 ✅ |
| 删除光标前一个字符 | `Ctrl + H` 或 `Backspace` | 和普通删除一样 |
| 删除光标处到行尾的内容 | `Ctrl + K` | 常用于快速删尾 |
| 删除行首到光标的内容 | `Ctrl + U` | 清除开头部分 |
| 清空整行 | `Ctrl + U` + `Ctrl + K` | 连用效果等于 `Ctrl + C` 清空当前行 |
| 交换光标前后字符 | `Ctrl + T` | 打错字时修救用 |
| 自动补全路径/命令 | `Tab` | 输入一部分按 `Tab` 自动补全 |
| 查看命令历史 | `history` | 显示历史命令（带编号） |
| 执行历史命令第 N 条 | `!N` | 比如 `!123` 执行第 123 条命令 |

| 场景 | 快捷键 | 用途 |

| 向前跳一个词 | `Alt + B` |  |

## ✅ 特别技巧

### 🔁 快速编辑上一条命令（超实用）

```bash
bash
复制编辑
fc

```

它会在 `$EDITOR`（比如 vim）中打开上一条命令，编辑后保存并自动执行，非常适合修改长命令。

你也可以指定修改第 N 条命令：

```bash
bash
复制编辑
fc 1003

```

---

### 🔍 搜索历史命令（模糊匹配）

按下：

```bash
bash
复制编辑
Ctrl + R

```

然后输入你记得的片段，比如：

```bash
bash
复制编辑
(reverse-i-search)`ssh':

```

输入片段后，自动补全历史中匹配的命令，再按回车执行。

如果匹配错了，按 `Ctrl + R` 继续往前找下一个匹配。

---

## ✅ 示例练习

```bash
bash
复制编辑
git clone https://github.com/yourrepo.git

```

你回车执行后，再按：

- `↑` → 调出上一条命令
- `Ctrl + A` → 移动到行首
- `Alt + F` → 向右跳一个词（光标跳到 `clone` 后）
- `Ctrl + K` → 删除 clone 后面内容
- 替换为新的 repo 地址后回车

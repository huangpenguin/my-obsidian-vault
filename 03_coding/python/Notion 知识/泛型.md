# 泛型

在 Python 的类型注解中，使用 `Tuple[int, str]` 来表示一个元组类型，其中第一个元素是 `int` 类型，第二个元素是 `str` 类型。这种语法使用的是方括号 `[]`，而不是圆括号 `()`。这是因为在类型注解中，方括号用于指定泛型类型，而不是表示实际的元组。

### 类型注解中的方括号 `[]`

在类型注解中，方括号 `[]` 用于指定泛型类型。泛型类型是指一类可以容纳多种类型的容器类型，例如列表、字典、元组等。使用方括号来指定这些容器中元素的具体类型。

### `Tuple` 示例

例如，`Tuple[int, str]` 表示一个包含两个元素的元组，第一个元素是 `int` 类型，第二个元素是 `str` 类型。使用方括号表示具体类型：

```python
from typing import Tuple

def process_key(key: Tuple[int, str]) -> None:
    print(f"Processing key: {key[0]} with value: {key[1]}")

# 调用示例
process_key((1, 'example'))  # 输出：Processing key: 1 with value: example

```

### 其他泛型类型示例

1. **列表**：

```python
from typing import List

def process_items(items: List[int]) -> None:
    for item in items:
        print(item)

# 调用示例
process_items([1, 2, 3, 4])  # 输出：1 2 3 4

```

**字典**：

```python

from typing import Dict

def process_dict(data: Dict[str, int]) -> None:
    for key, value in data.items():
        print(f"{key}: {value}")

# 调用示例
process_dict({'a': 1, 'b': 2})  # 输出：a: 1 b: 2

```

**集合**：

```python

from typing import Set

def process_set(items: Set[str]) -> None:
    for item in items:
        print(item)

# 调用示例
process_set({'apple', 'banana', 'cherry'})  # 输出：apple banana cherry

```

### 总结

在 Python 的类型注解中，使用方括号 `[]` 来表示泛型类型，如 `Tuple`、`List`、`Dict` 和 `Set`，以明确容器中元素的类型。这种方式有助于提高代码的可读性和类型检查的准确性。 `Tuple[int, str]` 中的方括号用于指定元组中的具体类型，而不是表示实际的元组结构。

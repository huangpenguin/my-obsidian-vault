# 装饰器decorator

### 修饰器的基础概念

装饰器是Python中一个强大的功能，用于在不修改函数本身的情况下，增强或改变函数的行为。修饰器本质上是一个高阶函数，它接受一个函数作为参数并返回一个新的函数。这个新的函数通常会对原函数进行某种包装，以在调用原函数之前或之后执行一些额外的代码。

---

### 修饰器的例子

- **定义修饰器函数**

一个修饰器函数通常接收一个函数作为参数，并返回一个新的函数。这个新的函数通常被称为 `wrapper`，它封装了原始函数，并在其中添加了额外的逻辑。

- **包装函数**

`wrapper` 函数内部会调用原始函数，并且可以在调用之前或之后执行一些额外的操作。

- **返回包装函数**

通过 `return wrapper`，修饰器函数将这个包装函数返回，取代原始函数。这使得在调用原始函数时，实际上会调用这个包装函数，并执行包装函数中的额外逻辑

```python
'''
在这个例子中，my_decorator 是一个装饰器，它包裹了 say_hello 函数，使得在调用 say_hello 函数前后都打印一些额外的信息。
'''
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("Something is happening before the function is called.")
        result = func(*args, **kwargs)#这里执行被包括的函数
        print("Something is happening after the function is called.")
        return result
    return wrapper#返回修饰后的函数

@my_decorator
def say_hello():
    print("Hello!")

say_hello()
```

## 使用装饰器创建生成器的示例

我们可以使用装饰器来增强你的生成器函数 `my_range`。例如，创建一个装饰器来打印生成器的开始和结束信息：

```python
def log_generator(func):
    def wrapper(*args, **kwargs):
        print(f"Starting generator '{func.__name__}' with args: {args} kwargs: {kwargs}")
        generator = func(*args, **kwargs)
        for value in generator:
            yield value
        print(f"Generator '{func.__name__}' finished.")
    return wrapper

@log_generator
def my_range(first=0, last=10, step=1):
    number = first
    while number < last:
        yield number
        number += step

# 使用装饰器的生成器
for x in my_range(1, 5):
    print(x)

for x in my_range(1, 5):  # 可以重新创建并使用生成器
    print(x)

```

### 详细解释

1. **定义装饰器 `log_generator`**：
    
    ```python
    python复制代码
    def log_generator(func):
        def wrapper(*args, **kwargs):
            print(f"Starting generator '{func.__name__}' with args: {args} kwargs: {kwargs}")
            generator = func(*args, **kwargs)
            for value in generator:
                yield value
            print(f"Generator '{func.__name__}' finished.")
        return wrapper
    
    ```
    
2. **使用装饰器**：
使用 `@log_generator` 来装饰 `my_range` 函数。这将会自动将 `my_range` 函数传递给 `log_generator` 装饰器，并将其返回值（`wrapper` 函数）赋给 `my_range`。
3. **调用生成器**：
当你调用 `my_range(1, 5)` 时，实际上是在调用 `wrapper` 函数。`wrapper` 函数会在调用生成器前后打印日志信息。

这个装饰器示例演示了如何在生成器函数的前后添加一些额外的行为，增强生成器的功能而不修改其本身的实现。

## 实验室 Infra：日常维护手册（建议记入笔记）

作为这套系统的搭建者（实验室的系统管理员），你未来只需要掌握以下 3 条高频运维命令，就能把两台服务器管得井井有条：

### 1. 监控：谁在后台跑训练？吃了多少资源？

有同学反映实验跑得慢，或者你想知道现在后台有几个容器在炼丹：

Bash

```
# 查看宿主机上所有正在运行的容器（能看到 train-xxx 的名字）
docker ps

# 查看 GPU 的实时状态、温度和显存占用
nvidia-smi

# 实时查看某一个同学/分支的训练日志
docker logs -f [容器名称]
```

### 2. 强杀：实验写挂了，死循环了怎么办？

如果代码写错导致 Loss 飞了，或者显存 OOM 卡死，不要用传统的 `kill -9`：

Bash

```
# 直接一行命令，优雅地停止并彻底销毁该训练容器，释放 GPU 显存
docker rm -f [容器名称]
```

### 3. 清理：服务器硬盘又满了怎么办？（重点）

深度学习最吃硬盘。同学们频繁 push 代码，服务器会堆积大量产生的临时容器和旧镜像。**建议每两周执行一次“大扫除”**：

Bash

```
# 1. 清理所有已经停止运行的垃圾容器（放心，正在跑的训练容器不会被删）
docker container prune -f

# 2. 清理所有无用的孤儿镜像层（释放大量 GB 级的系统硬盘空间）
docker image prune -a -f
```

# git

### **创建功能分支然后 PR（推荐做法）**

- 从 dev 创建新分支：`git checkout -b feature/功能名` 或 `dev_aaa`
- 在新分支上开发和提交
- 推送到新分支：`git push origin feature/功能名`
- 在 GitHub 创建 Pull Request，等待审核
- 审核通过后合并回 dev

git push origin feature/llm-reasoning

```jsx
隔离环境（仅git历史共享）

```

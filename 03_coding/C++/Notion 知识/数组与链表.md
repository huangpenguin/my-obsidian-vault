# 数组与链表

数组是C语言中的一种内置数据结构，它是一组连续存储的相同类型的元素。你可以通过下标访问数组中的元素，数组的大小在编译时必须是一个常量表达式。

而链表是一种自定义的数据结构，在C语言中需要通过指针来实现。链表是由一系列节点组成的，每个节点包含数据以及指向下一个节点的指针。与数组不同，链表的大小可以动态增长，并且插入、删除元素时的效率较高，但访问元素的效率较低，因为需要遍历链表。

数组和链表都有各自的优缺点，适用于不同的场景。通常情况下：

- 当你需要快速访问元素，并且知道数组的大小时，数组是一个不错的选择。
- 当你需要频繁地插入、删除元素，并且不知道需要存储的元素数量时，链表可能更合适。

#include <stdio.h>
#include <stdlib.h>

// 定义链表节点结构
struct Node {
int data;          // 数据
struct Node *next; // 指向下一个节点的指针
};

// 向链表中插入新节点
void insert(struct Node **head, int data) {
// 创建新节点
struct Node *newNode = (struct Node *)malloc(sizeof(struct Node));
if (newNode == NULL) {
printf("内存分配失败\n");
exit(1);
}
newNode->data = data;
newNode->next = NULL;

```
// 如果链表为空，将新节点设为头节点
if (*head == NULL) {
    *head = newNode;
    return;
}

// 找到链表尾部，并将新节点插入尾部
struct Node *current = *head;
while (current->next != NULL) {
    current = current->next;
}
current->next = newNode;

```

}

// 遍历并打印链表中的所有节点数据
void printList(struct Node *head) {
struct Node *current = head;
while (current != NULL) {
printf("%d -> ", current->data);
current = current->next;
}
printf("NULL\n");
}

// 释放链表的所有节点内存
void freeList(struct Node *head) {
struct Node *current = head;
while (current != NULL) {
struct Node *temp = current;
current = current->next;
free(temp);
}
}

int main() {
struct Node *head = NULL; // 初始化链表头节点为空

```
// 向链表中插入一些数据
insert(&head, 1);
insert(&head, 2);
insert(&head, 3);
insert(&head, 4);

// 打印链表中的数据
printf("链表中的数据：\\n");
printList(head);

// 释放链表的内存
freeList(head);
```

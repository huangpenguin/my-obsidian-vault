# 机器学习的书的p61

Φ(x)-J(w)图会展示逻辑损失函数（对数损失函数）在不同情况下的表现。

### 1. **图的基本结构**

- **横轴（X轴）**：表示预测概率 hθ(x)，即模型预测一个样本属于正类（标签为1）的概率。范围是从 0 到 1。
- **纵轴（Y轴）**：表示损失函数的值。损失函数的值衡量的是预测的准确程度，值越大表示损失越大。

### 2. **两条线的解释**

通常情况下，这样的图中会有两条线分别表示：

- **真实标签 y=1 时的损失（正类的损失）**。
- **真实标签 y=0 时的损失（负类的损失）**。

### 对数损失函数的公式：

逻辑回归使用的对数损失函数定义如下：

$$
\text{loss}(h_\theta(x), y) = -y \log(h_\theta(x)) - (1 - y) \log(1 - h_\theta(x))
$$

- 当 y=1 时，损失函数为：−log(hθ​(x))
- 当 y=0 时，损失函数为：−log(1−hθ​(x))

### 3. **图中两条线的具体解释**

### 真实标签 y=1 时（正类损失）：

- 这条线表示当真实标签为 1 时，模型预测的概率 hθ​(x) 越接近 1，损失越小。
- 在 hθ​(x)=1 时，损失为 0，因为预测完全正确。
- 当 hθ​(x) 越接近 0 时，损失急剧增大。即：

$$
\text{损失} = -\log(h_\theta(x)) \rightarrow \infty \quad \text{当 } h_\theta(x) \rightarrow 0
$$

这条线是一条下降曲线，从左上角（高损失）到右下角（低损失）。

### 真实标签 y=0 时（负类损失）：

- 这条线表示当真实标签为 0 时，模型预测的概率 hθ​(x) 越接近 0，损失越小。
- 在 hθ​(x)=0 时，损失为 0，因为预测完全正确。
- 当 hθ(x) 越接近 1 时，损失急剧增大。

$$
\text{损失} = -\log(1 - h_\theta(x)) \rightarrow \infty \quad \text{当 } h_\theta(x) \rightarrow 1
$$

这条线是一条上升曲线，从左下角（低损失）到右上角（高损失）。

### 4. **图的整体解释**

- 在这张图中，当模型的预测概率接近真实标签时（例如 y=1 且 hθ​(x) 接近 1，或者 y=0 且 hθ​(x) 接近 0），损失很小。
- 当模型的预测概率与真实标签相差较大时（例如 y=1 但 hθ​(x) 接近 0，或者 y=0 但 hθ​(x) 接近 1），损失急剧增大。

这种损失函数的性质确保了模型在做出错误预测时会受到较大的惩罚，从而促进模型的学习，使其更准确地预测样本的标签。

损失函数的设计是为了在接近真实标签时有较小的损失，而在远离真实标签时有较大的损失，从而引导模型学习更准确的预测。

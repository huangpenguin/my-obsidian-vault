# 基本知识

## 一、Git 仓库和分支的基本概念

### 📦 仓库（repository）

Git 里可以有：

- 本地仓库（你电脑里的项目）
- 远程仓库（如 GitHub 上的项目）

例如：

```
本地仓库 ←→ 远程仓库（GitHub 上的 origin）

```

### 🌿 分支（branch）

分支是版本线索，默认的分支一般叫 `main` 或 `master`。

你可以有多个分支，例如：

```
main（稳定版）
dev（开发中）
feature-x（某个新功能）

```

---

## 📤 `git push origin master` 的含义分解

```bash
git push origin master

#非同名branch时
git push origin master:my_remote_branch

```

### 解释：

- `git push`：执行“推送”操作（把代码推到远程仓库）
- `origin`：是远程仓库的名称（默认是 GitHub）
- `master`：是你本地想推送的分支名

🟰 整句话的意思是：

> 把我当前本地的 master 分支内容推送到 GitHub 上的 origin 远程仓库中，也叫 origin/master。
> 

[本地分支与远程分支](%E6%9C%AC%E5%9C%B0%E5%88%86%E6%94%AF%E4%B8%8E%E8%BF%9C%E7%A8%8B%E5%88%86%E6%94%AF.md)

### 无权直接push时,**使用分支推送（推荐）**

一般的工作流程是：

- 从 `master`（或 `main`）分支拉一个新分支：
    
    ```bash
    
    git checkout -b my-feature-branch
    
    ```
    
- 在这个分支上做改动、提交。
- 然后推送这个新分支到远程：
    
    ```bash
    
    git push origin my-feature-branch
    
    ```

## 🔍 三、怎么在本地命令行看当前仓库 & 分支信息

### ✅ 查看当前分支

```bash
git branch

* master  # 当前分支
  dev

```

或更详细：

```bash
git branch -vv

#会显示远程绑定信息，例如：

* master 1234abc [origin/master] Last commit message...
```

表示本地 `master` 分支追踪的是远程 `origin/master`

---

### ✅ 查看远程仓库的 URL（GitHub 链接）

```bash
git remote -v

```

输出类似：

```

origin  https://github.com/your-username/your-repo.git (fetch)
origin  https://github.com/your-username/your-repo.git (push)

```

说明你当前仓库的远程仓库是这个地址。

---

## 💡 四、如果你想知道“我推的是哪个分支、到哪个 GitHub 地址”，就查这些：

| 想知道什么 | 指令 |
| --- | --- |
| 当前分支 | `git branch` 或 `git branch -vv` |
| 当前绑定的远程分支 | `git branch -vv` |
| 当前远程仓库地址 | `git remote -v` |

## 🛠 小技巧：设置默认推送目标

```bash

git push -u origin master

```

这个命令的意思是：

- 推送 `master` 到 `origin`
- 并绑定，以后只需要输入 `git push` 就行了，不用再写 `origin master`

---

1. **查看分支**：
    
    ```
    git branch
    ```
    
    列出所有本地分支，当前分支前会标有 `*`。
    
2. **创建分支**：
    
    ```
    git branch <branch-name>
    ```
    
    创建一个新分支，但不切换。
    
3. **切换分支**：
    
    ```
    git checkout <branch-name>
    ```
    
    切换到指定分支。
    
4. **创建并切换分支**：
    
    ```
    git checkout -b <branch-name>
    ```
    
    创建并立即切换到新分支。
    
5. **删除分支**：
    
    ```
    git branch -d <branch-name>
    ```
    
    删除指定分支（需先切换到其他分支）。
    
6. **合并分支**：
    
    ```
    git merge <branch-name>
    ```
    
    将指定分支合并到当前分支。
    
7. **查看远程分支**：
    
    ```
    git branch -r
    ```
    
    列出所有远程分支。
    
8. **推送分支到远程仓库**：
    
    ```
    git push origin <branch-name>
    ```
    
    将本地分支推送到远程仓库。
    
9. **拉取远程分支**：
    
    ```
    git checkout -b <branch-name> origin/<branch-name>
    ```
    
    创建并切换到远程分支的本地副本。
    

### 示例

1. **创建并切换分支**：
    
    ```
    git checkout -b feature-login
    ```
    
    创建并切换到 `feature-login` 分支。
    
2. **开发完成后合并到主分支**：
    
    ```
    git checkout main
    git merge feature-login
    ```
    
    切换回 `main` 分支并合并 `feature-login`。
    
3. **删除分支**：
    
    ```
    git branch -d feature-login
    ```
    
    删除 `feature-login` 分支。

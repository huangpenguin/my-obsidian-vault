# 关于 scanf_s 和数组的处理(与上面字符串数组和字符串指针有关系)

**`scanf_s`** 函数用于安全地读取输入。它可以修改传入的字符数组，因为数组名在C语言中会退化为指向数组第一个元素的指针。当你调用 **`scanf_s`** 并传递数组名时，实际上是传递了一个指针，指向这个数组在内存中的位置。**`scanf_s`** 将读取的字符存储在这个位置。

以下是一个例子：

```c
char str[64];
scanf_s("%63s", str, sizeof(str));
```

这里，**`str`** 是一个字符数组的指针，**`scanf_s`** 将输入的字符串存储在 **`str`** 所指向的内存位置，并且 **`sizeof(str)`** 提供了数组的大小，用于确保输入不会超出数组的边界。

### **2. 关于字符串字面量和数组赋值：**

字符串字面量（例如 **`"asdwefg"`**）在C中是不可修改的常量字符串。数组初始化可以使用字符串字面量，但不能直接将一个新的字符串字面量赋值给数组。

例如，以下代码是有效的：

```c
char a[] = "asdwefg"; // 初始化数
a = "dawd"; // 错误：不能将字符串字面量赋值给数组
```

### **为什么 `a = "dawd";` 会报错？**

数组名在C语言中是一个常量指针，它在声明时被初始化后，不能再被赋值为其他地址。**`a`** 作为一个数组名，代表一个固定的地址（数组首元素的地址），你不能改变这个地址指向另一个字符串字面量的地址。

### **正确的字符串操作方法：**

要修改数组的内容，可以使用字符串操作函数，如 **`strcpy`**：

```c
#include <stdio.h>
#include <string.h>
int main(void)
{
    char a[64] = "asdwefg"; // 初始化数组
    printf("Before: %s\n", a);

    strcpy(a, "dawd"); // 使用 strcpy 将新字符串拷贝到数组
    printf("After: %s\n", a);

    return 0;
}

```

这样，**`strcpy`** 将字符串 **`"dawd"`** 的内容复制到 **`a`** 指向的数组位置。需要注意的是，目标数组 **`a`** 必须有足够的空间来存储新字符串。

### **综上所述：**

1. **`scanf_s`** 能修改数组内容是因为它接收一个指向数组的指针。
2. 字符串字面量不能直接赋值给字符数组；初始化时可以用字面量，但修改内容需要使用字符串操作函数如 **`strcpy`**。
3. 数组名是一个常量指针，不能在初始化后改变其指向。

# 読み出し専用プロパティ

`@property` 和 `@set_name` 是 Python 中用于属性和元编程的一些装饰器和机制。

### `@property`

`@property` 是一个内置装饰器，用于将方法转换为属性。它允许你定义一个方法，但以属性的方式访问它。这在封装和控制属性访问时非常有用。

示例：

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        print('1: in function with property decorator')
        return self._radius

    @radius.setter
    def radius(self, value):
        print('2: in function with setter decorator')
        if value < 0:
            raise ValueError("Radius cannot be negative")
        self._radius = value

    @property
    def area(self):
        print('3: in another function with property decorator')
        return 3.14159 * (self._radius ** 2)

# 创建 Circle 类的实例
circle = Circle(5)

# 使用 @property 方法
print(circle.radius)  # 获取半径  
circle.radius = 10    # 设置半径
print(circle.area)    # 计算面积

print(type(circle.radius))  #<class 'int'>，所以这玩意其实被修饰成了一个属性
print(type(circle))  #<class '__main__.Circle'>
```

在这个例子中：

- `radius` 属性通过 `@property` 装饰器来获取和设置值。
- `area` 属性是只读的，通过 `@property` 装饰器来计算和返回值。

对于使用@property生成的属性，只能使用setter修改值，否则报错

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

c=Circle(5)
c.radius=10#报错
```

这种方法也实现了只读属性，此处如果不加setter就变成只读的了

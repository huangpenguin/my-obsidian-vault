# macOS 快捷键与触控板手势速查

## 一、 核心快捷键对照表（Win vs Mac）

> [!tip] 键盘映射逻辑 记住一个核心原则：Windows 下的 `Ctrl`，在 macOS 下绝大部分对应 `⌘ Command` (简称 Cmd)。

|功能|Windows|macOS|
|---|---|---|
|**复制 / 粘贴 / 剪切**|`Ctrl` + `C` / `V` / `X`|`⌘ Cmd` + `C` / `V` / `X`|
|**撤销 / 全选 / 查找**|`Ctrl` + `Z` / `A` / `F`|`⌘ Cmd` + `Z` / `A` / `F`|
|**保存**|`Ctrl` + `S`|`⌘ Cmd` + `S`|
|**退出当前应用**|`Alt` + `F4`|`⌘ Cmd` + `Q`|
|**切换应用**|`Alt` + `Tab`|`⌘ Cmd` + `Tab`|
|**切换窗口 (同应用内)**|无 / 依赖任务栏|`⌘ Cmd` + `` ` `` (左上角反引号)|
|**强制退出程序**|`Ctrl` + `Alt` + `Del`|`⌘ Cmd` + `Option` + `Esc`|
|**打开应用设置**|`Win` + `I` (系统设置)|`⌘ Cmd` + `,` (逗号)|
|**全屏截屏**|`Print Screen`|`Shift` + `⌘ Cmd` + `3`|
|**区域截屏**|`Win` + `Shift` + `S`|`Shift` + `⌘ Cmd` + `4`|
|**全局聚焦搜索**|`Win` + `Q` 或 `S`|`⌘ Cmd` + `空格`|

## 二、 触控板核心手势

|场景分类|手势动作|功能说明|
|---|---|---|
|**基础点击**|单指点按|选择 / 左键点击|
||双指轻点|呼出**右键菜单**|
||三指点按|查词典 / 快速预览 (需开启 Force Touch)|
||双指点两下|快速缩放 (网页 / PDF)|
|**浏览滚动**|双指 上下/左右 滑动|垂直 / 水平滚动页面|
||双指 左右滑动|浏览器页面 后退 / 前进|
|**多任务切换**|四指 左右滑动|切换全屏应用 / 虚拟桌面|
||四指 向上滑动|打开任务调度中心 (Mission Control)|
||四指 向下滑动|展开当前应用的所有窗口|
|**全局视图**|四指/五指 向内捏合|显示应用列表 (Launchpad)|
||拇指与三指 向外张开|显示桌面|

_(注：部分四指手势可能因开启了“三指拖拽”而顺延，请以个人系统设置为准)_

## 三、 终端补全与文本编辑高阶快捷键

### 1. 终端补全 (zsh + oh-my-zsh)

- `Tab`：命令、路径、文件名自动补全。
    
- `➡️` (右方向键)：出现补全列表后，用于选择建议项。
    
- `Enter`：确认选中该补全项。
    
- `Ctrl` + `C`：取消补全，或清除当前行。
    

### 2. 全局原生文本光标控制 (Emacs 风格)

> [!info] 隐秘而强大的内置快捷键 macOS 默认支持 Emacs 快捷键。在 Spotlight、Safari 地址栏、备忘录等所有**原生文本框**中均可盲打使用，双手无需离开主键盘区。

- `Ctrl` + `A`：移动光标到 **行首**
    
- `Ctrl` + `E`：移动光标到 **行尾**
    
- `Ctrl` + `K`：删除从光标到 **行尾** 的所有内容
    
- `Ctrl` + `U`：删除从 **行首** 到光标的所有内容
    
- `Ctrl` + `B` / `F`：向左 (Backward) / 向右 (Forward) 移动光标

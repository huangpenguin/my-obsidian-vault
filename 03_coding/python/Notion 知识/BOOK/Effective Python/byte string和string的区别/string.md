# string

```python
a = 'a \u0300p ropos'
b = 'a \u0300 p ropos'
c = 'a\u0300 p ropos'

print(list(a))

print(a)
print(b)
print(c)

```

### 代码

1. **定义 Unicode 字符串**：
    - `\u0300` 是一个 Unicode 转义序列，表示组合重音符（grave accent），它会组合在前面的字符上，形成一个新的字符。
    
    ```python
    
    a = 'a \u0300p ropos'
    
    ```
    
    - 这里的 `\u0300` 会跟在 `a` 后面，但是由于中间有一个空格，它不会与 `a` 组合。
    - 实际上，这段字符串等于 `a`、空格、重音符、`p`、空格、`r`、`o`、`p`、`o`、`s`。
    
    ```python
    
    b = 'a \u0300 p ropos'
    
    ```
    
    - 这里的 `\u0300` 会跟在 `a` 后面，由于中间有一个空格，它不会与 `a` 组合。
    - 实际上，这段字符串等于 `a`、空格、重音符、空格、`p`、空格、`r`、`o`、`p`、`o`、`s`。
    
    ```python
    
    c = 'a\u0300 p ropos'
    
    ```
    
    - 这里的 `\u0300` 紧跟在 `a` 后面，没有空格，它会与 `a` 组合形成带有重音符的 `à`。
    - 实际上，这段字符串等于 `à`、空格、`p`、空格、`r`、`o`、`p`、`o`、`s`。
2. **打印字符串的列表形式**：
    
    ```python
    
    print(list(a))
    
    ```
    
    - 这会将字符串 `a` 转换为一个字符列表。
    - `a` 中的字符列表是：`['a', ' ', '\u0300', 'p', ' ', 'r', 'o', 'p', 'o', 's']`。
3. **打印字符串**：
    
    ```python
    
    print(a)
    print(b)
    print(c)
    ```
    

### 完整输出

综上所述，运行这段代码后，会看到以下输出：

```python
['a', ' ', '̀', 'p', ' ', 'r', 'o', 'p', 'o', 's']
a ̀p ropos
a ̀ p ropos
à p ropos

```

- 列表形式的输出展示了每个字符，包括重音符 `̀`。
- `a` 和 `b` 中重音符没有与 `a` 组合，因为中间有空格。
- `c` 中重音符与 `a` 组合形成了 `à`。

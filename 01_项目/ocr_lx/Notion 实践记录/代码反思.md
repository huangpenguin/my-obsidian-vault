# 代码反思

## 关于 extend() vs append()

### **extend() 的作用：**

```python
results_list = []
results_list.extend(generate_arrangement_no_results())  # 假设返回 [result1, result2]
results_list.extend(generate_room_number_results())     # 假设返回 [result3, result4]

# 结果: results_list = [result1, result2, result3, result4]

```

### **如果用 append()：**

```python
results_list = []
results_list.append(generate_arrangement_no_results())  # 假设返回 [result1, result2]
results_list.append(generate_room_number_results())     # 假设返回 [result3, result4]

# 结果: results_list = [[result1, result2], [result3, result4]]  # 错误！嵌套列表

```

**extend()** 将列表中的所有元素逐个添加到目标列表中，而 **append()** 会将整个列表作为一个元素添加。

# 多个装饰器叠加

在Python中，你可以将多个装饰器叠加使用，每个装饰器都会依次应用于目标函数，从内到外的顺序。例如，如果你有两个装饰器 `decorator1` 和 `decorator2`，并希望同时应用它们，可以按如下方式进行：

```python
@decorator1
@decorator2
def some_function():
    pass
```

这等价于：

```python
some_function = decorator1(decorator2(some_function))
```

下面是一个具体的例子，展示如何叠加多个装饰器：

### 示例

1. **定义两个装饰器**：
    - `log_start_end`：在函数开始和结束时打印日志。
    - `log_arguments`：打印函数的参数。

```python
def log_start_end(func):
    def wrapper(*args, **kwargs):
        print(f"Starting '{func.__name__}'")
        result = func(*args, **kwargs)
        print(f"Finished '{func.__name__}'")
        return result
    return wrapper

def log_arguments(func):
    def wrapper(*args, **kwargs):
        print(f"Arguments for '{func.__name__}': args={args}, kwargs={kwargs}")
        return func(*args, **kwargs)
    return wrapper

```

1. **定义生成器函数并使用装饰器**：

```python
@log_start_end
@log_arguments
def my_range(first=0, last=10, step=1):
    number = first
    while number < last:
        yield number
        number += step

```

1. **使用装饰器的生成器**：

```python
for x in my_range(1, 5):
    print(x)

```

### 运行结果

运行上述代码时，输出将如下所示：

```arduino
Starting 'wrapper'
Arguments for 'my_range': args=(1, 5), kwargs={}
Finished 'wrapper'
1
2
3
4

```

这个示例展示了多个装饰器如何叠加使用，每个装饰器在其内部执行额外的逻辑，同时不修改原始函数的逻辑。注意装饰器的应用顺序：最内层的装饰器（`log_arguments`）最先执行，最外层的装饰器（`log_start_end`）最后执行。

### 2. 元素访问

```cpp
cpp复制代码
std::vector<int> v = {1, 2, 3, 4, 5};

// 使用下标访问元素
int value1 = v[0];

// 使用 at() 方法访问元素（带边界检查）
int value2 = v.at(1);

// 获取第一个和最后一个元素
int first = v.front();
int last = v.back();

```

### 3. 修改容器

```cpp
cpp复制代码
std::vector<int> v;

// 添加元素到末尾
v.push_back(6);

// 删除最后一个元素
v.pop_back();

// 插入元素到指定位置
v.insert(v.begin() + 1, 7);

// 删除指定位置的元素
v.erase(v.begin() + 2);

// 清空所有元素
v.clear();

// 重新分配大小
v.resize(5); // 如果新大小小于当前大小，末尾元素被删除；如果新大小大于当前大小，新增元素初始化为默认值

// 预留空间
v.reserve(20); // 预留至少能容纳 20 个元素的空间

```

### 4. 容量和大小

```cpp
cpp复制代码
std::vector<int> v = {1, 2, 3, 4, 5};

// 获取元素个数
size_t size = v.size();

// 获取最大可能存储的元素个数
size_t max_size = v.max_size();

// 检查是否为空
bool empty = v.empty();

// 获取分配的存储空间大小
size_t capacity = v.capacity();

```

### 5. 迭代器

```cpp
cpp复制代码
std::vector<int> v = {1, 2, 3, 4, 5};

// 遍历 vector
for (std::vector<int>::iterator it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << " ";
}

// 使用反向迭代器遍历
for (std::vector<int>::reverse_iterator rit = v.rbegin(); rit != v.rend(); ++rit) {
    std::cout << *rit << " ";
}

```

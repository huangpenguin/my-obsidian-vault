# 親への支援要請(继承)

```python
class Person:
	def __init__(self,name):
		self.name=name
class EmailPerson(Person):
    def __init__(self,name,email):
        super().__init__(name)
        self.email=email	
		
b=EmailPerson('a','b')
```

总共使用了几种不同的特征重要性评估方法，并基于这些评估方法选择了最重要的特征用于随机森林模型训练。这些特征重要性评估方法分别是：

1. **递归特征消除（RFE, Recursive Feature Elimination）**：通过递归消除不重要的特征，直到剩下指定数量的特征。RFE方法结合了模型的训练过程，帮助找到对模型预测最重要的特征。
2. **随机森林特征重要性（RF Feature Importance）**：直接通过训练随机森林模型后得到的特征重要性分数，基于特征在决策树中的重要性来计算。这是嵌入式特征选择方法。
3. **置换重要性（Permutation Importance）**：通过随机打乱某一特征的数据，观察模型性能的变化，来衡量该特征的重要性。如果模型性能下降幅度较大，说明该特征很重要。
4. **特征删除重要性（Drop-Column Importance）**：逐个移除特征，然后重新训练模型，观察模型性能的变化。移除重要特征时，模型性能的下降幅度较大，说明该特征更重要。

最终，这几种方法评估出来的特征集分别用于训练多个不同的随机森林模型，并通过交叉验证评估其性能。

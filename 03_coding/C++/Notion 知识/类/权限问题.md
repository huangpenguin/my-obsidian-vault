# 权限问题

在 C++ 中，一个派生类不能直接访问另一个派生类的成员函数，除非通过公共基类的公共或受保护成员函数来访问。派生类之间的访问权限是通过继承结构和访问控制来管理的。

### **访问权限总结**

- **公共成员**：可以被任何代码访问。
- **受保护成员**：可以被类本身和派生类访问，不能被类的外部代码直接访问。
- **私有成员**：只能被类本身访问，不能被派生类或类的外部代码直接访问。

### **友元类和友元函数**

友元类和友元函数可以访问类的私有和受保护成员。友元关系是单向的，即类声明谁为友元，谁就可以访问它的私有和受保护成员，而不是相互的。

```cpp
#include <iostream>

class Base {
public:
    void publicMethod() {
        std::cout << "Base public method" << std::endl;
    }

protected:
    void protectedMethod() {
        std::cout << "Base protected method" << std::endl;
    }

private:
    void privateMethod() {
        std::cout << "Base private method" << std::endl;
    }
};

class Derived1 : public Base {
public:
    void derived1Method() {
        std::cout << "Derived1 method" << std::endl;
    }

    void accessBaseMethods() {
        publicMethod();        // 可以访问基类的公共成员
        protectedMethod();     // 可以访问基类的受保护成员
        // privateMethod();    // 无法访问基类的私有成员
    }
};

class Derived2 : public Base {
public:
    void derived2Method() {
        std::cout << "Derived2 method" << std::endl;
    }

    void accessDerived1Methods(Derived1& d1) {
        d1.publicMethod();     // 可以访问基类的公共成员
        d1.derived1Method();   // 可以访问 Derived1 的公共成员
        // d1.protectedMethod(); // 无法直接访问基类的受保护成员
        // d1.privateMethod();   // 无法访问基类的私有成员
    }
};

int main() {
    Derived1 d1;
    Derived2 d2;

    d1.accessBaseMethods();
    d2.accessDerived1Methods(d1);

    return 0;
}

```

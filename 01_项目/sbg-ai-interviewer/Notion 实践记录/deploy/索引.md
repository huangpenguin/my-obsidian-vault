# deploy

---

本项目最终使用shell脚本快速push dockerfile到acr，然后以此建立aca，不需要手动使用指令

---

### 建ACR

### 第一步：创建一个“仓库” (Azure Container Registry, 简称 ACR)

你需要一个地方来存放你本地打包好的 Docker 镜像。

1. 在 Portal 顶部的搜索框搜 **"Container registries"**。
2. 点击 **Create**。
3. **Resource Group**：选你看到的那个 `chatbot`。
4. **Registry name**：起个名字（比如 `mychatbotreg`）。
5. **Location**：选和你 Search 服务一样的区域（比如 East US）。
6. **SKU**：选 **Basic**（最便宜，学习够用了）。
7. 创建完成后，进入该资源，在左侧菜单找 **Access keys**，把 **Admin user** 勾选为 **Enabled**。
    
    > *这一步很重要！之后你本地推镜像需要这里的用户名和密码。*
    > 

### 第二步：本地把镜像“推”上去

这时回到你的电脑终端（确保已安装 Docker）：

1. **登录仓库**：
`docker login <你的仓库名>.azurecr.io`（输入刚才 Access keys 里的用户名密码）。
2. **构建并打标签**：
`docker build -t <你的仓库名>.azurecr.io/chainlit-app:v1 .`
3. **推送**：
`docker push <你的仓库名>.azurecr.io/chainlit-app:v1`

### 第三步：创建一个“服务器” (Azure Container Apps, 简称 ACA)

镜像传上去后，我们要让它跑起来。

1. 在 Portal 搜索 **"Container Apps"**。
2. 点击 **Create**。
3. **Resource Group**：选 `chatbot`。
4. **Container App name**：起个名字。
5. 在 **Container** 选项卡里：
    - 取消勾选 "Use quickstart image"。
    - **Image source** 选 **Azure Container Registry**。
    - 在下拉列表里选你刚才推上去的 `chainlit-app:v1`。
6. **Ingress (入口)** 设置：
    - 选中 **Enabled**。
    - **Target Port** 填 `8000` (Chainlit 默认端口)。

---

### 💡 一个关键提醒：Secrets 填在哪？

你刚才提到的 `srch-sbg`（Search 服务），你的代码肯定需要它的 **Endpoint** 和 **API Key** 才能工作。

1. 点开你的 `srch-sbg` 资源，在左侧找 **Keys**，复制那个密钥。
2. 在创建 **Container App** 的过程中，有一个 **Environment variables** 界面。
3. 你需要在这里手动添加代码里用到的变量，例如：
    - `AZURE_SEARCH_ENDPOINT` = `https://srch-sbg.search.windows.net`
    - `AZURE_SEARCH_KEY` = `你的密钥`
    - `OPENAI_API_KEY` = `你的 OpenAI 密钥`

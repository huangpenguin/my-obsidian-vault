### 算法

1. **Sort（排序）**
    - **简介：** 对容器中的元素进行排序。
    - **用法：**
        
        ```cpp
        
        #include <algorithm>using namespace std;
        
        vector<int> vec = {3, 1, 4, 1, 5, 9};
        sort(vec.begin(), vec.end());  // 默认升序排序,可自定compare函数
        ```
        
2. **Lower Bound（下界）**
    - **简介：** 查找第一个大于等于给定值的元素位置。
    - **用法：**
        
        ```cpp
        
        #include <algorithm>using namespace std;
        
        vector<int> vec = {1, 2, 2, 4, 5};
        auto it = lower_bound(vec.begin(), vec.end(), 3);  // 返回大于等于3的第一个位置
        int index = it - vec.begin();  // 转换为索引
        
        ```
        
3. **Upper Bound（上界）**
    - **简介：** 查找第一个大于给定值的元素位置。
    - **用法：**
        
        ```cpp
        
        #include <algorithm>using namespace std;
        
        vector<int> vec = {1, 2, 2, 4, 5};
        auto it = upper_bound(vec.begin(), vec.end(), 2);  // 返回大于2的第一个位置
        int index = it - vec.begin();  // 转换为索引
        
        ```
        
4. **Binary Search（二分查找）**
    - **简介：** 在有序序列中查找元素。
    - **用法：**
        
        ```cpp
        cpp复制代码
        #include <algorithm>using namespace std;
        
        vector<int> vec = {1, 2, 3, 4, 5};
        bool found = binary_search(vec.begin(), vec.end(), 3);  // 查找元素3是否存在
        
        ```
        
5. **STL常用函数**
    - **accumulate：** 对容器中的元素求和。
    - **next_permutation：** 计算下一个排列。
    - **max_element / min_element：** 查找容器中的最大值和最小值。

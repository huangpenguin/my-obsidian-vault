# 新版本流程

### 1. 环境准备

 先安装paddlepaddle，由于cuda是12.2，我们采用了11.8

```jsx
nohup python3 -m pip install paddlepaddle-gpu==3.1.0 -i https://www.paddlepaddle.org.cn/packages/stable/cu118/ > paddle_install.log 2>&1 &

```

```bash
# 安装PPOCRLabel
pip install PPOCRLabel

# 或者从源码安装
git clone <https://github.com/PaddlePaddle/PaddleOCR.git>
cd PaddleOCR/PPOCRLabel
pip install -r requirements.txt

```

### 2. 数据组织结构

```bash
# 创建新项目目录
mkdir new_ocr_project
cd new_ocr_project

# 组织数据结构（参考现有项目）
mkdir -p datasets/new_project/
mkdir -p datasets/new_project/images/
mkdir -p datasets/new_project/det/
mkdir -p datasets/new_project/rec/
mkdir -p configs/det/
mkdir -p configs/rec/

# 将30张照片放入images目录
cp /path/to/your/30/images/* datasets/new_project/images/

```

### 3. 使用PPOCRLabel标注

```bash
# 启动PPOCRLabel
PPOCRLabel

# 或者指定数据目录
PPOCRLabel --lang ch --kie True datasets/new_project/images/

```

### 4. 标注流程

### 检测标注（Detection）

1. **打开图片文件夹**：选择 `datasets/new_project/images/`
2. **绘制文字区域**：
    - 使用矩形框或多边形框选文字区域
    - 确保框选准确包含所有文字
3. **保存标注**：生成对应的标注文件

### 识别标注（Recognition）

1. **文字内容标注**：为每个检测框输入正确的文字内容
2. **特殊字符处理**：注意日文假名、汉字的正确输入

### 8. 数据增强考虑

由于只有30张图片，需要考虑数据增强：

```yaml
# 在配置文件中添加数据增强
Train:
  dataset:
    transforms:
    - DecodeImage:
        img_mode: BGR
        channel_first: false
    - DetLabelEncode:
    - IaaAugment:
        augmenter_args:
        - {'type': 'Fliplr', 'args': {'p': 0.5}}
        - {'type': 'Affine', 'args': {'rotate': [-10, 10]}}
        - {'type': 'Resize', 'args': {'size': [0.5, 3]}}
    # ...更多增强策略

```

### 9. 训练策略建议

```bash
# 由于数据量小，建议：
# 1. 使用更小的学习率
# 2. 更多的epoch数
# 3. 早停策略避免过拟合

# 修改配置文件中的学习率
Optimizer:
  lr:
    learning_rate: 0.001  # 比baseline更小的学习率

```

### 10. 验证数据质量

```bash
# 检查标注质量
python scripts/check_labels.py datasets/new_project/det/det_new_project_train.txt

# 可视化标注结果
python scripts/visualize_labels.py

```

**关键建议**：

1. **标注质量**：30张图片虽然不多，但标注质量要非常高
2. **数据增强**：必须使用大量数据增强来扩充训练数据
3. **预训练模型**：充分利用预训练模型的能力
4. **迭代优化**：先用少量数据验证流程，再逐步优化

# 自定义异常类

```python
class UppercaseException(Exception):
  pass
word =['a','Fv','GFc']
for word in words:
	if word isupper():
		raise UppercaseException(word)
```

### 改进的方法

如果想要在遍历列表时检测到全大写的单词并抛出异常，有更好的方法可以改进代码，例如：

1. **捕获异常并处理**：可以使用 `try-except` 块来捕获异常并进行相应处理，而不是让程序直接崩溃。
2. **使用内置函数 `all()`**：通过 `all()` 函数和列表推导式，可以简化代码。
3. **提供更多信息**：抛出异常时提供更多的上下文信息。

改进后的代码如下：

```python

class UppercaseException(Exception):
    def __init__(self, word):
        super().__init__(f"Uppercase word found: {word}")#一个格式化字符串

words = ['a', 'Fv', 'GFc']

try:
    for word in words:
        if word.isupper():
            raise UppercaseException(word)
except UppercaseException as e:
    print(e)
```

### 进一步改进

如果希望仅检查特定条件而不引发异常，还可以使用生成器表达式或过滤函数来简化代码：

```python
words = ['a', 'Fv', 'GFc']

uppercase_words = [word for word in words if word.isupper()]

if uppercase_words:
    print(f"Uppercase words found: {uppercase_words}")
else:
    print("No uppercase words found.")

```

# server配置

X群DMZ，Y群社内サーバーの場合

機密性の観点からは、サーバはできるだけ社外から直接アクセスできない LAN のサーバ群 Y に配置し、 DMZ のサーバ群 X には、社外から直接アクセスしなければならない最低限のサーバのみ配置することが望まれます。

RP サーバ は、社外の利用者の Web ブラウザからアクセスを受け付けて、 Web サーバにアクセスを中継する役割を果たしますので、 DMZ に配置しています。

Web サーバを LAN のサーバ群 Y に設置して、 FW で RP サーバ から Web サーバへの通信を許可すれば、利用者から間接的に Web サーバを利用できます。ただし、 RP サーバ がなく、社外から直接 Web サーバを利用したいときは、 DMZ 上のサーバ群 X に配置する必要があります。

DB サーバは Web サーバとの間だけで通信し、社外から直接アクセスする必要がないので、社内 LAN のサーバ群 Y に設置します。

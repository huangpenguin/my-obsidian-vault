# 风格检查linter,formatter

## **📋 代码质量检查工具说明**

### 1. **Linter (代码检查器) - `uv run ruff check`**

- **目的**: 静态分析代码，发现质量问题
- **检查内容**:
    - 语法错误、代码风格违规
    - 未使用的变量、导入
    - 类型注解问题
    - 行长度、空白问题
    - 安全隐患

### 2. **Formatter (代码格式化器) - `uv run ruff format`**

- **目的**: 自动统一代码格式
- **执行内容**:
    - 缩进、空白统一
    - 行长度调整
    - 导入语句排序
    - 括号、逗号位置统一

### 3. **Test (测试) - `uv run pytest tests/ -v`**

- **目的**: 验证所有功能正常工作
- **执行内容**:
    - 运行所有测试用例
    - 显示详细执行结果 (`v`标志)
    - 失败测试的详细信息

### 4. **Coverage (覆盖率) - `uv run pytest tests/ --cov=src --cov-report=term-missing`**

- **目的**: 识别未被测试覆盖的代码行
- **执行内容**:
    - 测量src目录的覆盖率
    - 显示未测试的代码行详情

### 5.Pyright

- **类型一致性检查**：确保变量、函数参数和返回值等符合类型注解的定义。
- **未定义标识符检测**：识别使用前未定义的变量或函数。
- **模块导入有效性检查**：验证导入路径、模块或成员是否存在。
- **未使用代码提示**：提示未被使用的导入、变量、函数等，有助于清理无用代码。
- **函数调用匹配性检查**：确保函数调用时的参数数量、顺序和名称与定义一致。
- **类型推导和流分析**：推导变量类型，并在不同分支中进行类型流追踪，捕捉逻辑错误。
- **类和继承关系校验**：检查类的定义、继承结构及方法覆盖的一致性。
- **配置文件校验**：识别 pyrightconfig.json 中的配置问题。

## 1. 技能推荐安装在哪里？（项目 vs 全局）

在这个项目中，技能的安装位置取决于你的**开发场景**。你可以根据以下原则来选择：

- **推荐安装在“项目（Project）”级别（默认）：**
    
    - **适用场景：** 团队协作项目、特定技术栈的项目（例如某个项目专门用 Next.js，另一个项目用 Python）。
        
    - **优点：** 技能文件会保存在当前项目根目录的 `.agents/skills/` 下，可以随着 Git 一起提交（Commit）。这样团队里的其他成员拉取代码后，他们的 Cursor 也能自动获得相同的规范和技能。
        
    - **命令：** `npx skills add <仓库名> --skill <技能名>` （不需要加额外参数，默认就是当前项目）。
        
- **推荐安装在“全局（Global）”级别：**
    
    - **适用场景：** 纯个人的通用提效技能（例如：按特定格式写 Git Commit Message、日常代码重构润色、自动生成 Release Notes 等）。
        
    - **优点：** 电脑上的所有项目都能直接复用，不需要每个项目都装一遍。
        
    - **命令：** 加上 `-g` 或 `--global` 参数，例如：
        
        Bash
        
        ```
        npx skills add vercel-labs/agent-skills --skill frontend-design -g
        ```

## 2. 有没有可视化的 List 指令？

该工具本身是基于终端（CLI）的，虽然没有独立的 GUI 独立软件界面，但它提供了非常方便的终端交互式（类可视化）和列表指令：

- **查看已安装的技能列表：** 使用以下指令可以直观地看到你当前在全局或项目中安装了哪些技能：
    
    Bash
    
    ```
    npx skills list
    # 或者使用简写
    npx skills ls
    ```
    
    _如果要单独看全局安装的，可以加 `-g`：`npx skills ls -g`。_
    
- **交互式搜索与浏览（强烈推荐，体验最像可视化）：** 如果你想在一个交互式界面里上下键浏览、搜索技能，可以使用 `find` 命令。它内置了类似 `fzf` 的模糊搜索效果：
    
    Bash
    
    ```
    npx skills find
    ```
    
- **真正的网页端可视化浏览：** 如果你想在精美的网页上挑选技能，直接访问官方提供的技能集市：**[skills.sh](https://skills.sh/)**，在这里你可以像逛应用商店一样预览和查找全世界开发者贡献的技能。

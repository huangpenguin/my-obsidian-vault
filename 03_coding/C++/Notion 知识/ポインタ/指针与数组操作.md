# 指针与数组操作

指针（Pointers）：指针是一种特殊的变量，其值为内存地址，即某个变量或对象在内存中的位置。通过指针，可以直接访问或修改内存中的数据。指针可以指向任何数据类型（整数、浮点数、对象等）的变量或对象。

const关键字：const是C++中的关键字，用于声明常量。在变量声明中，const可以使其值不可变。在函数声明中，const可以表示该函数不会修改类的成员变量。此外，const还可以应用于指针。

### 指针的位置操作

```cpp
int main()
{
int array[] = {1, 2, 3, 5, 7, 11};
for (int* ptr = array; ptr != (array + 6); ++ptr)
{
cout <<"ptr: "<<ptr<<" "<< *ptr << endl;
}
}
```

从上面可以看出对指针进行+1的运算，不是字面值上的+1而去寻找下一个位置，所以可能指针的字面值变大了4（因为这里int是四个字节byte）

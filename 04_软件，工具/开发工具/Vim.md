# vim

## 🎯 模式切换

| 快捷键 | 含义 | 用途 |
| --- | --- | --- |
| `Esc` | 回到普通模式（Normal） | 浏览、删除、复制、粘贴、跳转等 |
| `i` | 进入插入模式（Insert） | **输入和编辑文字** |
| `v` | 进入可视模式（Visual） | 保存、退出、查找、替换等 |
| `:` | 进入命令行模式（Command） | 选择内容（像鼠标拖选） |

---

## 🚀 移动光标（Normal 模式）

| 快捷键 | 含义 |
| --- | --- |
| `h` `j` `k` `l` | 左 下 上 右 |
| `0` / `^` | 行首 / 首非空字符 |
| `$` | 行尾 |
| `w` / `e` | 下一单词开头 / 结尾 |
| `b` | 上一单词开头 |
| `gg` / `G` | 文件开头 / 结尾 |
| `Ctrl-d` / `Ctrl-u` | 向下 / 向上半屏滚动 |

---

## 🧽 编辑操作

| 快捷键 | 含义 |
| --- | --- |
| `x` | 删除当前字符 |
| `dd` | 删除当前行 |
| `dw` | 删除一个单词 |
| `u` | 撤销 |
| `Ctrl-r` | 重做（反撤销） |
| `yy` / `p` | 复制当前行 / 粘贴 |
| `r` | 替换单个字符 |

---

## 📝 插入操作

| 快捷键 | 含义 |
| --- | --- |
| `i` | 插入光标前 |
| `a` | 插入光标后 |
| `I` | 插入行首 |
| `A` | 插入行尾 |
| `o` / `O` | 向下 / 向上插入新行 |

---

## 💾 保存和退出（命令模式）

进入命令行：先按 `:`，再输入以下命令：

| 命令 | 含义 |
| --- | --- |
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` / `ZZ` | 保存并退出 |
| `:q!` | 强制退出（不保存） |

---

## 🔍 查找与替换

| 命令 | 含义 |
| --- | --- |
| `/text` | 向下查找 "text" |
| `?text` | 向上查找 |
| `n` / `N` | 下一个 / 上一个匹配 |
| `:%s/foo/bar/g` | 替换所有 "foo" 为 "bar" |

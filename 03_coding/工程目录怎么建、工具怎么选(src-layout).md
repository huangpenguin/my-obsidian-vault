[[一个路径的问题(PYTHONPATH)]]


学习现代 Python 工程化最佳实践，最高效的途径是以下四个：

#### 1. 现代核心工具的官方文档（最推荐！）

你现在用的 `uv` 是当下 Python 届最火、最先进的工具。这类现代工具的文档本身就是一本“最佳实践指南”。

- **你可以去读**：`uv`、`Poetry`、`Ruff`、`pytest` 这些工具的官方文档。
    
- **为什么**：因为这些工具的发明，本身就是为了**强迫或引导**开发者使用最佳实践。比如你看 `uv` 或 `Poetry` 的教程，它教你第一步怎么初始化项目时，就已经默认给你生成 `src-layout` 的结构了。顺着它们的教程做，你自然就在用最佳实践。
    

#### 2. 优秀的开源项目（抄作业）

想知道现在流行什么，直接去看 GitHub 上最火、代码质量最高的 Python 项目是怎么组织目录的。

- **推荐观摩**：`FastAPI`、`Pydantic`、`HTTPX`。
    
- 点开它们的 GitHub 仓库，看看它们的文件夹怎么建的，测试放在哪里，配置文件有哪些。你会发现它们惊人地一致（基本都是 `src-layout`），这就是行业标准。
    

#### 3. 专门针对 Python 工程化的现代指南

如果你真的想系统性地看一些文字资料，不要看泛泛的软件工程书，要看专门针对 Python 的工程化指南：

- **《Hypermodern Python》**：这是一篇在 Python 圈子里极其著名的系列博客（你可以搜索这个关键词），它详细讲解了如何从零搭建一个“极其现代、极其规范”的 Python 项目，包括怎么格式化、怎么测试、怎么建目录。
    
- **《Architecture Patterns with Python》**（中文翻译版叫《Python 企业级编程》或常被称为 Cosmic Python）：如果你想学更深一步的代码架构（怎么写出好维护的业务代码），这本书是目前最棒的。
    
- **Real Python 网站**：这个网站上的文章质量极高，搜索 "Python Project Structure" 就能找到非常详细的图文解释。
    

#### 4. Python 官方的增强提案（PEP）和 PyPA

像 `src-layout` 能够成为标准，是因为 Python 官方打包机构（PyPA）推荐了它。 当你遇到不懂的配置（比如 `pyproject.toml` 是什么），直接去搜索 **PyPA 官方文档**，里面会解释为什么要这样做。

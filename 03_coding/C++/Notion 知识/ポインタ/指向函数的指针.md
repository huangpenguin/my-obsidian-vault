# 指向函数的指针

```cpp
#include <iostream>
#include <vector>
using namespace std;

void show(int v)
{
    cout << v << endl;
}
void enumerate(int *first, int *last, void (*func)(int))
{
    for (; first != last; ++first)
    {
        func(*first);
    }
}
int main()
{
    int array[] = {1, 2, 3, 4, 5, 6, 7};
    size_t length = sizeof(array) / sizeof(array[0]);
    enumerate(array, array+length, show);//调用的时候要写实参
}

```

此处enumerate的最后一个形参就是函数指针

将show函数改写成匿名函数

```cpp
    enumerate(array, array + length, [](int v)
              { cout << v << endl; });
    //此处就是参数传递了，不需要捕获，因为enumerate会一直传入参数
```
